# しょうごっこさん 予約特典施策に向けて｜30代ちゃん・makiさんでうまくいったことの整理（working）

対象：30代ちゃん 6月コラボ（楽天ROOM note）／makiさん 8月ローンチ（秘書さんの物語note）。

## サマリー

**結果（各IF内の前回比）**
- 30代ちゃん6月：予約78→98、入会13→18、入会率27.7%→30.0%（2月コラボ比）。特典で間口を広げても質を保てた
- makiさん8月：5月コラボ（先行予約含む）比で、友達追加81→222、面談予約57→93、入会4→12、実施率56.1%→59.1%、売上¥198万→¥549万（どちらも面談が翌月にずれた分を含む）

## 1. 特典noteを作るときにやったこと

**主役を、読み手と同じ立場の身近な人にした**
- 30代ちゃんは従姉妹（専業主婦・SNS未経験）、makiさんは秘書さん（フルタイムの看護師から、おうちでの仕事へ）を主役にした。
- インフルエンサー本人ではなく身近な普通の人にすると、「この人だからできたんでしょ」と思われにくい。
- makiさんは5月は本人が主役だった。8月に秘書さんを主役にして、集客・予約・入会とも5月を上回った。

**稼いだ金額の先の生活まで書いた**
- 30代ちゃん：楽天ROOMの月4,000円で終わらせず、「月5万あれば在宅で働ける、習い事を増やせる、夫に確認しなくていいお金になる」まで書いた。
- makiさん：月10万で旅行、後回しにしていた服や美容まで書いた。秘書さんが始めた理由も「好きな仕事がしたかった」ではなく、「家族との時間もお金も、両方あきらめたくなかった」で書いた。
- 書く順番は、今の生活を振り返る→このままだと変わらないと気づく→見本の人の働き方→特典→相談会。

**タイトルは、意外な結果で引いた（makiさん）**
- 実際のタイトル：「【保存版】働く時間は減って、収入は2倍に増えた秘書の話。─家族時間を増やして＋月10万を作った「おうち仕事」」
- 秘書さんの本業（看護師）はタイトルに入れなかった。読み手はパートや会社員が多いので、「看護師の話」にすると自分とは違う人の話だと思われるため。
- 「収入を増やすには働く時間を増やすしかない」と思っている読み手に、「働く時間は減ったのに収入は増えた」を見せた。

**noteを1本書いて、冒頭をお試し版にした**
- 30代ちゃん：本編の最初の3章（はじめに・本人の実績・従姉妹の話）をそのままお試し版にした。従姉妹の結果（約4,000円）は全部見せて、やり方（楽天ROOMとは・始め方）は本編に残した。
- makiさん：本編の冒頭8,117字をお試し版にした。
- お試し版に足したのは、冒頭の「一部公開版です」という注意書きと、末尾の予約への案内だけ。

**本編は、できそう感→梯子落とし→だから相談会の順で書いた**
梯子落とし＝「このnoteを読んだだけでは足りない」「一人だと止まりやすい」と伝えて、スクールや相談会が必要だと思ってもらうパート。
- 30代ちゃん：楽天ROOMの始め方を具体的に書く（できそう感）→「楽天ROOMは入口としてはいいけれど、それだけで月10万・20万は大変」（梯子落とし）→次に身につけたいスキルの順番は人によって違うので、カウンセリングで整理（だから相談会）。
- makiさん：秘書さんの物語と未経験から始める5STEP（できそう感）→「全部できる人を目指さなくていい」「自分一人で整理できていたら、もう動き始めている」（梯子落とし）→だから特典は面談まで受けて完成（だから相談会）。
- どちらも、相談会の話は本編の最後にだけ出した。

**公開前に、口コミをもらっておいた（30代ちゃん）**
- 卒業生にnoteを先に読んでもらい、口コミをもらって、ローンチ中すぐに出せるようにした。

## 2. ローンチ期間中にやったこと

**予約の伸び方（日別）**

| | 30代ちゃん6月 | makiさん8月 |
|---|---|---|
| 1日目 | +16（21時開始・3時間） | +12（19時開始） |
| 2日目 | +26（オプチャを作り、深夜にお試し版を配布） | +25（お試し版の配布開始） |
| 3日目 | +15（ライブ配信中の4.5時間は投稿ゼロで+1） | +7（月曜。土日の枠が埋まり、翌週の日程はまだ開いていなかった） |
| 締切日 | +16（公式LINEで4回配信） | +38（3章を参照） |
| 締切後（延長） | note経由の予約を日曜まで延長し、4日間で+29 | 枠を9/6まで開けたまま延長し、82→85 |

**投稿を時間差で出し、予約が増えている様子をその都度見せた**
- 午前・午後・夜に分けて、4〜5枚ずつ出した。まとめて出すと読むのが重く、見られなくなる。
- 30代ちゃん：「LINE追加103人／予約61人」と今の数字を画像で見せた。LINE追加はしたけど予約していない人に「◯人がLINE止まりです」と呼びかけた。
- makiさん：「もう7人も追加で！お昼休みにえらい」など、予約が入るたびに出した。

**2日目に、お試し版を配った**
- 30代ちゃん：オプチャを作って、そこでお試し版を配った。締切後の延長期間にも、お試し版経由の予約が続いた。
- makiさん：ストーリーで「お試し版」とコメントした人に自動で送った。コメントに抵抗がある人向けに、翌日からnoteの直リンクも貼った。お試し版の分量は、モザイク付きのスクロール動画で見せた。

**noteの感想や、試した人の報告をすぐ載せた**
- 30代ちゃん：「もう読み終わって楽天ROOMを早速開設している人もいます」
- makiさん：公開10分で届いた感想DM、「今日からできること早速やってみます」などの声

**投稿できない時間は、公式LINEで埋めた**
- 30代ちゃん：最終日、ストーリーが出せない日中に、公式LINEで未予約者へ4回（15・17・21・23時）配信して+13。
- 投稿できなかった時間は予約が止まった（30代ちゃん：ライブ配信中の4.5時間で+1）。

**予約できる日程を切らさなかった（makiさん）**
- 3日目（月曜）は、土日の枠が埋まり、翌週の日程はまだ開いていなかった。フォロワーさんから「来週の日程が出たら予約します」というDMも届いていた。この日は+7で期間中最少。
- 締切日の朝10時に、土日の枠と9/6までの日程を開けて「交渉して開けてもらった」と告知。開けてから約1時間で+7。

**予約前の不安を消す投稿をした（30代ちゃん）**
- 詐欺スクールの見極め方と、スキルスキップが上場企業グループであることを発信した（申込者に詐欺・高額スクールの被害経験者が多かったため）。
- 「特典はきっかけにすぎない」と期間中ずっと伝えて、特典だけが目当ての予約を減らした。

## 3. 締切でやったこと

- 30代ちゃん：締切を2回作った。ストーリーズの特典最終日に+16。そのあとnote経由の予約だけ日曜まで延長して、その最終日に+8。
- makiさん：締切日1日で+38。
  - 朝：「予約枠50のラスト1枠」→「埋まった」と見せた
  - 昼：枠を追加した。9/6まで日程を開けたことも伝えた
  - 予約前アンケート（LINE追加後、相談会を予約する前に答えるアンケート）に答えたのに予約していない人へ、「◯人が止まっています」と呼びかけた（アンケート97件・予約72件の時点）
  - 夜：予約DMを載せて予約した人を褒め、「まだ間に合う」とお試し版のリンクをもう一度貼った
  - 締切後も枠を開けたまま延長し、82→85

## 4. 予約後にやったこと

- 30代ちゃん：公式LINEで、未予約者・未実施者・予約者・体験待ちに分けて配信した。事前キャンセルは12→5に減った。
- makiさん：「事前診断してない人が5名います」とストーリーで呼びかけた（事前診断に答えないと自動でキャンセルになるため）。
- makiさん：相談会に行った人の感想DM（勧誘されなかった／秘書さんの事例で始める順番が分かった）を載せた。「キャンセルしないで」とお願いするより、行く理由になる。

## 5. それでも残った課題

- 特典で間口を広げると、事前診断に答えずに自動キャンセルになる人が増える。2人とも全体の着席率・入会数は保てた。
  - 30代ちゃん：自動キャンセル9→18（2月コラボ比）
  - makiさん：自動キャンセル3→11、予約に占める割合は5%→12%（5月コラボ比）。当日キャンセルは26%→15%に減り、キャンセル率全体は43.9%→40.9%
- 締切で押す前に、相談会に行く理由を作っておく。行く理由がないまま締切で押すと、勢いで予約→日が近づいて事前キャンセル、になる。

## 6. しょうごっこさんでやること（案）

**特典note**
- 主役はあんなさん（しょうごっこさんのフォロワーから入会した会社員）。
- 本編は「できそう感→梯子落とし→だから相談会」の順に組み直す（担当者さんにコメント済み）。お試し版は上司がブラッシュアップ中。
- 仕事の説明（SNS運用代行・ゴースト型/プロデュース型・単価）は5月のnoteで出しているので、あんなさんの実体験で見せる。
- 公開前に、あんなさんや、しょうごっこさん経由で入会した卒業生に本編を読んでもらい、口コミをもらっておく。
- よくある質問や相談会メモで、家族への相談やお金のことも聞いていいと伝えておく（しょうごっこさん8月は、着席しても入会しなかった理由の上位が家族への相談・お金・できるか不安）。

**ローンチ期間**
- 日別の流れを決める（特典公開→2日目にお試し版→締切→延長）。
- お試し版の配り方を決める（コメント・直リンク・LINE、しょうごっこさんなら動画も）。
- 投稿が薄くなる日（撮影・家族の予定）を先に洗い出し、公式LINEで埋める。
- 締切は二段にするか、満枠→増枠を見せるかを決める。
- 予約前アンケートで止まっている人への呼びかけと、事前診断の回収を締切日に入れる。

**注意**
- しょうごっこさん8月（勉強会）は、母数を広げた分キャンセル率49%。いちばん多かったのは事前診断未回答の自動キャンセル。
- アマギフは予約の釣りではなく、末尾のご褒美に置く。

**すでにある強み**
- 海上保安官から在宅ワークへ、家族を最優先にする働き方という一次情報。
- 7月PRは動画（VSL→代表との対談→SARINAさん対談）で道筋を見せ、確かめたいことが具体的な予約者が多かった（67%）。対談動画は配布2日目で402件見られている。
