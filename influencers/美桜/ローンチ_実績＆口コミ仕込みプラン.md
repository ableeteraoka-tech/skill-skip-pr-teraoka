# ローンチ 実績＆口コミ 仕込みプラン（美桜さん・30代ちゃん式）

> 狙い：30代ちゃんが7月ローンチでやっていた「①卒業生Before/After実績 ②事前に集めた口コミ ③0→1報告」を、ローンチ本番(9/5〜9/8)で連射できるよう、**事前に弾込め**しておく。
> 重要な気づき：30代ちゃんの7月ローンチは**実質6/29から**動いていた＝告知の前に"仕込み週間"がある。美桜さんは**事前教育期間(8/29〜9/4)＝仕込み週間**として使う。
> 表記：美桜さんは「一部公開版」。数字・体験談の掲載は**必ず本人許可**（既存ヒアリングシートの許可ブロック準拠）。

---

## A. 実績の強化（Before/After 実績カード化）
既存ヒアリングの2名の数字を、ストーリーにそのまま貼れる**短い実績カード**に変換する（30代ちゃんの実績ページ式）。

### フォーマット
```
【実績①】★仮名（★属性：例 30代・2児ママ・元専業主婦）
Before： ★始める前（例：PC苦手／"自分にできるか不安"）
After ： ★今（案件の種類＋月◯万／累計◯万）
一言 ： 「★初報酬・変化のひとこと」
```

### 下書き（既存数字ベース・★は本人確認）
- 【実績①】★仮名（★属性）
  - Before：★（始める前の状況・不安）
  - After：Canvaのフィード作成から始めて、今は動画編集も。**月2万／累計約10万**
  - 一言：「★（初報酬が出たときの気持ち）」
- 【実績②】★仮名（★属性）
  - Before：★
  - After：切り抜き・動画買取・運用代行まで。**月5.9万／累計10.8万**
  - 一言：「★」

### 追加で欲しい素材
- [ ] "最初の1件"のエピソード（一番刺さる）＋ 初期作品の**Before/After画像**
- [ ] 2名を1枚にまとめた**実績まとめ画像**（ストーリー1枚で見せる用）

## B. 口コミの先取り（pre-seed）
ローンチDay2〜3で出す「読んだ子の声★」を、**事前に確保**しておく。

### 誰に頼む
1. 受講生2名（＋美桜さんの仲良いフォロワーがいれば優先）
2. **一部公開版／本noteを事前に読んでもらえる少人数モニター**（数名でOK）

### 何を頼む
- 読んだ率直な感想（狙いは「未経験でもイメージ湧いた」「やってみたくなった」系）
- 可能なら**実際にCanvaで1つ作ってみた／やってみた感想**（＝0→1の芽）
- 掲載可否（スクショOK？／ニックネーム？）

### いつ（9/5ローンチ逆算・30代ちゃん6/26-30の型を移植）
30代ちゃんは本番(6/29)の前に「予告→信頼構築→口コミ先取り」の仕込み3日をやっていた。美桜さんは**事前教育の終盤を仕込み週間**に使う。
- 〜9/2：**実績カード化**（受講生2名ヒアリング→Before/After＋掲載許可）
- 9/3（事前教育Day6頃）：**予告**（コラボが来ると匂わせ／質問箱で不安・悩みを集め＝訴求弾）
- 9/3〜9/4：**信頼構築**（スキルスキップの実績・運営を軽く提示／予約特典の位置づけを予告）
- 9/3〜9/4：**口コミ先取り🎯**（note／一部公開版を受講生・仲良いフォロワー・モニターに先読み→感想回収＋掲載可否）
- 9/4：**弾フォルダ整理**（実績カード・口コミ・スクショを台本の★に紐づけ）
- 9/5〜9/8：**本番ローンチ**で連射（下の対応表）

### ローンチ台本の★との対応
| 台本の★ | 使う弾 |
|---|---|
| Day1⑧ 予約反応★ | 1人目予約DM／〇分で〇人 |
| Day2② 動き出した子の声★ | 予約DM＋背景ストーリー |
| Day2① 反応スクショ★ | 予約・受け取りの通知/オプチャ盛り上がり |
| Day3④ 読んだ子の声★ | **事前モニターの感想**（B で回収） |
| Day3 実績（新設候補） | **Before/After実績カード**（A） |
| Day4② 予約数/0→1報告★ | 期間中の0→1・予約数 |

## C. 口コミ依頼テンプレ（DM・そのまま送れる）
> ※美桜さんの声で。相手により微調整。

**受講生・モニター向け：**
「突然ごめんね🙏 今度スキルスキップさんとコラボで、デザインの特典noteを出すの📖
その前に、◯◯ちゃんに"先に"読んでもらって、正直な感想が聞きたくて…！
・読んでみてどう思ったか（"難しそう"が減った？等）
・もし少しでもCanva触ってみられたら、その感想も
差し支えなければ、感想をストーリーで紹介させてもらえたら嬉しいです🥹（ニックネーム/匿名OK）」

**フォロワー全体向け（事前教育中に軽く撒く）：**
「デザインの特典note、もうすぐ完成します🎨
"こういうところが知りたい""ここが不安"ってあれば、質問箱で教えて〜！
実際に読んでくれた人の声も、これから紹介していくね☺️」
