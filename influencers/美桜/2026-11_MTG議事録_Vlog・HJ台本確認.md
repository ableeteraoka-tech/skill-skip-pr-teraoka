## 🔹 話し合いの詳細

### 💡 1. Vlog（朝ルーティン）の狙いと冒頭コピー

- **狙い**：忙しい朝に美容や丁寧な暮らしまでこなしている、というギャップを作る。
- 美容シーンは凝ったものでなくてよいが、**必ず入れる**。美容で人を集めておくと美容アイテムを売りやすくなるため。例：ストーリーズで紹介中のメデュラのヘアアイロン（要確認）。
- 時刻の表示を入れる（前回、美桜さんが気づいた点）。

**冒頭コピーの候補**

| 案 | 内容 | 美桜さんの反応 |
|---|---|---|
| A | 30代独身一人暮らし 出勤前の朝ルーティン（当たっているが普通） | — |
| B | 東京独身一人暮らし／東京独身女一人暮らし 仕事前ルーティン | まずやってみる案 |
| C | **二日酔いなのに朝5時起き** | 「面白い」「私っぽい」。シャワー→美顔器でむくみ取り、と自然な流れが組めそう |
| D | 午前中に全部詰め込む女（15時ごろに仕事を終える生活） | 横展開（第2パターン）向き |

> 「二日酔いなのに朝5時起き…私っぽい。タイトルとかもいいですね」（美桜さん）

### 💡 2. Vlogのシーン構成

```
電車（冒頭フック）
 → 朝5時起床（必須）
 → ウォーキング／散歩（できれば小走りで動きを出す）
 → 帰宅・シャワー
 → スキンケア・ヘアケア（美容シーン）
 → 土鍋でご飯を炊く（朝から土鍋のギャップ）
 → 愛犬の散歩
 → メイク・ヘアセット・着替え
 → 「行ってきます」→ 再び電車
```

- シーンの順番は寺岡さんの仮置き。**メイクと犬の散歩の順番を入れ替えてもOK**。
- 犬はほとんど歩けず、ちょこちょこ動く程度。「走れないから散歩を2回に分けている」と添えると、美桜さんの優しさが伝わる。
- 歩く・走るシーンは、斜め上からの自撮りか足元のカット。ストレッチを入れると「運動しています」感が出る。
- **第2パターン**：お昼まで引っ張って仕事の様子を入れ、「15時には終了してお酒」で締める。

> 「イメージついた」「すごい、作ってみたい」（美桜さん）

### 💡 3. 電車カットの撮り方 🔴

🔴 **電車始まりの冒頭は今流行っているので、まずテストで試す。**

- 美桜さんは前日に試し撮りした。夕方で人が多く、緊張してカメラが近くなり、アップになってしまった。
- 参考アカウントは勇気を出してカメラを引いている。服が下の方まで映っていて、自撮り棒を使っているくらいの距離。
- 揺れすぎるとノイズになる。**ブレすぎず、少し動きがあり、奥行きがある**画が理想。カメラ目線は一瞬ならOK。
- 撮る場所：車両の端を選ぶ。平日の昼、地下鉄や私鉄が狙い目。JRは混みやすい。

**服装と見え方**

- 露出は控えめでよい。「いい女」風の格好だと「こんな格好で仕事に行くの？」と目を引く。
- 美桜さんは「その格好でデートに行く」と言っていたが、**視聴者目線では「その格好で出勤するの？」というギャップになる**と寺岡さんが説明し、納得してもらった。
- 冒頭だけ電車で、その後は普通のトレーニングやルーティンにつなぐ構成も一般的。辻褄を厳密に合わせなくてよい。

⚠️ 電車系の動画には、男性の「お疲れ様」「可愛いのに大変だな」といったコメントも付きやすい（痴漢を連想させる層）。バズると入ってくる層なので、引き換えとして受け入れる。

### 💡 4. ヒーローズジャーニー①：デザイナー職のキャリア

**台本の流れ**

```
デザイナーは「おしゃれ・キラキラ」というイメージ
 → 憧れて専門学校へ。毎日朝8時〜夜8時（要確認）まで学び、学年2位に
 → 実際は派遣社員で年収360万。スキルを磨く時期だと思って頑張った
 → 「好きな仕事」と「ちゃんと稼げる」は違うと気づき、就活
 → 大手に入って年収アップ → 副業も開始
 → 会社を辞め、今は好きな仕事ができている →「努力が大事」
```

- 美桜さんの確認では「流れは大体合っている」。
- 派遣の話は盛りすぎなのでカットしてもよい。

**素材の悩みと解決策**

| 悩み | 解決策 |
|---|---|
| 社会人時代の写真がほぼない（残っているのはCG専門学校の写真3枚と、アメリカ在住の小学校時代の写真くらい） | ストーリーズやnoteで出した写真を使う。**写真は2枚程度で十分**、あとは何でもよい |
| 派遣時代や退職の場面の映像がない | **今の映像を撮ってオレンジ・黄色っぽく加工し、平成風のレトロ感を出す** |
| 会社を辞めた話をどう表現するか | 最近の素材で問題ない（昼飲み、お祭り、旅行、カフェなど何でも） |
| 未来パート | 歩いている、散歩しているなど何でもよい。過去の動画素材も使える |

> 「映像ってばかにできない。汚く撮ったら誰も見てくれない気がする」（美桜さん）
> 「作ってみておかしかったら素材を差し替える。やるしかない」（美桜さん）

- 冒頭は玄関のカットが強い。参考動画では、犬が玄関に向かって走ってくる（お菓子で釣って、ドアを開ける・閉めるを繰り返して撮る）。
- 美桜さんの犬は迎えに来ないので、自分が玄関から入ってくる形でもよい。

### 💡 5. ヒーローズジャーニー②：ショート版（会社を辞めたら平日昼からお酒）

- フック：「会社を辞めたら、平日の昼からお酒を飲んでいました」。過去パートは短くする。
- 「今は稼げるようになったから辞めた」→ 共感ポイントとして「唯一のデメリットは話し相手がいないこと（笑）」を入れ、視聴者との距離を縮める。
- 未来パート：仕事終わりにお酒を飲みながら犬の散歩。
- 締めのメッセージ例：「今日が一番若い日だから、みんな頑張ろうね」（変更OK）。

### 💡 6. ヒーローズジャーニー③：ジュエリーきっかけ（フック強め）

```
「〇〇（ハイジュエリー。「アルハンブラ」と推定・要確認）がきっかけでした」
 → 最初はすぐに出せる金額じゃなかった。給料が上がっても貯金は増えなかった
 → 「欲しいものを誰かに買ってもらうのもいいけど、自分で買える力をつけたかった」（前回の美桜さんの言葉）
 → 副業を開始 →（本業化の流れ）→ 自分で稼いだお金で買った
 → 締め：「買ってもらうのも、自分で買うのも、どっちも選べる女でいて」
```

- 美桜さんの評価：**直近の歴史なので作りやすそう**。
- オープニング案：キラキラ系のジュエリー、デコルテが開いた服で歩くカット。
- 美桜さんから、**電車カットでボディライン系の服を着る**案が出た。寺岡さんも「めちゃくちゃいい」と賛成。Vlogと一緒に撮影できる。
- 「OLの悩み」として共感を取りやすい切り口。

### 💡 7. 編集のテンポ・音源・尺

| 項目 | 推奨 |
|---|---|
| ナレーション | **入れない**。参考動画も入れておらず、それがテンポの良さにつながっている |
| テロップ | 台本の文言を**短くして**入れる（今は長すぎる） |
| 音源 | ナレーションなしで**エモい系の音源**。Mrs. GREEN APPLEなどがおすすめ。PRではないので何でも使える |
| 1カットの長さ | 平均0.8秒。短いと0.5秒、売りたい物のシーンだけ2秒程度。社内まとめ資料あり |
| 尺 | 参考動画は約80秒。60秒程度でもよい。今は尺の長さはあまり関係ない |
| 編集の進め方 | 参考動画を下に敷いて、同じテンポでカットを切って真似する |

- 制作時間の目安：撮影はもっと短くて済むはず。編集は3時間程度かかる見込み（文字起こしが不明瞭、要確認）。
- 型が固まればAIでもある程度編集できる。ただしカット割りはAIではまだ難しいので、**最初は自分で編集**するのがおすすめ。

> 「曲の指定がまじで嬉しい。曲が分からなさすぎた」（美桜さん）

### 💡 8. 投稿の進め方（スケジュール合意）

- **Vlogから着手**（美桜さん：「一番最初にやれそう」）。家の中の美容シーンは楽だが、外の撮影、特に電車が大変。
- 撮影：今週末（14・15日）。朝のお客様の固定仕事のあとに撮る。電車は土曜に時間を取って着替えて行く（土曜は混む点が懸念）。
- 投稿：17日（火）目標、遅くとも翌週前半。
- **まずトライアルリールに出す**（上野さんの方針）。24時間後の数字をもとに相談し、必要なら改善してから本投稿する。
- Vlogのあとにヒーローズジャーニーに取りかかる。

> 「素材が良ければあとはどうにでもなる。電車次第。あれがまじでプレッシャー」（美桜さん）

## 🔹 評価まとめ

### ✅ 強み
- 顔なし・手元撮影の「買わなきゃよかった」ジュエリーネタで、40万リーチ・低いスキップ率という勝ちパターンを自分で見つけている。
- 素材の品質へのこだわりが強く、撮り直しを厭わない。
- 「二日酔いなのに朝5時起き」など、キャラが立つ切り口を即座に自分事にできる。

### ⚠️ 伸びしろ（課題）
- 撮影8時間＋編集6時間と制作負荷が高く、毎日投稿や量産には向かない状態。
- ナレーションを入れる癖があり、テンポが落ちやすい。
- 社会人時代の写真が少なく、HJの過去パートの素材が不足している。
