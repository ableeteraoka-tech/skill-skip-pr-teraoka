## A. 実証2本から学ぶ「勝ってる構成」の共通骨格

maki・done姉さんが揃って踏んでいる順番。ここが美桜さんの現行に足りない。

1. **悩みの代弁（具体・複数）** — 冒頭3〜5行で読者の悩みをセリフで並べ「自分の話だ」にする
2. **「私も同じでした」→主人公の物語** — 顔のある1人（一人称）が、悩みの底から動き出す
3. **対になる理想（具体・複数）** — 悩みと1対1で対応する"叶った暮らし"を箇条書き
4. **収入の月次時系列** — 0円期間を正直に見せる→少しずつ増える推移（＝感情の背骨）
5. **「私だからでしょ？」への反証** — 未経験の受講生／秘書を、顔のある1人として立てる
6. **なぜ今この仕事か（市場）** — 読者の体験（スクロールで広告）に置き換えてから数字
7. **入口スキルの提示** — 低ハードル・センス不要・無料
8. **✂️一部公開版はここまで**
9. **本編の価値提示 → 面談への橋（後述の5ステップ）**

### done姉さんFBの最重要ポイント（美桜さんにもそのまま効く）
- **気持ちは「言葉」でなく「場面」で書く**（"我慢した"→"レジ前まで持って行って値札を見て棚に戻した"）。「その文、動画に撮れる？」テスト。
- **語り手を一本化**（friend と 私 が混線しない）。主人公は顔のある1人に固定。
- **煽り語（確実に/裏ワザ/圧勝）は感情パートで外す**。

## D. 面談への橋（一部公開版クロージング）＝done姉さんFB追記の5ステップ

**美桜さん仕様の注意**：[[cta-no-premature-sales-fear]]に従い、第一部で「勧誘されない」を先回りしすぎない。軽いためらい（何話す？決めなきゃ？）を拾って"行きたくなる"方向へ。

1. **問いかけで自分ごと化** … 「月5万増えたら、まず何に使いたい？」
2. **予約という行動を褒めて背中を押す** … 「気になっても実際に動く人はほとんどいない。予約したあなたはもう一歩進んでる」
3. **面談＝"頭の中を一緒に整理する場"** … 「その場で何かを決める場じゃなく、頭の中を一回ぜんぶ整理する場」＋聞けること5点。⚠️**「売られる場/勧誘」は否定形でも絶対に出さない**（その心配をするのはもっと先の段階の人。持ち出すと逆に不安を植える）→[[cta-no-premature-sales-fear]]
4. **軽いためらいだけ拾う** … 「何を話せば／うまく話せるかな／まだ決まってないのに→ぜんぶ大丈夫」（※"勧誘しません"は前面に出さない）
5. **チェックリスト＋特典** … 「✅こんな人に来てほしい」＋当日メモのお願い＋Amazonギフト◯◯相当
