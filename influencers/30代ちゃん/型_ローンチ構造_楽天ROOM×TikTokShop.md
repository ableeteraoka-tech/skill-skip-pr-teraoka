# 30代ちゃんの型（楽天ROOMコラボ／TikTok Shopのnote販売）

元にしたもの：ストーリーズ文字起こし（woman_from30 2026-06・07・10・11）、プレイブック_コラボ運用、ローンチ・プレイブック（maki×30代）
2つは目的が違う。楽天ROOMはスキルスキップとのコラボ（ゴールは相談会予約）、TikTok Shopは本人の有料note販売（ゴールはnote購入。600部超）。教育の進め方は共通点が多い。

## サマリー

1. どちらも「本人がこっそりやっていた→完成→みんなにも」の連載で、販売前から待たれる状態をつくっている
2. 実績は本人ではなく、身近な初心者（卒業生・従姉妹や友達のキッズ4人）を主役にする。本人は「巻き込んだ人」の立ち位置
3. 疑問と不安は、販売前に質問箱・オプチャのライブ・Q&Aで先に潰す。買ったあとに「自分には関係なかった」とならないようにする
4. 期限は「早い者勝ちにしない」と言いつつ、価格と期間で締める。最終日は残り時間と部数を小刻みに出す
5. 楽天ROOMでは、特典はきっかけ、相談会は作戦会議、と役割を分けて相談会につないでいる

## 1. 楽天ROOMコラボ（6月）

コラボ期間：6/29 21時〜7/2（延長あり）／特典：楽天ROOMの始め方note＋Amazonギフト1,000相当／予約102（LINE追加73）

### 全体の構成

| フェーズ | 時期の目安 | やったこと | ねらい |
| --- | --- | --- | --- |
| ① 種まき | 開始9日前 | 雨の日に家で楽天ROOMのnoteを書いている | 何かが始まる気配 |
| ② 特典とコラボの発表 | 開始7日前 | 特典のテーマ（楽天ROOMの始め方、予約者限定、初心者向け）、コラボ日程、真っ先に行動した人への特典 | 特典と相談会をセットで最初から出す |
| ③ 価値観のすり合わせ | 開始6〜5日前 | アンケート：子どもを産んで仕事への考えは変わった？→「バランス良く両立したい」が最多→本人も同じ | 読み手と同じ側に立つ |
| ④ 理想を集める | 開始6〜3日前 | 近い未来こうなれたらいいな、を教えて→モヤモヤ・悩み・理想の質問箱に回答 | 自分ごと化 |
| ⑤ 信頼 | 開始3日前 | 詐欺スクールの見分け方3つ、運営は東証プライム上場のベクトル | 予約前の不信を下げる |
| ⑥ 完成・先読みの感想 | 開始前日 | 卒業生に先に読んでもらった感想、無料のつもりが1万6000字 | 待たれる状態 |
| ⑦ 相談会の位置づけ | 開始前日 | noteだけで完結しない、楽天ROOMはきっかけで相談会は作戦会議、入会を決める場所ではない | 相談会を受ける理由 |
| ⑧ 開始 | 1日目 21時 | 特典2つ、予約前アンケート10件・予約9件の速報、卒業生のDM、育休中に入会した人 | お祭り感 |
| ⑨ 2日目以降 | 2〜4日目 | 残り枠（25→8）、note読んで始めた人、お試し版の配布、表面的なネガティブ情報を一蹴、最初の熱量 | 再加速 |
| ⑩ 締切を二段に | 特典最終日／延長最終日 | 「本日最終日」＋延長で「このリンクが消えるまで」 | 締切で2回伸ばす |

### 効いたこと

- **特典の価値を本人以外に言わせる**：卒業生に先に読んでもらい「え、これ特典なの？」の感想を載せた
- **特典と相談会の役割分け**：「楽天ROOMはキッカケで、カウンセリングは作戦会議」「なるほどで終わるのは意味がない」
- **お試し版の動線**：開始翌日以降にオプチャ→お試し版note→予約の動線を出し、特典期間後も予約が続いた（全体の約28%を追加）
- **発信を止めない**：ストーリーズが空く時間は公式LINEを連打

### 課題（2月との比較で見えたこと）

- 中盤に物販PRが多く、コラボの教育が開始1週間前に圧縮された
- 楽天ROOMの数百円の話で理想の天井が低く、料金で止まる人が出た
- 発信しない働き方（運用代行・オンライン秘書）の実像が出せていない

## 2. TikTok Shopのnote販売（10月）

販売期間：10/24 21時〜11/1 23:59（発売記念価格）／無料部分1万字／最終600部超

### 全体の構成

| フェーズ | 時期の目安 | やったこと | ねらい |
| --- | --- | --- | --- |
| ① 匂わせ | 発売3週間前 | 朝5時からnoteを書いている／突然の歯医者13万でも、最近始めたことで先月40万くらい収益化できたから心穏やか | 何をやっているのか気になる |
| ② オプチャで先に集める | 発売2週間前〜 | オプチャのトークライブ（夜中）。質疑応答をしてから売る、と宣言。オプチャ1000人 | 熱い人を先に囲う |
| ③ 正体の発表 | 発売10〜9日前 | 「インスタの裏でこっそり別のSNSで副業してた」→従姉妹や友達（キッズ）とのグループLINE→無料のご報告noteをキーワードDMで配布（2,000人超が受け取り） | 期待のピーク |
| ④ 仕組みの説明 | 発売8〜4日前 | 「どうやってお金になるの？在庫は？誰が払う？」を代弁→仕組みの動画をキーワードDMで配布。1円クーポン、サンプルが届く話 | 一番手前から理解させる |
| ⑤ よくある不安に先回り | 発売4〜2日前 | 既存アカウントでいい？／フォロワー1000人いける？（キッズは5〜10日で達成）／保証はできない、やるかやらないか | 買う前の壁を下げる |
| ⑥ 誰向けかと価値観 | 発売前日 | 家でできる仕事と、自分のペースで家でできる仕事は違う／自由な分、自分で動ける人しか進まない／買って満足の人は買わないで | 絞り込みと納得 |
| ⑦ 発売日の告知 | 発売前日 | 表紙の発表、発売日時、早い者勝ちにしない、通知が欲しい人はキーワードDM | 待機させる |
| ⑧ 発売 | 1日目 21時 | 「おまたせ」→キッズ4人のプロフィール（年代・家族・仕事・最高収益）→販売期間と初回価格→その後オプチャライブ | 初速 |
| ⑨ 販売中 | 2〜7日目 | キッズのインタビュー、購入者の進捗（2日で1000人、初収益）、Q&Anote、質問箱に毎日回答、ネガキャンへの対応、リワードの無料note | 実例を毎日積む |
| ⑩ 最終日 | 8日目 | ラスト質問箱、450→480→500→600部、残り3時間・1時間・10分 | 締切で再加速 |
| ⑪ 販売後 | 終了後 | 購入者の成果報告を毎日紹介、焦らなくていい、比べるなら動画を比べて | 購入者の継続と次の再販の種 |

### 効いたこと

- **初心者4人の実例**：本人1人の成功ではなく、属性の違う4人（未就学児ママでパート、フルタイム会社員、インスタスクールで挫折した人など）と最高収益を並べた。「自分と近い人」を見つけやすい
- **キッズへのインタビュー形式**：始める前の不安→やってみて簡単だったこと／難しかったこと→一緒にやって役立ったこと→変化→これから始める人へ。体験の順番で読ませている
- **キーワードDMで段階的に配る**：ご報告note（きっず）→仕組みの動画（きそ）→オプチャ（おぷちゃ）。DMするたびに関与が深まる
- **質問を公開で答える**：個別に返さず、ストーリーズとQ&Anoteで全員に答える。同じ不安の人がまとめて解消される
- **厳しめの線引き**：保証はできない、個別サポートはしない、スクールの方が向いている人もいる。誇大に見えず、信用につながっている
- **締切の理由が明確**：初回価格は今だけ、再販時は値上げ、12月の大型セールに間に合わせるなら今

## 3. 2つに共通する型

| 要素 | 楽天ROOM | TikTok Shop |
| --- | --- | --- |
| 作っている過程を見せる | 雨の日にnoteを書いている、完成 | 朝5時から書いている、図解作り、表紙の発表 |
| 主役は身近な初心者 | 卒業生、note読んで始めたフォロワー | 従姉妹や友達のキッズ4人 |
| 先読みの感想 | 卒業生に読んでもらった感想 | 発売前の楽しみDM、フライングで始めた人 |
| 理想や価値観を集める | バランス良く両立したい、近い未来の理想 | 自分のペースで家でできる仕事 |
| 不安の先回り | 詐欺スクールの見分け方、上場企業 | フォロワー1000人、在庫、誰が払う、怪しくない？ |
| オプチャ | お試し版の配布先 | ライブで質疑応答、先に囲う |
| 期限 | 予約枠と特典期間、延長で二段 | 初回価格と販売期間、再販は値上げ |
| 予約・購入の速報 | 予約9件、残り25枠→8枠 | 300→450→600部、三脚も180個 |

## 4. ほかのIFに使うときの注意

- 30代ちゃんの毒っ気や関西弁、言い回し（キッズ、やるか、やるか、など）は流用しない。型だけ使う
- TikTok Shopは本人の商品販売なので、相談会への導線はない。コラボで使うときは、楽天ROOMの「特典はきっかけ、相談会は作戦会議」を足す
- 信頼ストック（育休noteを400部買われる関係）があって効いた型。新しいIFでは、教育期間で信頼を積む部分を厚めにする
