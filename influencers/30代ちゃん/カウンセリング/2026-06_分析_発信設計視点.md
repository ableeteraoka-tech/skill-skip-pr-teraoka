# 30代ちゃん 6月コラボ カウンセリング分析（インフルエンサー発信設計の視点）

営業クロージング目線ではなく、「**30代ちゃんがどんな投稿をすれば、この層が引き上がる（申込→体験→入会に進む）か**」に落とすための分析。

## 0. 前提・データ品質
- 14ファイル中：顧客の声が使えるのは **9件**、入会1件（松井）は音声英語化けだがカウンセラー側から状況を復元、`宮田怜奈`は**顧客ではなくカウンセラーの営業トレーニング**なので除外、残り4件（垂水・奈良輪・脇丸・松井）は顧客音声が英語誤認識。
- 補完に **6月事前診断110件**（属性・悩み・理想の自己申告）。

## 1. 実際に来ている人（属性の横断像）
- 30代前半〜40代前半の女性。子持ち（育休・専業・時短）と独身が混在。
- 本業は専門職（美容師・歯科衛生士・看護師・薬剤師・銀行員）／事務／専業主婦／医療系。
- **SNSは「見る専」がほぼ全員**。発信・運用の実務経験はほぼなし（例外：水谷＝既に運用代行）。
- 共通動機：「本業一本の不安」「収入をもう一つ」「在宅で子と時間」「スキルない自分への不安」。
- 金額欲求は控えめ（"月3〜5万でも""あればいいな"が多数）。＝**切迫した金欠より"漠然とした将来不安"が主動機**。

## 2. セグメント別：止まっている理由 → 引き上げる投稿

### ● 入会（松井美穂／育休中・美容師）
- 決め手：**「守りたいもの」が明確**（美容師は続けたい・収入水準は下げたくない・貯金・海外旅行）＋**時間制約が明確**（1日2h）→ カウンセラーが"時間内で回るレベル1＝投稿制作代行"に一点集中で提案でき、動画編集/Webデザインを「時間が足りず挫折する」と外せた。旦那（IT系）の巻き込みも促した。
- **引き上げ投稿の型**：「守りたいもの × 少ない時間で回る具体像」。同属性（育休/専門職ママ）の実例。→ 6月の**育休note**が刺さった構造とまったく同じ。

### ● 検討中・体験待ち（"あと一歩"層：町田・松本和子・磯部・竹内・水谷・東）
止まっている理由（複数該当）：
1. **時間確保の壁**（東＝平日不可・土日のみ／磯部＝扶養内・幼稚園）
2. **再現性・成果への不安**（水谷＝既に他スクールで1年やって伸びず「半年で本当に結果出る？」）
3. **料金ネック**（分割・回収イメージ）
4. **「スキル・センスがない」不安**（松本＝6年ブランク自信なし／竹内＝Webデザインは"センス"で挫折）
5. **既存スクールとの比較**（水谷）／**過去の詐欺スクール勧誘トラウマ**（町田）

**引き上げ投稿の型**：
- 再現性 → 「**同属性卒業生の"使える時間別 × 半年での結果"の実例（数字つき）**」。※7月頭に出した卒業生実績（Before/After・月17万/60万等）はこの層に直撃。もっと"時間が少ない人"の実例を増やすと刺さる。
- 不安解体 → 「**センス・スキル不要／未経験の実像**」「**詐欺スクールの見極め方＋上場企業グループ（ベクトル）**」※6/26で発信済み・好反応。
- 時間 → 「**1日1〜2h／土日だけでも回る**」具体像。
- 迷い（副業か転職か＝東） → 「**付けたスキルは転職にも効く**」の両取り訴求。

### ● 未入会（"温度低め・目的ふわっと・特典目当て"層：江部・長松・山下）
共通パターン：
1. **目的が"ふわっと"・締切なし**（江部＝「あればいいな」／長松＝「ふわっと副業」）
2. **SNS・発信自体への苦手意識 → 消去法で選択**（長松＝「発信者の選択肢がないんで消去法」／東も発信は「やりたいと思われない」）
3. **特典（note）目当ての側面**（山下＝「**一番のきっかけは絶対もらえるノート**」と明言）
4. **本業に別の解がある**（山下＝事務方管理職に昇進の道／江部＝本業が好きで安定）

→ これが当初仮説「**6月は特典訴求で浅い層が増えた**」の実像。全員もらえるnote特典が間口を広げ、"情報収集の延長・特典目当て・目的ふわっと"層まで申込に流入した。

**引き上げ投稿の型**：
- "ふわっと"を"自分ごと"に変える → 「**このまま3年後どうなる？**」の危機の具体化（6月ストーリーの「10年後大丈夫そう?」「NISA貧乏」が該当。属性別に解像度を上げる）。
- **発信したくない層の受け皿を明示** → 「**発信しなくてもできる裏方（運用代行・オンライン秘書）の実像**」。※ここが今**手薄**。長松・東・磯部はここが分かれば残った可能性。
- 特典で終わらせない導線 → note内で「カウンセリングは作戦会議」に接続（実施済み）。ただし温度低め層は**申込"前"の教育の厚み**が効く。

## 3. まだ顕在化していない共通の悩み（投稿で"先回り"できる）
- **「自分が何に向いてるか分からない」**（ほぼ全員の根底）→ 自己分析・向き不向きの見つけ方コンテンツ。
- **「頑張ってるのに成果が出ない」構造への無自覚**（松井のカウンセラーが使った"ランニングで痩せない＝時間の使い方"の比喩が秀逸）→ 「時間の使い方／少ない時間で成果を出す設計」投稿。
- **「在宅仕事は向こうから来ると思ってた」誤解**（松本・磯部）→ 「仕事の取り方」の実像（楽天ROOM noteの延長）。

## 4. 全体3項目（発信設計の視点で）
1. **入会 vs 未入会の差分と埋め方**
   - 差分：入会は「守りたいもの＋締切感＋時間の見通し」が具体。未入会は「目的ふわっと＋SNS苦手＋特典目当て」。
   - 埋め方：申込前後の投稿で①危機の自分ごと化（締切感）②同属性の成功実例（できる感）③発信しない働き方の提示（苦手の解体）を厚くする。
2. **CVできるカウンセラー vs 失注**（※サンプル小・参考）
   - 宮田（松井を入会）：時間制約に合う"レベル1"へ即・一点集中で絞り込む提案が上手い。
   - 阿久津：6件担当で入会0（体験待ち3/検討1/未入会2）。ただし送客された層の温度が低かった可能性が高く、カウンセラー要因と断定不可。
   - 発信設計の示唆：**"温度を上げてから送客"すればどのカウンセラーでもCVは上がる**。入口の特典より、教育投稿の厚みがCVを左右する。
3. **お客様に刺さるトーク・エピソード**
   - 「センス・スキル不要」「完璧じゃなく"とりあえず"で進める人が最強」「少ない時間でも回る」「詐欺の見極め」「守りたいもののために"余裕があるうちに"準備」。
   - 30代ちゃんの一次体験（会社員時代に準備した／離婚のために/従姉妹に1からやらせた実例）が最も強い。**"実体験×数字"が刺さる**。

## 5. 投稿テーマ提案（優先順）
1. **同属性卒業生の"時間別×半年結果"実例集**（育休ママ/専門職/時短/独身…属性ごとに）← 再現性不安に直撃
2. **「発信しない働き方」特集**（運用代行・オンライン秘書のリアルな1日／仕事の取り方）← 未入会の"SNS苦手・消去法"層の受け皿（今手薄）
3. **「向いてる副業の見つけ方」自己分析コンテンツ** ← 全員の根底「何が向いてるか分からない」
4. **「頑張っても成果が出ない人の時間の使い方」**（ランニング比喩）← 過去スクール挫折者に効く
5. **「このまま3年後どうなる？」属性別の危機の自分ごと化** ← 温度低め層を締切感へ
6. **詐欺スクール見極め＋上場企業グループの安心**（継続）← 不信・比較検討層
