# HM カウンセリング分析サマリー

## この分析でわかること（先に結論）
- 来ている人の典型像＝**20代後半〜30代・出会いが少ない環境・アプリや自力に疲れ・年齢/周囲の結婚で焦っている女性**。
- 申込の本当の動機は広告ではなく、**「取り残される恐怖・年齢リミット・婚活疲れ」という背景圧力 ＋ 直近の点火イベント（破局・関係の停滞・親の病気）**。
- 響くのは結婚テクニックより **「焦りの言語化 → 数字での逆算（30歳まで/出産リミット）→ 具体的行動」**。

## データの前提
- **定性**＝恋愛・結婚カウンセリング**8名（n=8）**の文字起こし（悩み・理想・トリガーを精読）。※個人名は伏せ、事例A〜Hで表記。

- 出所は「診断LP／SNS・Instagram無料診断」経由の新規カウンセリング。

## ④ トリガー構造（3層）
```
[層3 背景圧力] 年齢リミット・周囲の結婚・婚活疲れ・孤独恐怖   ← 常に燻っている
      ＋
[層2 点火イベント] 破局・関係の停滞・親の病気・アプリの失望   ← 「今」動いた理由
      ＋
```

  - 特定の相手で停滞：F・H
  - **親の病気で人生見直し：G**（＝家族のライフイベントは非常に強い着火点）

## ⑤ ペルソナ（8名→4タイプ）
1. **「好きがわからない」自己理解未満型**（A・C）：理想がふわっと、恋愛感情が不明。孤独恐怖が動機。→ 言語化支援が刺さる。
2. **「特定の相手で足踏み」型**（E・F・H）：現在or直近に相手がいるが温度差・本心が見えず決めきれない。→ 相手軸でなく“自分軸”の整理。
3. **「傷リカバリー」型**（B）：破局の傷で消耗、次は失敗したくない。→ 共感と“行動で示す誠実さ”の再定義。
4. **「タイムリミット着火」型**（D・G）：年齢や親の病気で人生を考え直し、諦めと焦りの綱引き。晩婚未着手も含む。→ 数字の逆算＋“今動く”後押し。

## ⑧ 入会の決め手と、入会を阻むブロック
### 入会・前向きになった人の共通点
- **過去に明確な失敗経験**（婚約破棄・遠距離破局・浮気・離婚）→「もう繰り返したくない」が原動力。
- 面談で**「自分一人では出てこなかった理想が言語化できた」体験**（唯一の入会者33歳の決め手）。
- **危機感の数値化**（29歳と30歳の違い／35歳までの出産）で納得。
- **2回目面談・体験でステップを刻む**と警戒が下がり前進（体験ワーク待ち＝この型）。

### 入会を阻むブロック（＝何を補填すれば入会するか）
| ブロック | 具体（記述より） | 補填策 |
|---|---|---|
| **再現性への不信** | 「本当に変われるか不安」「過去コーチング/相談所で変われなかった」 | 実績・ビフォーアフター・再現性の証明 |
| **即決できない** | 「一旦冷静になりたい」「焦りたくない」「即決できず体験」 | 体験・2回目面談・ロードマップ提示（既に有効） |
| **金銭的優先度** | 「金銭的に優先度を上げられず失注」 | 価格の見せ方・支払い柔軟性 |
| **自力志向/競合比較** | 「自力でダメならお願い」「似たサービスと同時進行」 | 自力の限界提示＋差別化 |
| **変化意欲なし** | 「変わりたいと思わない」「このままでいい」 | 追わない（CV対象外） |
- 注意：記述に**「CVしてはいけない層」**（会話が成立しない/精神的に不安定/理想が非現実的）が複数。無理に追わない線引きが必要。

## ⑩ 示唆
- **最大の課題は成約前のキャンセル**（確定27件中48%、当日6件）。予約〜実施のリマインド設計・当日離脱防止が、面談内容の改善より先に効く可能性が高い。
- **リードスコアリングが有効**：事前アンケートの〈結婚希望＝1年以内〉×〈期待＝理想の相手を見つけたい〉は前向き層と強く相関。この層を優先枠・手厚い事前接触に回す。
- 温度が低い層（数年以内／課題を客観視したい）はキャンセル・未入会が多い。切り捨てずに、**"数年以内→今動く理由"を作る逆算トーク**（年齢・出産リミットの数値化）で引き上げる。
- 伸ばすなら**層3（取り残される恐怖・年齢リミット・婚活疲れ）を言語化する訴求**。「親の病気で人生を考えた」等のライフイベント文脈も強い。
- 未入会/検討中の壁は「理想ふわっと型」「特定の相手で足踏み型」「傷が生々しい型」で分岐。追客・トークを型別に設計。
- 次の一手：**キャンセル者の属性分析**（誰が飛ぶか）と施策への落とし込み。
