# 気づき：予約特典2本の比較（成功 vs 不調）

**結論サマリー**：成功した26_2(ハーテック)は「在宅で稼ぐ」で入口が広く・視座が低く・収益の仕組みと到達点が具体。不調の26_6(スキルスキップ)は「AIで時短発信」で入口が狭く・視座が高く・収益の仕組み/ママ理由/商材への橋渡しが欠落。**次回特典は26_2の型に寄せる**。

| 観点 | 26_2 ハーテック（成功◎） | 26_6 スキルスキップ（不調△） |
|---|---|---|
| 訴求の入口 | 在宅ワーク＝稼ぎたい（母数広い） | 発信したい人（母数狭い） |
| 視座 | 低い（〜とは/始め方から） | 高い（いきなり"売れる/売れない"） |
| 収益の仕組み | あり（報酬率2%・ランク・収益例¥140） | ほぼ無し（1行だけ） |
| ママにおすすめの理由 | 専用セクションで3つ提示 | 無し |
| 到達点（天井） | 月3〜40万のハシゴ＋実例で見える | 金額・到達像がほぼ無い |
| 証拠（数字/実例） | 多い | ほぼゼロ |
| 商材への導線 | 締めにHerTech勉強会をさらっと | 第11章で唐突に「予約キャンセルしないで」 |
| 軸の一貫性 | タイトル→中身→締めが一直線 | AI時短→プロンプト→スキルスキップで3回ブレ |

## 弱点の詳細（26_6＝直すべき点）
1. **入口が「発信訴求」で狭い** → 副業/在宅ワーク訴求に変えれば母数が広がる。AI時短は"手段"で"動機"ではない。
2. **視座が高い** → 「なぜ売れにくいか(第2章)」は未着手の人には早い。まず収益化の仕組みから。
3. **収益化の仕組み説明が無い** → 報酬率・成果報酬・ランクなど「どう稼げるか」を26_2並みに。
4. **ママにおすすめの理由が無い** → スキマ時間/日常がコンテンツ/共感 等の"なぜママか"を追加。
5. **スキルスキップへの架け橋が無い** → 本文はAI発信ノウハウ、商材はSNS運用代行(=発信しない働き方)。両者を繋ぐ橋渡しが必要。第11章の引き止めは"守り"で逆効果の懸念。
