# はあちゅうさんの型（ローンチ構造）

元にしたもの：8月ローンチ（予約60・入会率32%）、10月本キャンペーン（予約率62%→32%に低下）、10月延長（3日間の教育で目標10予約→20予約）
8月を基本形、延長を短縮形、10月を「抜けると何が起きるか」の確認に使っている。

## サマリー

1. 流れは、期待値を上げる→自分にもできそう→相談会を受ける理由、の順。特典は相談会の条件として最初から一緒に見せる
2. スキルスキップの名前と相談会は、教育の初日から出す。配布後に初めて出すと、特典目当ての人が予約まで進まない（10月）
3. 期待値は2段階で上げる。稼げる仕組み（一番手前から）→その先の楽しみ（スキルを掛け合わせた先）
4. 実績は段階で見せる。フォロワーと同じスタート地点の人の小さな金額→大きな金額→本人の実績
5. 予約前に目的を言語化させる（何に使いたい？）。これが実施率を支えている

## 2. 各要素の中身

### ① 期待値を2段階で上げる

| 段階 | 何を見せるか | 実例 |
| --- | --- | --- |
| 1段目：稼げる | お金が入る仕組みを一番手前から説明する。どれくらい入ると思う？と問いかける | 紹介料は2〜4%、特別に20%の商品も／セールは普段の5倍売れる／12月はボーナスと年末の買い物が重なる |
| 2段目：その先の楽しみ | スキルを掛け合わせると、仕事の幅が広がる | 企業から商品が届く、サンプル、旅行に招待／企業の投稿を作る仕事、PR案件（投稿1.5万＋成果1件2万） |

- 一番手前から説明したことで、ストーリーズ1枚目の閲覧数が405→694に上がった（延長）
- 10月は仕組みを飛ばして応募文の書き方から入り、仕事のイメージがつかなかった

### ② 実績は段階で見せる

| 順番 | 誰の実績か | 実例 |
| --- | --- | --- |
| 1 | フォロワーと同じスタート地点の人 | フォロワー0の知人が2投稿で3,975円 |
| 2 | 同じ人のその後 | 売上279,893円、成果報酬8,198円 |
| 3 | 本人 | 楽天ROOM歴12年・ランキング1位、自分も売れない壁にぶつかった |
| 4 | 本人の身近な卒業生 | 手伝ってくれているママ、パソコンも使えないところから月28万 |
| 5 | 受講生 | 育休中から始めて月25万、受講中に累計約30万 |

- 10月は28万の一点だけで、時間軸がなく遠すぎた。その人が特別だったのでは、と思われやすい

### ③ 目的を言語化させる

- 質問箱で「収入が増えたら何に使いたい？」→回答を並べて紹介→本人の体験（息子との思い出、子どもと過ごせる時間は7年半）
- 配布の約2週間前から始めている。予約の直前ではない
- 予約後は「事前診断に答えると、カウンセラーが最適解を準備してくれる」で事前診断につなぐ

### ④ スキルスキップの信頼

- 肯定の形で出す：上場企業のグループ、何年も一緒に仕事をしている会社、手伝ってくれているママが卒業生
- 10月の「決して怪しいスクールではありません」（否定の形）は、かえって不安を植える
- 「今回も協力してもらいました」は前回を知っている人向けの言い方。初めての人にもわかるように説明し直す

### ⑤ 相談会を受ける理由

| 言い方 | 実例 |
| --- | --- |
| どんな場所か | 決断する場所ではなく、自分に合う働き方を見つける場所 |
| 何をするか | 今までの仕事や得意なこと、理想の働き方、使える時間、向いている仕事を整理する |
| 特典とつなぐ | 楽天ROOM×〇〇の〇〇は人それぞれ。相談会で自分に合う〇〇を見つける |
| なぜセットか | 楽天ROOMはきっかけ、相談会はこの先の計画を立てる時間 |
| 受けた人の声 | 卒業生ママの長文DM（話を聞いてもらってビジョンが明確に）、運用代行が向いているとわかった |

### ⑥ 締切と枠の使い方

- 開始時点から先着◯名と枠を出す（延長）
- 予約数を速報で出す（5分で3件→10分で8件→32→35→39）
- 枠が埋まったら一度「満席」で区切り、時間を空けて増枠する
- 最終日は残り時間（6時間、3時間）と残り枠（7名、5枠）を小刻みに
- 「本当に最後」は温存し、言ったらそれ以上延長しない

### ⑦ 低意欲層を絞る

- 本気で1万円でも増やしたい人限定／過去に受け取っても実践しなかった人が多かった
- 楽天ROOMだけでは限界で、成果を伸ばすならスキルの掛け合わせが大事
- 絞ったことで、LINE追加は減ったが予約率が上がった（6月：93追加→56予約、8月：56追加→63予約）

## 3. 抜けると起きること（10月・延長の反省）

| 抜けたこと | 起きたこと |
| --- | --- |
| 教育でスキルスキップと相談会を出さなかった | 予約率が62%→32%。特典目当てで追加した人が、相談会が条件だと知って止まった |
| お金が入る仕組みを説明しなかった | 仕事のイメージがつかず、最初の一歩が重く見えた |
| 特典を一人で完結できるように見せた | 相談会に行く理由が弱くなった |
| 実績が一点だけ | 遠すぎて、自分ごとにならなかった |
| 教育とnoteで想定読者がずれた | 会社員向けのnoteに、会社員0人が集まった |
| 枠を埋めることを優先した（延長） | 着席のうちRG違反が40%、「時期をみて始めたい」が56%に増えた |
| 締切後に入会とキャンセルの話が続いた（延長） | 絞り込みすぎの懸念。締切後は、相談する理由と相談するとどうなれるかを中心にする |
