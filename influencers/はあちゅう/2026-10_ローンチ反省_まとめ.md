## 2. 課題

### 課題A：スキルスキップと相談会が、事前教育で一度も出ていない（最重要）

| | 8月 | 10月 |
|---|---|---|
| スキルスキップの名前 | 配布の20日前（コラボ発表の初日） | 配布当日・配布開始後に初めて |
| 「コラボ決定」の告知 | 配布の20日前 | 配布の翌日 |
| お手伝いママが卒業生であること | 初日から出している | 出ていない |
| 特典はスキルスキップのプロと作った | 配布までに繰り返し | なし |
| 信頼の出し方 | 上場企業ベクトルのグループ、母体が分からないスクールは紹介しない（肯定の形） | 「決して怪しいスクールではありません」（否定の形で、かえって不安を植える） |
| 相談会の説明 | 配布の2日前に前向きに説明 | 配布の翌日に「言い忘れてましたが」の流れで |
| 相談会を受ける理由 | 「楽天ROOM×〇〇の〇〇は人それぞれ」、動画編集を次の選択肢に | 配布前はなし |
| 相談会を受けた人の声 | 卒業生ママの長文DM | なし |

- 8月の勝ち筋（スクール名を配布20日前に出す）が抜け、6月と同じ構造（配布後に相談会が出てくる）に戻った
- 「今回もスキルスキップに協力してもらいました」は、前回を知っている人向けの言い方
- 予約率が62%から32%に下がったのは、特典目当てでLINEを追加した人が、相談会が条件だと知って予約まで進まなかった可能性が高い

**要確認：なぜ打ち出さなかったのか**
- 事前教育の台本は誰が、いつ作ったか。8月の成功要因は共有されていたか
- はあちゅうさん側に、スクール名を早く出したくない意向があったか
- 特典の企画（お手伝いママを主役にする）が先に決まり、スキルスキップとのつながりが後回しになったか
- 相談会を特典の条件にすると決まったのはいつか

### 課題B：仕事のイメージがつかず、最初の一歩が重い

| | 8月 | 10月 |
|---|---|---|
| お金が入る仕組み | 楽天ROOMの紹介料の仕組みを説明してから、やり方へ | 投稿作成代行がどんな仕事か、誰から依頼が来て、いくらになるかを飛ばして応募文へ |
| 最初の一歩 | 0円、フォロワー0、1日5分〜、忙しい日は5分でOK | 探す→応募→契約→納品と、仕事を受けるまでの全工程 |
| 訴求の中心 | 楽天ROOM（お金が入る場所そのもの） | 投稿テンプレート、1枚目の作り方（仕事をするための道具＝手段の手段） |
| 特典の見せ方 | 楽天ROOMは入口、その先はスキル | 「どこで探し、何を準備し、どう応募するかが明確に」と、一人で完結できる見せ方 |

- 「ママは普通だけでも大変なのに、そこにプラスでお金を作るのは大変すぎ」と思われやすい
- テンプレートがなぜ仕事につながるのか（企業は投稿を外注している→1枚作れれば応募のサンプルになる）がつながっていない。6月の「AIで時短」と同じ構造
- 特典だけで足りるように見えるため、相談会に行く理由が弱くなる

### 課題C：実績が「28万」の一点だけ

| | 8月 | 10月 |
|---|---|---|
| 金額の見せ方 | 段階的：2投稿で3,975円→売上279,893円→成果報酬8,198円 | 281,735円のみ（複数回） |
| 誰の実績か | 知人（フォロワーと同じスタート地点）、特典の実践者、受講生、卒業生ママ | お手伝いママ1人 |
| 時間軸 | 検証の過程を6日間で見せた | 「4か月で初仕事」は出ているが、そのときの金額がない |

- 281,735円は2年半続けた結果。時間軸なしで「30万弱の収入を得る方法」と並べると、誇大に見えるリスクがあり、未経験の人には遠すぎる
- お手伝いママ以外の実績がないため、「その人が特別だったのでは」と思われやすい

### 課題D：教育とnoteで、想定している人がずれている

| | 8月 | 10月 |
|---|---|---|
| ターゲットの切り方 | 働き方では絞らず「収入を増やしたいママ」全般。DMも専業・育休・パート・シングル予定と幅広い | 問題提起の主語が「正社員を辞めてパートに」「専業主婦だとして」 |
| noteの想定読者 | − | 「会社の仕事と子育てをしながら」と会社員向け |
| 集まった人 | 会社員34%・パート21%・専業主婦16%・医療職14% | 会社員0人、パート4人・専業主婦2人（9人中） |

- 10月の予約者は手取りの中央値8万円、貯金0円が5人、費用の不安を書いた人が2人。入会の段階で金銭面が壁になりやすい
- 外で働けない事情（子どもが多い、不登校・療育）がある人が多く、使える時間は8月より長い
