### 振り返り（8月との比較）

**1. スキルスキップのコラボを、事前教育で打ち出していない（最重要）**

8月は配布の20日前のコラボ発表で、スキルスキップの名前、上場企業グループであること、仕事を手伝っているママが卒業生であることを出し、配布までに「特典はスキルスキップのプロと作った」と繰り返していました。10月は事前教育で一度も名前が出ず、初めて出たのは配布当日の配布開始後、「コラボ決定」の告知は配布翌日でした。信頼の出し方も「決して怪しいスクールではありません」と否定の形で、かえって不安を植えています。8月で入会率に一番効いた要素が抜け、6月と同じ構造に戻ったことで、特典目当てでLINEを追加した人が、相談会が条件だと知って予約まで進まなかった可能性が高いです（予約率62%→32%）。

| | 8月 | 10月 |
| --- | --- | --- |
| スキルスキップの名前 | 配布の20日前 | 配布当日・配布開始後 |
| お手伝いママが卒業生であること | 初日から出している | 出ていない |
| 特典はスキルスキップのプロと作った | 配布までに繰り返し | なし |
| 信頼の出し方 | 上場企業グループ、母体が分からないスクールは紹介しない（肯定の形） | 「決して怪しいスクールではありません」（否定の形） |

**2. 相談会を受ける理由を作れていない**

8月は「楽天ROOMの成果を伸ばすなら、他のスキルとの掛け合わせが大事」「楽天ROOM×〇〇の〇〇は人それぞれ」と、特典だけでは足りない理由を伝え、動画編集を次の選択肢として置いたうえで、相談会を「自分に合う働き方を見つける場所」と説明していました。卒業生ママの長文DMで、相談会を受けた人の声も見せています。10月は配布前にこのどれもなく、特典も「探す→応募→納品」まで一人で進められる作りだったため、相談会に行かなくても足りるように見えていました。

**3. 問題提起から「稼ごう」へのつなぎが急すぎる**

8月は問題提起を軽め（物価高、夏休みの出費）にして、「収入が増えたら何に使いたい？」→子どもとの今しかない時間→「月1万円でも」と、理想と小さな一歩につないでいました。10月は「ママばかり負担が大きい、時間もお金もない」と強く共感させたあとに、「なら、自分で作りませんか」「今の仕事にプラスで」と、ママにもう一つ負担を足す形でつないでいます。「社会が変わるのを待っていられない→自分で変えられるのは働き方とお金→家で働けば急な発熱にも対応できる→そのうえで自分のお金を持つ」と、稼ぐことを問題提起への答えとして出せれば、自然につながったはずです。

| 段階 | 伝えること（こうつなげればよかった案） |
| --- | --- |
| ① 問題提起（共感） | ママばかり休む、辞めてパートになる、お小遣いもない |
| ② はあちゅうさんの意見 | おかしいと思う。でも、社会が変わるのを待っていたら、子どもはあっという間に大きくなる |
| ③ 自分で変えられるもの | 制度は変えられないけど、自分の働き方と、自分で使えるお金は変えられる |
| ④ 働き方を置き換える | 家で働ければ、急な発熱にもすぐ対応できる。通勤の時間が、作業の時間になる |
| ⑤ 稼ぐ | そのうえで、誰にも気をつかわずに使える自分のお金を持つ |
| ⑥ 小さな一歩 | 最初から大きく稼がなくていい。最初のお仕事は◯円から |

**4. 最初の一歩が重い**

8月は、初期費用0円・フォロワー0・1日5分〜と最初の一歩を極端に小さく見せ、知人の最初の成果も2投稿で3,975円という小さな金額で見せていました。10月は特典の中身が「探す→応募する→契約する→納品する」という仕事を受けるまでの全工程で、見せた金額も281,735円だけ、「簡単とは言いません」と大変さの方が前に出ています。普段から忙しいママには、始める前から重く見えやすい内容でした。

**5. 仕事のイメージがつかないまま、やり方の話に入っている**

8月は「おすすめ商品を投稿する→見た人が買う→紹介料が入る」と、お金が入る仕組みを説明してから、やり方の話に入っていました。10月は「投稿作成代行とはどんな仕事か」「誰からどんな依頼が来て、1件いくらになるのか」を飛ばして、応募文の書き方から入っています。訴求の中心も投稿テンプレートや1枚目の作り方という道具（手段の手段）で、それがなぜ仕事になるのかがつながっておらず、6月の「AIで時短」と同じ構造になっていました。

**6. 実績が28万円の一点だけで、遠く見える**

8月は知人の2投稿で3,975円→売上279,893円→成果報酬8,198円と段階的に見せ、特典の実践者・受講生・卒業生ママと複数の実績を重ねていました。10月は事前教育で見せた金額がお手伝いママの281,735円だけで、これは2年半続けた結果です。最初の金額や途中の金額がなく、ほかの人の実績もないため、未経験の人には遠すぎて「その人が特別だったのでは」と思われやすい見せ方でした（初任給29,645円は配布期間中に追加）。

**7. 問題提起とnoteで、想定している人がずれている**

8月は働き方では絞らず「収入を増やしたいママ」全般から入り、会社員34%・パート21%・専業主婦16%と幅広く集まりました。10月は問題提起の主語が「正社員を辞めてパートに」「専業主婦だとして」で、予約者も会社員0人、パート・専業主婦が中心になりました。一方でnote本体は「会社の仕事と子育てをしながら」と会社員向けに書かれていて、届いた人とずれています。予約者は手取りの中央値8万円、貯金0円が9人中5人と、入会の段階で金銭面が壁になりやすい層でもあります。
