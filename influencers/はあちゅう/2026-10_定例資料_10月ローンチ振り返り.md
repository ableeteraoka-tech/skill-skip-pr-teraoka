#### ③ 問題提起から「稼ごう」へのつなぎが急

**8月：問題提起は軽め。すぐ理想と小さな一歩につないでいた**
- 問題提起：物価高で、2〜3年前と同じ生活でも数万円多くかかる。夏休みは食費や光熱費、お出かけ代がかさむ
- つなぎ：「収入が増えたら何に使いたい？」→回答を紹介→息子との今しかない時間→「月1万円でも、子どもの今に使うお金を増やす方法を教えたい」

**10月：問題提起は強い。そのまま「自分で作ろう」に飛んでいる**
- 問題提起：「もう自分に使う時間がない」、女性だけにかかる出費、子の急な発熱で休むのはママ、出産後に辞めてパートへ、お小遣いなし
- つなぎ：「なら、自分に使えるお金、自分で作りませんか？」「今の仕事にプラスで収入UPができるかも」→応募文の話へ
- 「ママばかり負担が大きい」と共感させたあとに、「さらに自分で稼ごう」とママに負担をもう一つ足す形になっている

**こうつなげればよかった（案）**

| 段階 | 伝えること |
| --- | --- |
| ① 問題提起（共感） | ママばかり休む、辞めてパートになる、お小遣いもない |
| ② はあちゅうさんの意見 | おかしいと思う。でも、社会が変わるのを待っていたら、子どもはあっという間に大きくなる |
| ③ 自分で変えられるもの | 制度は変えられないけど、自分の働き方と、自分で使えるお金は変えられる |
| ④ 働き方を置き換える | 家で働ければ、急な発熱にもすぐ対応できる。通勤の時間が、作業の時間になる |
| ⑤ 稼ぐ | そのうえで、誰にも気をつかわずに使える自分のお金を持つ |
| ⑥ 小さな一歩 | 最初から大きく稼がなくていい。最初のお仕事は◯円から |

- 「稼ぐ」を負担の追加ではなく、問題提起（自分に使えるお金がない）への答えとして出す
- ②は読者を責める形にせず、はあちゅうさん自身の意見として言う。本人もすでに「世の中を変えるのは難しい。なら自分を変えるしかない」「不平不満を言っていても何も変わらない」と発信している

#### ④ 最初の一歩が重い

**8月：最初の一歩を極端に小さく見せていた**
- 初期費用0円、フォロワー0でもOK、写真もいらない、スキマ時間でできる
- 「1日5分〜、30日間」「忙しい日は5分でこれだけやればOK」と、時間の負担を具体的に小さくした
- 知人（楽天ROOMが初めて・フォロワー0）が2投稿で3,975円。最初の成果を小さな金額で見せた
- 動画編集などの次のスキルは「今はできなくてもOK、まずは楽天ROOMから」と、一度引いてから置いた

**10月：最初の一歩が「お仕事を取る」になっている**
- 特典の中身が、探す→応募する→契約する→納品する、と仕事を受けるまでの全工程
- 見せた金額が281,735円だけで、最初の一歩の小ささが見えない
- 「本気になれば実現可能」「簡単とは言いません」と、大変さの方が前に出ている

**まとめ**：8月は「5分でできる最初の一歩」→「その先はスキル（相談会で）」の順。10月は最初から「仕事を受ける」話なので、忙しいママには重く見えやすい。

#### ⑤ 仕事のイメージがつかない

**8月：お金が入る仕組みを説明してから、やり方へ**
- 楽天ROOMの仕組み：おすすめ商品を投稿する→見た人が買う→紹介料が入る（「このフライパン軽くて使いやすかった」のような具体例つき）
- そのうえで、なぜ売れないのか（見てもらえない）→解決策（Threadsとの掛け合わせ）→知人の結果、の順で見せた

**10月：仕事の話を飛ばして、応募文へ**
- 問題提起→お手伝いママの紹介→応募文の書き方とクイズ→振込281,735円→特典の告知
- 「投稿作成代行とはどんな仕事か」「誰から、どんな依頼が来るのか」「1件いくらで、どれくらい時間がかかるのか」が、ストーリーズではほぼ出ていない
- 訴求の中心が投稿テンプレートや1枚目の作り方（仕事をするための道具＝手段の手段）。それがなぜ仕事につながるのか（企業やお店はSNSの投稿を外注している→1枚作れれば応募のサンプルになる）がつながっていない。6月の「AIで時短」と同じ構造

**まとめ**：「自分にもできそう」と思う前に、仕事そのものがイメージできていない。次回は「仕事（お金が入る場所）」を先に見せ、テンプレートは「その仕事を始めるための道具」として後から出す。

#### ⑥ 実績が28万の一点だけ

| | 8月 | 10月 |
| --- | --- | --- |
| 金額の見せ方 | 段階的：2投稿で3,975円→売上279,893円→成果報酬8,198円 | 281,735円のみ（3回出している） |
| 誰の実績か | 知人（フォロワーと同じスタート地点）、特典を使った人、スキルスキップ受講生、卒業生ママ | お手伝いママ1人 |
| 時間軸 | 検証の過程を6日間で見せた | 「4か月で初仕事」は出ているが、そのときの金額はない |

**まとめ**：281,735円は2年半続けた結果なので、未経験の人には遠すぎる。お手伝いママ以外の実績もないため、「その人が特別だったのでは」と思われやすい。次回は、最初の金額→途中の金額→今の金額の段階と、ほかの受講生の実績をセットで見せる。

#### ⑦ ターゲットと想定読者がずれている

**8月：働き方では絞っていない**
- 入口は「収入を増やしたいママ」全般。「あといくら収入を増やしたい？」のアンケートから始めている
- 紹介したDMも、専業主婦、育休中で職場復帰に悩むママ、パートで小学生の子がいるママ、シングルになる予定のママ、と立場がばらばら
- 共通していたのは働き方ではなく、「子どもとの今しかない時間」「収入が増えたら何に使いたい？」という気持ちの部分
- 結果：会社員34%・パート21%・専業主婦16%・医療職14%と、幅広く集まった

**10月：問題提起でパート・専業主婦に寄り、noteは会社員向け**
- 「出産後に正社員ママが辞める→パートで働くママが増える→収入が減る」「例えば今、専業主婦だとして」と、正社員を辞めた後の人を主語にした問題提起が続いた
- 一方でnote本体は「会社の仕事と子育てをしながら」「平日日中は本業」と、会社員向けに書かれている
- 結果：会社員0人、パート4人・専業主婦2人・無職と教職員が1人ずつ（9人中）。手取りの中央値は8万円、貯金0円が5人、費用の不安を書いた人もいる

**まとめ**：ターゲットを明確に指定していたわけではないが、問題提起の主語でパート・専業主婦に寄った。教育とnoteで想定している人もずれている。入会の段階で金銭面が壁になりやすい層。
