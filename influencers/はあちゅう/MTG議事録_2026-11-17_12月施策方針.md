## 🔹 話し合いの詳細

### 💡 1. 勉強会ではなく個別面談で行く

浅野さんが、勉強会にした場合の試算を出した。

```
予約 200人
 → 参加 60%（はあちゅうさんのフォロワー想定）＝120人
 → 個別面談予約 30% ＝ 36人
 → 着席 60% ＝ 21人（今回と同じくらい）
```

- 200人の予約が必要だが、スキルスキップの勉強会は毎日開催ではなく、やるとしても3日間程度
- ハーテックは毎日開催なので、日程が合わずに離脱することがない。日程を合わせてまで参加する人はかなり本気の層
- 予約特典という浅いフックから、勉強会参加、さらに面談予約という長い動線は、今の開催頻度とは合わない
- 年末という時期も重なる
- 鎌田さん：特典がまた楽天ROOMで新しさがなく、勉強会にしても成果までの道のりが長い

> 🔴 **結論：12月は個別面談で行く。** 勉強会は、安定して開催できるようになったら改めて検討する

### 💡 2. 特典はLINEスタンプではなく楽天ROOM

**LINEスタンプについて（鎌田さんの試作から）**

| 観点 | 内容 |
| --- | --- |
| 作り方 | よく出てくる作り方どおりにやると工数は少なく見せやすいが、ありふれたスタンプにしかならない |
| 売れるもの | 友達が買ったのは、おやじギャグのような「お疲れたす」にレタスとおじさんの画像があるだけのもの。売れるジャンルのリサーチが必要 |
| ジレンマ | 簡単に見せると実績が出ず埋もれる。深く入ると簡単さがなくなり響かない |
| AI | AI前提だが、以前AIの特典を配ったときは反響がよくなかった（寺岡：訴求があちこちに行ったのが原因で、調整すれば大丈夫そう） |
| 再現性 | 再現性がないので実績が出せない |
| 参考 | LINE絵文字のほうが今は売れるらしい（スタンプとしても文字中にも使える）。ただし60個近く作らないと売れにくい |

- 昨日の鎌田さんの申請は、娘さんの描いたイラストをスタンプ化したもの
- はあちゅうさんも、経験としてやってみてもいいかも、くらいの熱量だった

**楽天ROOMを推す理由**

- 楽天ROOMの紹介料率が上がる（20%）という訴求がよかった。12月から年始は購買意欲が一番高まる時期で、訴求と合う
- まだ始めていない人、やめてしまった人、前回特典を受け取ったけど止まっている人に、今が始めどきと伝えられる
- 新規を取りつつ、すでに持っている人にもう一度やってもらう

> ✅ **結論：特典は楽天ROOMで行く。** LINEスタンプは、せっかくなので出すくらいはよい（「やってみたらめちゃくちゃ難しかった」という見せ方で）。鎌田さんはLINEスタンプを引退し、楽天ROOMに集中

### 💡 4. 楽天ROOMの企画軸

**前提（浅野さん）**

- 「楽天ROOM完全ロードマップ」はすでに配布済みで新しさがない
- AIもやっている（ワンチャンはある）
- 投稿事例集は、楽天ROOMをやっている人しか興味がなく、視座が高すぎる
- 一番多いのは「これから楽天ROOMをやろうかな」と思っている層。その目線に合わせて、まだやっていない企画を作るのが大事

**12月〜1月のセール**

| 時期 | セール |
| --- | --- |
| 11月 | ブラックフライデー |
| 12/4〜12/11 | 楽天スーパーセール（PRの頃には終わっている） |
| 1/1〜 | 新春ポイントアップ祭、福袋 |

- 鎌田さん：自分は年末年始は出費が多く、いったん落ち着くタイプ。足りない物をリストアップして余力があれば買う。ただ、年始は楽天の初売りのストーリーズが多く、つられて買うことは多い
- 浅野さん：一般的には1月はとても買う時期。訴求として使える
- 寺岡：みんなが買っているイメージが湧けばよい。「1月のセール攻略×楽天ROOM」のような打ち出しもあり

**出たアイデア**

- 寺岡：延長の1週間でいろいろ詰め込んだ内容を、もう少し丁寧に出したい

**鎌田さんの気づき（なぜ自分は欲しくなったか）**

鎌田さんは、ある方のショート動画の教科書を「この間買えばよかった」とずっと思っている。その理由を考えていた。

```
コミュニティ感、周りの口コミ（同僚も買った）
 ↓
ローンチ後もずっと、特典や教科書の話をし続けている
 ↓
良いものだと刷り込まれていく
```

- はあちゅうさんは、普段の発信がたまに別の話題になって意識がずれ、ローンチの1ヶ月前くらいにまた楽天ROOMの話を始める。「あのとき受け取っておけばよかった」という熱が途中で一度崩れるのがもったいない
- 裏技の企画は、すでに始めている人には刺さる。始めていない人に始めたいと思わせる入口が、もう一つ欲しい
- やっていない人に向けて言えることは出し尽くした感じがあり、引き出しがない

**フォロワー層とSNS**

- 鎌田さん：フォロワーの中で発信している人は少ない。知り合いしかいないアカウントにアフィリエイトリンクを貼りたくない人も多い。だから、知らない人に買ってもらえるThreadsの新アカウントがはまった。アンケートでも、発信に興味はあるが顔出ししたくない人がいた
- SNSの話が入ると、楽天ROOMとやることが混ざって多く見える
- 寺岡：楽天ROOMだけで完結することを、ストーリーズしか見ていない人は知らないかもしれない
- 鎌田さん：特典の中では「もっと収益を上げるならSNSで発信」と書いているので、読んでいる人は理解しているはず。SNSで収益を上げる方法として動画編集やデザインも伝えている
- 浅野さん：楽天ROOMで収益化できることは分かっている。スキルを掛け算するとさらに上を狙えることを知らない人のほうが多い印象

> ✅ **方向性：鎌田さんが12月まで楽天ROOMをもう一度やり、その様子を同時進行で載せる。** 毎月の収益とやったことをまとめた特典（タイトル例：未経験から楽天ROOMを始めて12ヶ月の収益額とやったこと全部まとめました）。収益額を出すかは要検討。タイトル・内容はこれから考える

### 💡 6. 理想の置き方

- 浅野さん：収入がそこそこある人は、日常で我慢をしていない。浅野さん・鎌田さん自身も我慢していない（鎌田さんは欲しい物があまりない）
- 理想を書くとき、スパやネイルを出しても、それが理想でなければ響かない。我慢しない平凡な暮らしが理想なら、そこを理想に置く
- 寺岡：30代ちゃんの言葉を借りると「バランスよく」。すごく贅沢したいわけではないが、保護者会に着ていける服は買いたい。働きすぎも嫌だし、お金がないのも嫌
- 浅野さん：贅沢しすぎず、少し手を伸ばせば届きそうな未来を望んでいる
- 浅野さんのアンケート：月1で親を連れて旅行に行きたい、月1でディズニーに行きたい、など。この1年で理想のレベルが下がっている気がする
- 鎌田さん：ディズニーならホテル（ファンタジースプリングス、ミラコスタ）に泊まりたい、くらい
- 鎌田さん：前はできていたことを、もう一度普通に叶える、が理想になりつつある
- 他のIFの理想の作り方（寺岡）：オペレーターさんに聞いてもらって合わせる、事前診断から理想のレベルを見る、ヒーロージャーニーがあれば何を叶えたかったかを使う
- 浅野さん：はあちゅうさん本人は理想としては上すぎるので、視聴者に合わせた理想のほうがよい

> ✅ **前はできていたことを、もう一度普通に叶える**を理想として取り上げる

### 💡 7. 延長からの改善点（寺岡から）

| 改善点 | 内容 |
| --- | --- |
| 理想・暮らしの変化を入れる | 延長は楽天ROOMの20%などで押したため、感情を動かせず、RG違反も多かった |
| 変わった側の人の未来を見せる | 理想に加えて、実際に変わった人の未来 |
| 段階を丁寧に踏む | 楽天ROOMから発信者・運用代行への間が飛んでいた。運用代行と発信者は両方出す（浅野さん：どっちもかな） |
| 中間の実績を出す | 楽天ROOMの5,000円から、次がいきなり20万円に飛んでいた。月5万円、10万円の中間層の実績も出す |
| 緊急性を感情で作る | 物価の話や時間軸。クリスマスに子どもにあと何回プレゼントを買えるか、など |

**緊急性について（浅野さん）**

- 浅野さんがストーリーズで緊急性の訴求をしたら、反響がとてもよく、いろいろな人からDMが来た
- 「あと何回」は、誰かの死や要介護など、人がアクティブに動けなくなるときをイメージさせる。緊急性の訴求として一番強い（「死」という言葉は使わない）
- 例：親とあと何回旅行に行けるか、子どもが小学生ならあと何回一緒に旅行に行ってくれるか、お父さんと孫をあと何回会わせてあげられるか
- 浅野さん自身、リールを見て親とあと何回旅行に行けるか数えたら、あと5回くらいだった。10万円ちょっとのホテルを「高いしまあいいか」と言っていたのを、アップグレードした
- 回数を増やすにも、1回の質を上げるにもお金が必要。お金を使う・稼ぐきっかけになる

> 🔴 **緊急性の訴求が延長では足りていなかった。** 今回は感情で緊急性を作る
