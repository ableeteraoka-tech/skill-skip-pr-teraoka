# 【5月訴求note】夫に隠れて服を買ってた私が、おうちで月5万稼ぐまで💕

- 著者：maki（@maakkiii1144）／公開：2026年5月22日 10:17／スキ48
- 位置づけ：**5月コラボ（先行予約→ローンチ）のリードマグネットnote**。AI教科書（[訴求資料_AI特典note](訴求資料_AI特典note_Threads×ChatGPT月2万教科書.md)）と対をなす。

## 全体構造（型）
**自己開示の共感ストーリー → 悩みの顕在化・切迫化 → "家族も私も"の価値転換 → 在宅ワーク(SNS)の教育 → 発信者/運用代行の適性診断 → 運用代行＝本命の理由 → 他副業の否定(残酷な真実) → スキルスキップ紹介＋受講生実績 → 無料個別相談会オファー(豪華特典) → 面談前の"準備3質問"＋"変わる人/変わらない人"**。

## 1. 掴み（理想と欠乏の対比）
「毎月あと5万円あったら…」習い事を増やす・家族で外食・疲れた日にお惣菜・自分の服やコスメを罪悪感なく買える。「人生を変えるのに20万も50万もいらない、あと数万円の余裕で毎日の幸せは変わる」。

## 2. 悩みの顕在化（自己開示ストーリー）※訴求の核
- **夫に隠れて服・美容品を買い、タグとレシートをゴミ箱の奥に隠す**。「嬉しいより先に"ごめんね"が来る」。
- 3人育児＋掛け持ちパート。先輩ママの「高校と大学が重なる時期は正直地獄」で**数字で現実を突きつけられる**。野球のグローブ3〜5万・スパイク・すぐサイズアウト、次男サッカー、長女は今年大学受験。
- 旅行は毎月1〜2万積み立て、車で行ける範囲の安宿。「本当は海外にも連れて行ってあげたいのに」。
- **「私の人生って、もう終わっちゃったのかな」**。毎日の小さな「諦め」が積もる。
- 価値転換：**「家族が大事だからって、私の人生を消していい理由にはならない」「家族も、私も、欲張る人生にしたい」「子どもに"我慢"だけでなく"人生は広げられる"姿を見せたい」**。

## 3. 在宅ワークの教育（SNS運用代行が本命）
- maki自身の道のり：未経験・知識ゼロ→最初は時給0円、いいね3つ（全部友達）→1年以上継続でフォロワー増→企業案件5,000円→パート超え。
- **⭐手段の階層提示**：SNSの仕事は「発信者タイプ」と「運用代行タイプ」の2つ。**まず運用代行から入るのがおすすめ**（発信スキルを"お金をもらいながら実践で"身につく）。
- 運用代行の中身：リール編集・投稿作成・コメント/DM対応・分析レポート。相場1投稿1,000〜3,000円→10投稿で1〜3万＋レポート等で**月5万も目指せる**。実績を積むとアカウント任され月10〜20万、さらにコンサル/インフルエンサーで月20〜100万も。**「スタートラインは月5万を目指すのがおすすめ」**。
- 「月5万つくる運用代行者の一日」＝家事育児のスキマで全部スマホ完結（朝1時間で1投稿、昼はオフ、夜に軽作業）。
- おすすめ理由：①大手スクールは受講生実績から"正しい運用の仕方"が整い独学の遠回り不要 ②SNS需要は増え続け"スキル資産"になる（デザイン力・動画編集・継続力）。

## 4. 他副業の否定（残酷な真実）
「他の在宅ワークで今から月5万は難易度が高い」——YouTube/動画編集は応募待ち多数、ブログは結果まで半年〜1年、ネット販売/ハンドメイドは材料費・手間。→ **一番再現性が高いのがSNS運用代行**。ただし自己流は遠回り→"正しい環境"＝**スキルスキップ**。

## 5. スキルスキップ紹介＋受講生実績
- 魅力：専属コーチのマンツーマン・インスタ特化／コーチ陣（1万フォロワー以上＋採用試験合格）／受講者3000名以上／**3ヶ月で平均3万円の副収入**／200本以上の動画教材／24時間質問し放題／案件獲得サポートが手厚い。
- 実績例：Yさん 1,010円→9,200円→24,500円→**4か月目58,672円**＋継続案件2つ。／ちかママさん オンライン秘書＋ショート動画で**月5万達成**（幼稚園の間に動画1本2時間＋案件3件）。「情報が多すぎて何から始めればか分からない人は一度コーチに相談を」。

## 6. 感情の締め（もう遅いはない）
「人生でいちばん若い日は、今日」「もう若くない/今さら で自分の未来を小さくしないで」「変わりたいと思った瞬間が、変わるタイミング」。

## 7. オファー：無料個別相談会（特典・限定）
- 60〜90分で理想の生活のロードマップをつくる場。現役プロカウンセラーが働き方/スキル/ステップを整理。「無理な勧誘は【絶対にしない】」。
- **先行予約が速攻で埋まった → 4日間限定コラボ**。豪華特典（64スライドの分析／営業文テンプレ／投稿テンプレ20／79スライド未経験在宅／155スライドInstagram完全攻略／リール攻略63スライド／デザインテンプレ12／やりたいこと発見／料金設定ガイド／受講生インタビュー／在宅タイプ診断／業務委託契約書雛形…16個以上）。
- ※注記：「5月のコラボは終了しました！」

## 8. ⭐面談前の"顕在化"装置（＝5月訴求の勝ち筋）
**「個別相談会で人生が変わる人・変わらない人」**を提示し、参加者に**準備3質問**をメモしてくるよう促す：
1. **もし月5万円増えたら、何に使いたい？（3つまで）** →「頑張る理由」＝理想の顕在化
2. **今いちばん不安に感じていることは？** →「不安」の言語化＝乗り越え対象の明確化
3. **半年後、どんな自分になっていたい？** →ゴールの顕在化

→ これにより、**面談に来る前から悩み・理想・危機感が"自分の言葉"で顕在化**され、温度の高い状態で面談に臨む設計。**AI教科書（月2万）にはこの装置が無く、ノウハウ提供で終わっている**のが対照的。
