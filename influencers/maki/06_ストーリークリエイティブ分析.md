# ストーリークリエイティブ（CR）分析：5月共感型 vs 6月AI教育型

主軸＝maki（@maki_moneylife）の**日別ストーリーズ文字起こし**（[文字起こし/](文字起こし/)、5月204枚・6月173枚・7月145枚）を訴求タイプで分類し、申込・ファネルの結果（[03](03_事前診断_5月コラボvs6月AI比較.md)／[05](05_入会者深掘り_なぜ会社員手取り15万に刺さったか.md)／[02](02_5月コラボvs6月AI_数値比較.md)）で裏付ける。
※分類はキーワードベースの多重タグ（1枚が複数要素を含む）。数値は「その要素を含む投稿の割合」＝傾向値。

## 🎯 最終結論（打ち手）
**40代前半の"払える層（会社員・手取り15万+）"に絞って、「教育費はこれから来る→時間がある今こそ仕込めば間に合う」という【先回りの危機感】で煮詰める。**
- ① ただの40前半でなく**"払える層（会社員・手取り15万+）"に向ける**／② 煽り方は「もう遅い」でなく**「今なら間に合う（先回り）」**。

**根拠3点：**
1. **なぜ40前半か＝一番大きいから**：フォロワーの**50.7%が35-44**、申込も40前半が最多（5月コラボ58%）。動かせば一番効くボリューム。
2. **なぜ"払える層に絞る"か＝40前半の半分は払えないから**：40-44は申込最多(38)なのに**入会11%**。面談に来た23名の**約4割が手取り一桁パート／専業主婦(0円)＝79万は構造的に払えない**（貯蓄<100万が反応層の40%とも一致）。ここは何を訴求しても決まらない。
3. **なぜ"先回りの危機感"か＝40前半は切迫感が弱いから**：40前半の払える層は意欲「時期をみて／迷い」が多い（子が小学生前後で教育費ピークが"これから"）。対して**45-49は入会29%と決まる**（子が中高大で教育費が"今"＋50目前の危機感で決め切る）。＝40前半に足りないのは"今やらなきゃ"＝「教育費の山はこれから→今こそ（先回り）」で作れる。

**外すと逆効果**：「もう遅い/更年期/老後」は45歳以上を呼ぶ言葉で50代は成約0%＝無駄。40前半には「今なら間に合う」。／払えない半分（手取り一桁パート）は煽っても決まらない（入口で"払える層"に寄せる訴求が別途要る）。

## サマリー（先に結論）
- **月ごとにクリエイティブの"性格"が明確に切り替わっている**：**5月＝共感型／6月＝AI教育型／7月＝共感回帰**。
- **5月**：悩み顕在化31%＋自己開示（親近感）19%＝**感情で悩みを顕在化・切迫化**。運用代行＝本命・月5万。→ パート・逼迫層に刺さり**予約率66%（高温）**、ただし払えない層も混ざり入会率20%。
- **6月**：手段教育46%（AI/Threads/楽天ROOM）＋特典27%（教科書）が主役、**共感が半減（顕在化19%・自己開示8%）**。→ **リーチ最大（友98）・会社員/払える層に純化**したが、悩みが立たず**予約率30%（低温）**、来た人は入会率42%。
- **7月**：AI教育10%に沈静し**悩み顕在化30%＋実績32%に回帰**（6月AIの入会・売上はこの7月に着地）。
- **一言**：6月はクリエイティブの主役を「悩み（感情）」から「手段（AIノウハウ）」に移した。これがリーチ拡大＆客層シフトを生んだ一方、悩みの顕在化・温度を落とし予約率を下げた。

## 2. 月別クリエイティブ戦略の読み解き
### 5月＝共感型（悩みを顕在化して面談へ）
- 主役＝**悩み顕在化（31%）＋maki自己開示（19%）**：「夫に隠れて服を買う罪悪感」「子どもに我慢させた」等で**痛みを自分ごと化**。
- **運用代行＝本命・最短ルート**として提示（発信者は挫折／運用代行は1ヶ月目から収益／適性診断アンケ「運用代行86%」）。打ち出す金額は**月5万〜**。
- 受講生実績22%で「同じ40代ママが月5/16/20万」を裏づけ。**キャンセル訴求0%**。
- → 温度が高く**予約率66%・実施率56%・今すぐ意欲57%**。ただし間口が広く手取り一桁の払えない層も来て入会率20%。

### 6月＝AI教育型（ノウハウで裾野を広げる）
- 主役が**手段教育（46%）＋特典（27%）**に交代＝**「AI使ってる?」啓蒙＋ChatGPT×Threads×楽天ROOMで月2万＋教科書**。
- **共感が半減（顕在化19%・自己開示8%）**＝悩みに刺さず"興味"で引いた。打ち出す金額が**月2万**に低下。
- 実績・相談会価値・SSコラボ感は**あった**（ミキさん月20万・"1年以上推してるSS"）が、**運用代行を"難しいから避けるもの"に位置づけ**、相談会は「月2万をより現実的にする補助」に格下げ＝**教育（自走Threads）と出口（運用代行スクール）がねじれ**、面談の必然性が低下。
- **キャンセル訴求（無断キャンセル）が頻発（4%）**＝「みんなキャンセルしている」の社会的証明で実施率を下げる方向。
- → **リーチ最大（友98）・会社員/手取り15万+に純化**したが**予約率30%・実施率41%**。来た人は元々運用代行志向＆払える層で**入会率42%**。

### 7月＝共感回帰
- AI教育を10%に絞り、**悩み顕在化30%＋実績32%**へ回帰。6月AI流入の入会・売上（発生¥2.70M）はこの7月に着地。

## 4. 示唆（次のCR設計）
- **入口（ハードル下げ）は6月の勝ち筋を残す**：スキマ15分・月2万・時短は時間のない会社員に刺さる。ここはキープ。
- **主役を"手段"から"悩み"へ戻し比率を回復**：6月で半減した**悩み顕在化・自己開示を5月水準（30%前後）に戻す**。温度＝予約率の源泉。
- **教育と出口を一直線に**：「Threads×AI＝入口（月2万）→本気の月5万は運用代行→それを相談するのが面談」と繋ぎ、**運用代行を"本命"に戻す**（金額の階段を見せる）。
- **⭐"面談＝自分を整理する場"を前面に（現状5-9%と全月手薄）**：「何がしたいか分からなくてもOK、話して気持ちと状況を整理するだけで次の一歩が見える」という**自己分析の価値**を打ち出す。目標が曖昧な受動層（AI流入の"見てるだけ"52%）の予約を押せる、最も伸びしろのあるレバー。
- **キャンセル訴求（無断キャンセル・希少性煽り）の頻度を落とす**：反復は「みんなキャンセルしている」の社会的証明になり実施率を下げる。実績・カウンセラー紹介・意気込みなど"行きたくなる"内容に置換。
- **面談前の顕在化装置を移植**：5月noteの準備3質問（月5万増えたら何に使う/今の不安/半年後）をAI導線の予約完了・リマインドに差し込む。

### なぜ40-44が決まらないか＝二重の理由（面談に来た23名の内訳）
40-44は新規38→実施23→入会4。面談に来た23名を精読すると：
1. **払えない層が4割来ている**：面談参加23名のうち**手取り一桁パート／専業主婦(0円)が約9名（41%）**。795,000円は構造的に無理（40-44のパート入会はゼロ）。
2. **払える層(手取り15万+)も"今すぐ"に煮詰まっていない**：残りの会社員も多くが意欲「時期をみて／迷い」。**子が小学生前後で教育費ピークが"これから"**＝切迫感が弱い（例：手取27万「時期をみて」／21万「離婚は2年後」／18万「不妊治療で貯金を使った」）。45-49が「子が中高大で教育費が"今"＋50目前」で決め切るのと対照的。

→ ＝**「払えない層の混入」＋「払える層の切迫感不足」の二重**。「40-44入会11%」の正体はこれ。

### 40-44にストーリーでできること／できないこと
- ⭕ **できる（払える40前半の煮詰め）**：①「時期をみて」を潰す危機感（"また今度は来ない"／教育費の先回り "今なら間に合う"）②同属性（40前半・会社員/フルパート・手取り15万+）の実績で「自分もできる」③費用不安の事前溶解（回収見込み・分割・"教材費以外かからない"）④面談前の準備3質問で危機感と目標を言語化。
- ❌ **できない（構造的天井）**：手取り一桁パート／専業主婦(0円)の"払えなさ"。面談に来ても決まらず、ストーリーで危機感を上げても支払い能力は作れない。
- → **現実的ゴール＝"40-44を丸ごと救う"ではなく"40-44の払える層の取りこぼし回収"**。払えない半分を根本で変えるなら入口側（払える層に寄せる訴求）の話に戻る（今は保留）。

### 言葉の年齢スキュー（5月ストーリーズ204枚）
言葉の大半は**どの年齢にも当てはまる中立語**（子供・お金・在宅・月5万）＝だから35-55に広く拡散。特定の年齢に向けた言葉は少ない：
| | 割合 | 例 |
|---|--:|---|
| **45+寄りの言葉** | 計5% | 大学/受験/専門/私立(3%)、もう遅い/今さら/50代(2%)、更年期/体力(1%)、老後/介護。＋後悔・人生後半の重いトーン |
| **35-45寄りの言葉** | 計11% | 保育園/幼稚園/2歳/乳児(6%)、今のうち/先回り/10年後(2%)、妊活/第二子/産育休(2%)、扶養(1%) |

→ 35-45に向けた言葉は11%と手薄。45-54に反応が寄るのは言葉より**感情の色（後悔・もう遅い）と、maki本人が40代であること**による。

### 結論：狙いは"40前半の【払える層】の取りこぼし回収"（新規シフトでも40前半全体でもない）
- **新規獲得で無理に35-44へ寄せる優先度は低い**（申込は既に40前半中心＝良ゾーン）。
- **ただし"40前半を丸ごと回収"も不可**：面談に来る40前半の約4割は手取り一桁パート／専業主婦(0円)＝**構造的に払えない**（貯蓄<100万が反応層の40%とも符合）。ストーリーで危機感を上げても動かない。
- **⭐本命＝40前半の"払える層"（会社員・手取り15万+・貯蓄100万+）の取りこぼし回収**：この層を**煮詰め（危機感）×同属性実績×費用回収の見せ方**で決め切らせる。新規で年齢を動かすより速く効く。
- **CR側の微調整**：削るのは50+（0%成約の無駄）＝「もう遅い/更年期/老後」等の45歳以上に効く言葉と重い後悔トーンを抑える。起こすのは40前半の払える層＝
  - maki自身の**"10年前＝30代の私"ストーリー**を前面に
  - 教育費を**"これから来る山に今から備える（先回り）"**に振る（45+の"今、地獄"でなく）
  - **"子が小さい今こそ、家で一緒にいながら"**（保育園・2歳・産育休）
  - **未来投資フレーム**（40代になる前に今のうちにスキル資産／後悔ベースでなく前向き）
