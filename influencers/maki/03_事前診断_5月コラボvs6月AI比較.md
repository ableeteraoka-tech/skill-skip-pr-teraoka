# 事前診断分析：5月コラボ vs 6月AI（比較版）

元データ：[2026_事前診断_maki.csv](2026_事前診断_maki.csv)。**6月AI**（紹介者`_AI`／新規カウンセリング実人数 **n=29**）を、**5月コラボ**（それ以外＝先行予約＋makiコラボ本体＋面談経由 **n=72**）と全項目で比較。割合の分母は各群の実人数、「回答なし（診断未記入）」を含む（5月11%・AI21%）。
AIファネル：ライン追加98 → 予約29 → 実施12（41%）→ 入会5（入会率42%）→ 売上¥2.70M。

## サマリー（先に結論）
- **AI訴求は"AIを使った副業"というフックで新規リーチを最大化（友98）**。ただし予約率30%・実施率41%と入口〜中間で大きく脱落し、**「SNSを見ているだけ」の受動層52%**が集まった＝温度は低め。
- **一方で、実施まで来た人の入会率は42%と全チャネル最高**。＝薄く広いが、芯に当たれば決まる。
- **像は5月コラボより"年齢が広く・所得は中間"**：40代前半コアが崩れ20-30代＆40代後半に分散、パートが半減して会社員34%・手取り15〜24万が中心。**シングルマザー・離婚/再婚を機にした自立ニーズ**が目立つ。
- **母数（予約29・実施12）は5月以降ベース（予約57・実施32）より減ったが、"払える層"の密度は上がった**：手取り0の専業主婦は入会0、手取り21万の会社員が入会最多。パート減・会社員/中間層増で、来た人の入会率は42%と最高。＝「数を絞った代わりに質が上がった」。
- 施策：**AIで集めた母数は「温めてから面談」前提**。予約直後の不安解消（費用・年齢・過去の失敗）＋同属性の成功事例で、実施率41%を底上げできれば高い入会率が効く。

## 1. 属性（5月コラボとの比較）
性別＝女性、婚姻＝既婚・子あり中心は両群共通。**変化したのは「年齢」と「職業（＝所得）」**。

### 年齢（構成比・実数）
| 年齢帯 | 5月コラボ n=72 | 6月AI n=29 | 変化 |
|---|--:|--:|---|
| 20-30代（40歳未満） | 9（12%） | 8（**28%**） | 構成比↑（**ただし実数は9→8で横ばい**） |
| 40代前半（コア） | 32（**44%**） | 6（21%） | **半減**（コアが薄まる） |
| 40代後半 | 13（18%） | 8（28%） | 増 |
| 50代以上 | 10（14%） | 1（3%） | **ほぼ消滅** |
| 回答なし | 8（11%） | 6（21%） | － |

→ **5月コラボの"40代前半"が減り、20-30代の構成比が上がった**。ただし**若年の実数はほぼ横ばい（9→8）**で、割合が上がったのは総数が72→29に減った（40代の申込が減った）ため。50代は消えた。

**「20-30代（40歳未満）」の内訳（新規／実施／入会）**
| 帯 | 5月コラボ | 6月AI |
|---|---|---|
| 〜34（20代〜30代前半） | 4／実施4／**入会1** | 4／**実施0（全員キャンセル）／入会0** |
| 35-39（30代後半） | 5／実施3／**入会2** | 4／実施2／**入会1**（38歳産育休） |

→ **35-39（30代後半）は5月・6月とも入会あり＝狙う価値のある若年ゾーン**。決まらないのは**〜34（20代〜30代前半）**で、6月AIでは4名全員がキャンセルし面談に来ていない（実施0）。＝「若年が入会しない」は正確には"〜34"の話で、35-39は問題ない。

### 職業（構成比・実数）
| 職業 | 5月コラボ n=72 | 6月AI n=29 | 変化 |
|---|--:|--:|---|
| パート・アルバイト | 30（**42%**） | 6（21%） | **半減 ← 最大の変化** |
| 会社員 | 21（29%） | 10（**34%**） | 微増 |
| 専業主婦 | 5（7%） | 2（7%） | 横ばい（元々少ない） |
| 自営業 | 4（6%） | 2（7%） | 横ばい |
| 回答なし | 8（11%） | 6（21%） | － |

→ **減ったのは主に「パート」**。その分、会社員と若年20-30代の比率が上がった。専業主婦は元々少なく横ばい。

### 手取り・貯金
| | 5月コラボ | 6月AI |
|---|---|---|
| 手取り | **0〜9万38%**（パート中心・逼迫） | **15〜24万42%**（中間所得） |
| 貯金 | 8割が5万以下 | 7割が5万以下 |

→ 総じて、**AIは"パート（手取り一桁の逼迫層）が減り、手取り15〜24万の会社員・中間層が増えた"**。この「払える層が増えたか／入会にどう効いたか」は §4.5 で分析。

→ **「収入×働き方」の芯は共通**。ただしAIは**「スキル」「SNS運用」の具体課題意識が薄い**（＝まだ手前の"漠然と不安"層）。悩みの発生時期は両群とも「1年以上前から」7〜8割で慢性化。

| | 5月コラボ | 6月AI |
|---|---|---|
| 最頻出（芯・共通） | 収入不安＋「在宅したいが何から始めるか分からない」 | ← 同じ |

- 6月AI「離婚して1人で子供3人を育てる」「再婚して働ける時間が減り自宅でできる仕事を」「お金のことばかり気にして子どもに我慢ばかりさせている」
- AI言及（少数）「makiさんのSNSでAIを使った副業を紹介されていて興味を持った」「AIをつかってなにをするのか知りたい」

### 理想の言葉（voice）

- 「本業に+収入し、投資や老後の安心材料にしたい」（将来の備え・中間所得らしい動機）

## 📌 補足：AIへの関心はどれくらいあるか（本人記述の言及分析）
診断の記述回答（本人が書いた文。※紹介者タグの"AI"は除外）に「AI」がどれだけ登場するかを群別に集計。

| | 5月コラボ n=72 | 6月AI n=29 |
|---|--:|--:|
| AI言及あり | **0件（0%）** | **3件（約10%）** |

AI群の3件（すべて記述）：
- 30歳・専業主婦「SNSで収益を得る方法。**AIをつかってなにをするのかを知りたい**」
- 46歳・会社員「**makiさんのSNSでAIを使った副業を紹介されていて興味を持った**」
- 40歳・会社員「興味スキル＝**AI活用**」

→ **「AIという言葉で振り向く人」は0→10%で出てきた**（＝AI訴求はフックとして機能）。ただし**絶対数は3人と少なく、中身は「AIで“何をするのか”知りたい」という“興味はあるが中身は分からない”段階**。実際、AI群でも興味スキルの本命は**インスタ運用代行34%・インスタ運用24%**で、「AI活用」を選んだのは1名のみ。
→ 示唆：**AIは集客の入口としては効くが、“AIそのものをやりたい”明確な需要はまだ薄い**。面談で「AIで具体的に何をするのか」を見せると刺さりやすい。

## 4.5 入会者の属性（5月コラボ vs 6月AI）
CSV期間（5/26〜7/31）の入会フラグ＝延べ14名を**群別に分解**（5月コラボ9・6月AI5）。※小さいnなので傾向として読む。一部は「07_前月からの繰越処理」で実施記録を伴わない。

| | 5月コラボ 入会9 | 6月AI 入会5 |
|---|---|---|
| 年齢 | 40代6・30代3（32/37/39）・**20代0・50代0** | 40代4・30代1（38）・**20代0・50代0** |
| 職業 | 会社員4・パート2・医療2・自営1 | 会社員2・パート2・産休育休1 |
| 手取り | 15万以上7／15万未満2（**手取り6万・13万の逼迫層も入会**） | **全員15万以上**（最低15万・最高23万） |
| 実施後の入会率 | 約20% | **41.7%（全チャネル最高）** |

### ⭐ AI訴求は「払える層に絞れた」＝訴求の"質"は良かった
- **AI入会5名は全員が手取り15万以上**（会社員・パート・産休育休）。一方5月コラボは手取り6万・13万の逼迫層も入会しており、**AIの方が"払える層"に純化している**。
- ただし**両群とも入会の芯は40代**。AIで申込構成比が倍増した**20-30代は入会に繋がっていない**（AI入会で若いのは38歳の1名のみ、20代0）。手取り0の専業主婦が入会0（§1）とも整合。
- **訴求効果の評価**：AI訴求は「払える層を集め、実施後の決定率も42%と高い」＝**"質"は良かった**。弱点は実施母数の少なさ（12件）で、絶対入会数（5）はまだ小さい。→ 伸ばすレバーは**「20-30代を増やす」ではなく、「予約〜実施の脱落を減らして払える層を実施に乗せる×面談で危機感醸成（§5.5）」**。

> 🔎 **なぜ会社員・手取り15万+に刺さり入会率が上がったのか**の深掘り（入会者14名の記述精読・時間制約×支払い能力のメカニズム）は [05_入会者深掘り](05_入会者深掘り_なぜ会社員手取り15万に刺さったか.md) を参照。

## 5. ⚠️ 予約後に来ない／決まらない理由の仮説（申込理由・聞きたいことから）
1. **費用不安**「費用について」「準備金は必要か」→ 費用感の早期提示 or「まず無料で聞ける」明言。
2. **過去の失敗・詐欺への警戒**「また結果が出ないのでは」「詐欺に遭った経験」→「他と何が違うか」「失敗経験からでもOK」を前提に。
3. **年齢・自信のなさ**「スキルがないけどできるのか」「機械音痴でも」「あまりマメでないが出来るか」→ **同属性（40代後半・シングル等）の受講生の声**を出す。
4. **受動・LINE登録慣れ**「いくつも登録したが乗り気になれない」→ AI流入は"見てるだけ"が半数。**予約直後の背中押し**が必須。

## 5.5 面談側の要因（2026/07 個票ケース分析より・n=2）
6月AIの「実施まで来れば入会率42%と高い」を、面談の中身が裏づける。Maki経由の入会1・未入会1を精読した結果（詳細：[参考_2026-07_Maki経由_カウンセリング入会分析.md](参考_2026-07_Maki経由_カウンセリング入会分析.md)）：

| | 入会（長村・47歳パート） | 未入会（浦末・パート/子3人） |
|---|---|---|
| STEP6（継続不安の先回り・3点セット） | 準拠 | **丸ごと欠落** |
| STEP8（他手段の消去＝副業しかない） | 準拠（簡略） | **丸ごと欠落** |
| 危機感の醸成 | 「今と同じ悩みを50代でも抱えるのは絶対嫌」と強く同意→**即決** | 費用が「五分五分」のまま模擬講提案で終了 |
| 決裁 | 本人単独（夫の反応は懸念材料どまり） | 本人単独・相談相手不在で迷いを一人で抱える |

→ **準拠率は97% vs 93%と僅差**で、成否を分けたのは"準拠率の高さ"ではなく**「STEP6/STEP8という必須STEPの実施有無」＝危機感を本人の言葉で固められたか**。
→ **示唆：AIは"事前キャンセルを減らして実施に乗せる"＋"実施時にSTEP6/8で危機感を醸成する"の両輪で、高い入会率をさらに取りこぼさず伸ばせる**。共通の弱点はSTEP5（目標金額・期限を本人に言わせる）が両ケースともカウンセラー提示になっている点。

## 6. PR改善提案
- **AIフックは新規リーチの武器として有効**（友98＝最大級）。「AIを使った副業」への興味が入口になっている。→ 入口の訴求は継続。
- **弱点は"予約〜実施の脱落"**（予約率30%・実施率41%・キャンセル59%）。ここが最大のレバー。**予約直後のリマインド＋費用/年齢/過去失敗の不安解消＋同属性の成功事例**で実施率を底上げすれば、高い入会率（42%）が効いて一気に伸びる。
- **受動層52%前提のナーチャリング設計**：「まず話を聞くだけでOK」「決めなくていい」で心理的ハードルを下げる。
- **キーワード**：
  - 悩み言葉「AIを使った副業って、実際なにをするの?」「離婚を機に、一人でも安心できる収入がほしい」「保育士/看護、体力的にこの先ずっとは続けられない」「子どもに我慢ばかりさせている」
  - 理想言葉「子どもが学校に行っている間だけ働く」「夫に頼らなくてもいい収入を」「月+5万で、老後と今の安心を同時に」
