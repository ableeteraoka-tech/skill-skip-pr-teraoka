# maki 事前診断分析（申込者プロフィール）

元データ：[2026_事前診断_maki.csv](2026_事前診断_maki.csv)（5/26〜7/31、新規カウンセリング実人数ベース）。
群分けは**紹介者タグ**：`_AI`付き＝**6月訴求（AI特典）n=29**／それ以外＝**5月訴求（先行予約＋ローンチ＋直面談）n=72**。
※割合は各群の新規カウンセリング人数を分母。「回答なし（診断未記入）」が5月11%・AI21%含まれる。

## サマリー（先に結論）
- **コア像＝40代前半・女性・既婚子あり・パート/会社員・手取り0〜14万・貯金ほぼゼロ**。悩みは「収入×働き方」、理想は「在宅副業で月+3〜5万＋子供との時間」、興味は**インスタ運用代行**。ただし**「今すぐやりたいが、スキル/PC/年齢/費用への不安で踏み出せない」受動層**。
- **5月訴求は"逼迫した40代前半コア"に的中**＝今すぐ意欲57%・実施率54%と温度が高い。共感ストーリー（子供の教育費・「おかえり」）がハマっている。
- **6月AIは母数を広げたが温度が下がった**＝年齢が40代後半＆20-30代に分散、会社員・中間所得層が増え逼迫度が低下。「SNS見てるだけ」52%、今すぐ意欲41%、実施率41%、事前キャンセル増。**ただし実施できた人の入会率は最高（41.7%）**。
- 施策示唆：**5月型の共感訴求を主軸に継続**しつつ、AIで広げた新規母数を**「同属性の成功事例＋費用・年齢の不安解消」で温めて実施率を底上げ**するのが伸びしろ。

## 2. 悩みの深掘り

### 選択式（複数回答・上位）
| 悩み | 5月訴求 | 6月AI |
|---|--:|--:|
| 収入に関する悩み | 75% | 76% |
| 働き方に関する悩み | 64% | 52% |
| スキルに関する悩み | 29% | 14% |
| SNS運用・集客 | 28% | 10% |
| 目標や計画 | 21% | 21% |

→ **「収入×働き方」の二枚看板は両群共通**。AIは「スキル/SNS」の具体課題意識が薄い＝まだ手前の"漠然と不安"層。
※悩みの発生時期は**両群とも「1年以上前から」が7〜8割**＝慢性化した不安。

### 自由記述の頻出テーマ（voice of customer）
1. **子供の教育費が重い**（習い事チア/バレー部・私立高・専門/大学・塾代）「授業料無償化でも部費・設備費でかなりの出費」
2. **在宅したいが何から始めるか分からない**（最頻出）「情報収集したいけど何から始めたらいいか分からず、ずっと行動できないまま時間だけが経過」
3. **スキル/PC/年齢への自信のなさ**「パソコン苦手」「機械音痴でもできる?」「40歳から/50歳越えてもできる?」
4. **今の仕事が体力的に続かない**（保育士・看護・テレアポ・接客の立ち仕事）「契約を切られたら終わり。この先ずっと続けられる保証がない」
5. **シングル/離婚後の自立不安**「一人で子供3人を育てていく」「養育費に頼らず安心できる収入を」
6. **過去の失敗・詐欺への警戒**「webデザインスクール中級で挫折」「物販スクールの入会金が無駄に」「SNSで詐欺に遭った」「正直、詐欺なのかなという不安」

### 属性別の悩みパターン
| 層 | 主な悩み |
|---|---|
| パート・低収入（手取り一桁） | 教育費・扶養の壁・体力的な継続困難・「お金がない」 |
| 40〜50代会社員 | 昇給なしの中での物価高・教育費高騰、将来/雇用不安、体力 |
| 専業主婦 | 収入ゼロからのスタート、スキル皆無、夫への相談・内緒 |
| 自営業 | 収入のムラ、SNSを活かしたいが方法不明 |

## 4. 温度感・行動レベル
| 項目 | 5月訴求 | 6月AI |
|---|---|---|
| 意欲 | 今すぐ57%＋時期をみて24% | 今すぐ**41%**＋時期をみて24% |
| 現在の状況 | 見てるだけ31%/まだ何もしてない28% | **見てるだけ52%**（受動が半数超） |
| 使える時間 | 1〜2時間64% | 1〜2時間72% |
| 面談実施率 | **54%** | **41%** |
| 事前キャンセル | 15% | **23%** |
| 実施後の入会率 | 20〜23% | **41.7%** |

→ **AIは"受動・低温・キャンセル多"だが、実施まで来た人は濃い**。＝入口を広げた分、面談前の脱落が増えた。**予約〜実施のナーチャリングが最大のレバー**。

## 5. ⚠️ 予約後に来ない／決まらない理由の仮説（申込理由・聞きたいことから）
優先度順：
1. **費用不安**が最頻出「講座はいくらか」「初期投資の費用がない」「高額スクールは厳しい」→ 費用感の早期提示 or「まず無料で聞ける」を明言。
2. **過去の失敗・詐欺への警戒**「また無駄になるのでは」「入会金が無駄になった」「詐欺なのか」→「他スクールと何が違うか」「未経験・失敗経験からでもOK」を前提に発信。
3. **年齢への自己不信**「40歳から?」「50歳越えても?」「44歳から遅くない?」→ **40〜50代・同属性の受講生の声**を意識的に出す。
4. **スキル/PC自信なし**「パソコン苦手」「機械音痴」「スマホ1台でできる?」→ ハードルの低さを具体で見せる。
5. **夫への相談・内緒**「旦那に内緒で申込」「バレたくない」（既婚8割）→「家族に相談してから決めてOK」「説明資料を渡せる」導線。
6. **慢性的な先送り＋受動**「何年もSNSを見て終わり」「勇気が出ない」→「まず話を聞くだけでOK」「決めなくていい」の心理的ハードル低下メッセージ。

## 6. PR改善提案
- **主軸は5月型の共感ストーリーを継続**：40代前半パート・逼迫層に「子供の教育費」「"おかえり"と言える働き方」が的中している。ここは崩さない。
- **AIで広げた母数を"温める"導線を追加**：AI訴求は新規リーチ（友98）を稼ぐ武器として有効。ただし予約後の脱落が多いので、**予約〜面談前に「同属性の成功事例＋費用・年齢の不安解消」**を差し込み、実施率41%→50%台を狙う。
- **事前キャンセル対策**：AIの事前キャンセル23%に対し、リマインド＋「受講生の声」＋「費用感の事前開示」で実施率を底上げ。
- **年齢の不安に応える**：40代後半・50代が一定数いる。「何歳からでも遅くない理由」「50代の実例」を発信。
- **キーワード**：
  - 悩み言葉「給料は上がらないのに物価と教育費だけ上がる」「在宅、興味はある。でも自分には無理だと何年も経った」「契約を切られたら終わり」「習い事・受験費用に毎月追われている」
  - 理想言葉「子供に"おかえり"と言える働き方」「スキルゼロ・パソコン苦手・40代でも始められた」「子供の"やりたい"を、お金を理由に諦めさせない」「年を取っても自分のスキルで稼げる安心」
