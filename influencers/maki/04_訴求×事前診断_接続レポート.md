# 訴求（発信）× 事前診断（申込）接続レポート
## ＝「何を発信したら誰が来たか」：5月共感型 vs 6月AI型の因果

出典：maki（@maki_moneylife）の日別ストーリーズ文字起こし（[文字起こし/](文字起こし/)）× 事前診断 [03_事前診断_5月コラボvs6月AI比較.md](03_事前診断_5月コラボvs6月AI比較.md) × 数値 [02_5月コラボvs6月AI_数値比較.md](02_5月コラボvs6月AI_数値比較.md)。

## サマリー（先に結論）
- **5月＝「子供・教育費の自己開示ストーリー × 月+5万 × インスタ運用代行」の共感型**。狭く深く刺し、**40代前半・パート・教育費で逼迫した層がドンピシャで来た**（今すぐ意欲57%・予約率66%）。
- **6月＝「AI使ってる? という啓蒙 × ChatGPT×Threads×楽天ROOMでスキマ15分・月2万 × 教科書特典」のAI型**。**軽いフックで裾野を広げ**、会社員・若年・受動層まで届いた（リーチ最大・友98）。ただし悩みの深掘りが弱く、**温度が下がった**（今すぐ41%・予約率30%・「SNS見てるだけ」52%）。
- **因果はほぼ一直線**：発信で「金額を下げ（+5万→月2万）」「悩みストーリーをAI啓蒙に差し替えた」ことが、申込の"温度低下・受動層増・スキル課題意識の希薄化"に対応している。
- ただし**入会の芯（40代・払える層）は訴求を変えても不変**。AIは"払える会社員"に純化できた点は良かったが、"AIをやりたい人"はまだ薄く、面談ではインスタ運用の本命に着地している。

## 1. 訴求の中身（発信側）

### 5月：共感ストーリー型
| 要素 | 実際の発信 |
|---|---|
| 悩みフック | **子供に我慢させる罪悪感**「娘が"お友達はバレエ習ってる、いいな"と。申し訳ない気持ちに」「GWの思い出発表で他の子は遊園地、うちは…」 |
| 自己開示 | maki自身の物語「掛け持ちパートでも月11万、サブで+3万」「月5万増えて、業者を呼べる・高い惣菜を選べるようになった」 |
| 金額 | **「あと+3万〜+5万で人生が変わる」**（「5万」系の語が月内46回） |
| オファー | スキルスキップ無料相談会／Amazonギフト特典／子どもNISA・GFS経済新聞 |
| 手段 | **インスタ運用代行**（「SNS勉強して正社員に」等） |
| 感情の締め | 「子供の未来をお金で諦めさせない"親としての武器"」「働き方を変えることは生き方を変えること」 |

> ⭐ **5月noteには"悩みを顕在化させる装置"が組み込まれている**（[訴求資料_5月note](訴求資料_5月note_夫に隠れて服を買ってた私が月5万.md)）。①**夫に隠れて服を買う罪悪感／「私の人生は終わったのか」**という自己開示で悩みを感情的に顕在化・切迫化。②面談前に**準備3質問**（「月5万増えたら何に使う?／今いちばんの不安は?／半年後どうなっていたい?」）＋**「相談会で変わる人・変わらない人」**を提示し、**予約者が"自分の言葉で"悩み・理想・危機感を言語化してから面談に来る**設計。→ これが5月の高い予約率66%・実施率56%・今すぐ意欲57%の源泉。**AI教科書にはこの装置が無い**（ノウハウ提供で完結）。

### 6月：AI型（AI×Threads×楽天ROOM）
| 要素 | 実際の発信 |
|---|---|
| 入口フック | **「AI使ったことある?」アンケート**→「40代の2人に1人が使ってる」「ChatGPTが収益になると知らなかった人77%」の**啓蒙** |
| オファー | **「寝る前15分、ChatGPT×Threadsで月2〜3万」**／**楽天ROOMアフィリ** |
| 特典 | **「Threads×ChatGPTでスキマ時間に月2万の教科書」**（目次：Threads収益化・楽天ROOM・月2万5ステップ・**AIプロンプト集**・実践ルーティン） |
| 金額 | **月2万**（5月の+5万より控えめ・ライト） |
| 受け手の反応 | 「スレッズ何も知らない、基礎から知りたい」「パソコン苦手だけど大丈夫?」＝**初心者・様子見の"気になる"層** |

> ⭐ **配布特典noteが訴求構造を決定づけている**（[訴求資料_AI特典note](訴求資料_AI特典note_Threads×ChatGPT月2万教科書.md)）。maki自身が教科書内で階層を明示：**「月5万以上しっかり稼ぎたい方にはインスタ運用」／「スキマ時間にちょっとだけの方にはThreads×AI（＝月2万・審査なし楽天ROOM）」**。つまり **AI/Threadsは"軽い入口"、稼ぎの本命（＝スクールが売る領域）はインスタ運用**、という設計。なお**教科書は"予約特典"（相談会を予約するともらえる）**。それでも予約率30%止まり＝**特典をフックにしても「面談を受ける」ハードルを越えさせられなかった**（リーチ98はAI啓蒙トピックの広さ由来）。

※キーワード出現（月内）：5月＝子供/教育費91・在宅44・+5万46・インスタ運用28／**AI 0・Threads 0・楽天ROOM 0**。6月＝**AI 62・Threads 44・楽天ROOM 18**・特典18（+5万は6に激減）。7月＝AI 4に沈静化・楽天ROOM 15残存。

| 発信で変えたこと（5月→6月） | 申込データに出た結果 | 根拠 |
|---|---|---|
| 金額を**+5万→月2万**に下げ、"スキマ15分"とライト化 | **温度低下**：今すぐ意欲57%→41%、緊急度「3ヶ月以内」24%→17% | §3・§4 |
| 悩みの**自己開示ストーリー→AI啓蒙**に差し替え | **受動層が増加**：「SNS見てるだけ」31%→52%、悩みの「スキル」29→14%・「SNS運用」28→10%と課題意識が希薄化 | §2・§4 |
| **「AI使ってる? 会社員も使う」**という会社員文脈の啓蒙 | **会社員↑・手取り中間層↑**（会社員29→34%、手取り15〜24万が42%）、若年20-30代が倍増 | §1 |
| **軽い誰でも答えられるフック**で裾野拡大 | **リーチ最大（友98）**だが**予約率30%・実施率41%**と入口〜中間で脱落、事前キャンセル増 | §4・[02](02_5月コラボvs6月AI_数値比較.md) |
| 手段を**インスタ運用代行→Threads×楽天ROOM×AI** | 申込に**「AIを使った副業」への言及が0→3件**出現。ただし興味スキルの本命は依然インスタ運用代行34% | §📌補足 |
| 共感で**狭く深く**（5月） | **予約率66%・実施率56%・今すぐ57%**＝濃い層が堅実に面談へ | §4・[02](02_5月コラボvs6月AI_数値比較.md) |

## 3. 「訴求は良かったのか」の評価
- **リーチ拡大は成功**：AI啓蒙という軽い入口で友98（最大級）。会社員・若年まで届き、**入会者は"払える層"に純化**（AI入会5名は全員手取り15万以上）。実施後の入会率42%は全チャネル最高。
- **弱点は"深さ"**：悩みの自己開示ストーリーが薄いぶん温度が下がり、**予約〜実施で大量に脱落**（予約率30%・キャンセル59%）。結果、絶対入会数は5とまだ小さい。
- **入会の芯は不変**：訴求をAIに振っても、決まったのは40代・払える層。20-30代は増えても入会に繋がらず、面談での本命はインスタ運用代行に着地。＝**「AIは"知らなかった層"を振り向かせる入口としては強いが、"AIをやりたい"需要はまだ育っていない」**。

## 4. 示唆（次の訴求設計）
- **ハイブリッドが最適**：**5月の共感ストーリー（子供・教育費・自己開示）で"深さ・温度"を作りつつ、6月のAI啓蒙で"入口の裾野"を広げる**。AIフックで集めた後、5月型の感情ストーリーで温度を上げてから面談に乗せる。
- **金額訴求は下げすぎない**：+5万→月2万のライト化が温度低下と連動。入会の芯は"払える層"なので、**「月2万から始めて+5万・在宅本業化」の段階提示**で切実さを保つ。
- **AI流入は"温めてから面談"前提**：受動層52%・事前キャンセル多を踏まえ、予約直後に「同属性（40代・払える層）の成功事例＋費用/年齢の不安解消」を差し込み、実施率41%を底上げ（§5.5の面談STEP6/8と両輪）。
- **5月noteの"顕在化装置"をAI導線にも移植**：AI教科書には無い**準備3質問（月5万増えたら何に使う?／今の不安は?／半年後どうなりたい?）**＋**「変わる人・変わらない人」**を、AI流入の予約完了画面・リマインドに差し込む。悩み・理想・危機感を"自分の言葉"で言語化させてから面談に乗せれば、低い予約率30%・実施率41%の底上げに直結（＝"悩み顕在化不足"というボトルネックへの直接処方）。
- **AIの中身を面談で見せる**：申込者は「AIで"何をするのか"知りたい」段階。面談で「AI=Threads/楽天ROOMで具体的にこう稼ぐ」を可視化すると、興味を実需へ転換できる。
