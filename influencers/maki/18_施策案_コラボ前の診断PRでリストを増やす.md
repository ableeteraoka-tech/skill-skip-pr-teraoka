# makiさん 施策案｜コラボの前に診断PRをしてリストを増やす

## サマリー

- **診断でリストを取り、コラボのときにそのリストへメッセージ配信でアプローチする**のが有効。
- コラボ（予約特典の配布）の**10〜14日前に診断PRをする**。診断PRの目的は**リストを増やすこと**で、診断PRからの予約は入ったらラッキーくらい。**10件取れればいい**。
- 根拠は、しょうごっこさん10月ローンチの結果。コラボ時のメッセージ配信経由の予約39人のうち、**24人（62%）が診断を通った人**で、そのうち17人は診断で新しくリストに入った人だった。

---

## 1. しょうごっこさんで起きたこと

**8月**
動画配布、勉強会、コラボと訴求を続けたことで、コラボのときにメッセージ配信から予約がたくさん入った。

**10月（診断ローンチのあとにコラボ）**

| 区分 | 人数 |
| --- | --: |
| メッセージ配信経由の予約（今回のリンクを踏んでいない予約） | 39 |
| ┗ 診断を踏んだ人 | 24 |
| 　┗ 過去のリストで、診断LPも踏んでいる人 | 7 |
| 　┗ 診断で新しくリストに入った人 | 17 |
| 今回のリンクを踏んでいて、診断も踏んだ人 | 4 |

- メッセージ配信経由の予約の6割が、診断を通った人だった。
- 17人は、診断がなければリストにいなかった人。診断PRで増やしたリストが、コラボのときのメッセージ配信で予約になった。
- 過去のリストの7人も、診断LPを踏んだことで、もう一度接点ができている。

**10月診断で集まった人**
診断で集まるのは、コラボより顕在層の割合が高い人たち（事前診断の比較は補足を参照）。

---

## 2. makiさんでやること

| 項目 | 内容 |
| --- | --- |
| タイミング | コラボの10〜14日前に診断PR |
| 目的 | リストを増やす（予約を取りに行く施策にしない） |
| KPI | 診断PRからの予約は10件程度。入ったらラッキーくらいで見る |
| 見る数字 | 診断を受けてリストに入った人数と、コラボ時のメッセージ配信経由の予約のうち、診断を通った人の数 |
| コラボのとき | 診断で取ったリストに、メッセージ配信で予約を案内する |

**9月末PRとの違い**
- 9月末PRは、診断PRで予約を取りに行き、キャンセル率が67%になった。
- 今回は、診断PRの役割をリストを増やすことに絞る。予約はコラボで取る。
- 9月末の課題だった、仕事の中身・始め方・最初の1件の取り方（how）が見えないという点は、診断からコラボまでの期間で届ける。

## 補足｜診断では、顕在層の刈り取りと興味づけを行う

しょうごっこさん10月の事前診断を、診断とコラボで比べた。診断で予約した人には、すでに動いている顕在層が多い（刈り取り）。一方で、まだ動き出していない人も3人に2人いて、この人たちには診断で興味づけをしておき、コラボのときのストーリーズや、メッセージ配信で予約につなげる。

**今の状況（いまどこまで動いているか）**

| 選択肢 | 10月診断（23） | 10月コラボ（82） |
| --- | --: | --: |
| SNSや広告で流れてくる情報を見ているだけ | 43% | 52% |
| まだ何もしていない | 22% | 28% |
| 気になることを自分で調べている | 9% | 13% |
| すでに行動している・情報収集をしている・やりたいことが決まっている | 26% | 5% |
| 無回答 | 0% | 1% |

→ 診断は、すでに動いている人が26%（コラボ5%）。ただし、見ているだけ・まだ何もしていない人も合わせて65%いる。

**理想を叶えたい時期**

| 選択肢 | 10月診断 | 10月コラボ |
| --- | --: | --: |
| 1ヶ月以内 | 9% | 2% |

| 9ヶ月以内 | 0% | 1% |
| 1年以内 | 35% | 52% |

→ 診断は、6ヶ月以内に叶えたい人が65%（コラボ46%）。コラボは半分以上が1年以内。診断の方が急いでいて、行動の段階も進んでいる。
