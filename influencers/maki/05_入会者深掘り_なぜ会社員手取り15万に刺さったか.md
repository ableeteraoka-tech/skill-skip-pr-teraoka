# 入会者深掘り：なぜ6月AIは「会社員・手取り15万+」に刺さり、入会率が上がったのか

対象：CSV期間（5/26〜7/31）の入会者14名（5月コラボ9・6月AI5）を記述まで精読。
一次資料：[訴求資料_5月note](訴求資料_5月note_夫に隠れて服を買ってた私が月5万.md)／[訴求資料_AI教科書](訴求資料_AI特典note_Threads×ChatGPT月2万教科書.md)。関連：[03_事前診断](03_事前診断_5月コラボvs6月AI比較.md)／[04_訴求×事前診断](04_訴求×事前診断_接続レポート.md)。

## サマリー（4つの問いへの結論）
- **なぜ5月=パート／6月=手取り15万+か** → **訴求が想定する"使える時間"が違うから**。5月「パート主婦がSNS運用代行で月5万」＝**時間をある程度使える人**像→パート・専業主婦が反応。6月「スキマ15分・AIで時短・月2万」＝**時間が全く取れないフルタイム層**にフィット→**定職があり収入は一定の会社員/フルパート（手取り15万+）**が「これなら私でも」と反応。
- **なぜ入会率（対実施）が上がったか（20%→42%）** → クリエイティブが**"時間はないが収入はある＝払える層"に母集団を純化**したから。5月は幅広く集め手取り一桁の"払えない層"も実施に混ざり入会率が下がった。
- **なぜライン追加が増えたか** → AIは**時流トレンド×誰でも参加できる啓蒙（「AI使ってる?」）×"スキマ15分・月2万"のハードル下げフック**で、低ハードルにリーチを最大化。
- **なぜ予約率・実施率が下がったか** → **悩みの顕在化不足＋動機が軽い（月2万ゆとり）＋面談前の顕在化装置なし＋受講生実績・SSコラボ感が薄い（相談会に行く理由が弱い）**。

## 中核メカニズム：「使える時間 × 支払い能力」で刺さりが分かれた
| | 5月コラボ | 6月AI |
|---|---|---|
| 訴求が想定する像 | **時間のあるパート/専業主婦**が月5万（1日2-3時間の"運用代行者の一日"） | **時間ゼロのフルタイム層**がスキマ15分で月2万（寝る前・AIで時短） |
| だから集まる層 | パート・専業主婦・逼迫層（**払えない層も多い**） | 定職あり・時間なし・**手取り15万+の会社員/フルパート（払える）** |
| 手段 | SNS運用代行（作業時間がそれなりに要る） | Threads×AIで時短（作業時間を圧縮） |
| 結果 | 予約は多いが入会率↓（手取り一桁は払えず） | 予約は少ないが入会率↑（払える層に純化） |

### なぜ会社員・手取り15万+に刺さったのか（3つの理由）
1. **時間制約の一致（最大要因）**：フルタイム会社員/フルパートは「もう1つバイトを増やす」が物理的に無理（「アルバイトに出る時間もない」「掛け持ちは子との時間が…」）。5月の"時間のあるパート主婦が運用代行"は自分ごと化しにくいが、**6月の"スキマ15分・AIで時短"は"時間がない自分でもできる唯一解"に見えた**。
2. **AIへの親和性（ユーザー仮説＝一部その通り）**：会社員は業務でPC/AIに触れており（別voiceに「今の会社はAI事務使ってます」）、**「AIでもっと効率的に収入を増やせそう」なイメージが湧きやすい**。→ 啓蒙型クリエイティブに反応しやすいのは会社員側。
3. **支払い能力**：手取り15万+＝スクール（795,000円）を払える。5月で反応した手取り0-9万のパート/専業主婦は"払えない層"（専業主婦入会0）。

→ つまり**6月AIは「時間はないが収入はある」層をピンポイントで選別した**。だから**実施まで来た人の入会率が42%（5月コラボ約20%の2倍超）**＝入会率上昇の正体は「クリエイティブによる母集団の質（時間制約×支払い能力）の純化」。

## 予約率・実施率が下がった理由（クリエイティブ観点の統合）
- **悩みの顕在化不足**：6月は「AI使ってる?」啓蒙中心で悩みに触れず、痛みが立たない（→ 予約率30%）。5月は自己開示ストーリー＋面談前の準備3質問で顕在化（→ 予約率66%）。
- **教科書は"予約特典"（予約しないともらえない）＝予約の手前で止まっている**：教科書は欲しくても「もらうには60-90分の面談予約が必要」というハードルを越えられない。**特典をフックにしても予約率30%止まり**＝面談に行く動機づけ（運用代行への橋渡し・悩み顕在化）の弱さが本質的ボトルネック。
- **相談会（＝スクール）へ行く理由が弱い**：6月は**受講生実績の提示がなく、SSコラボ感も薄め**。「AIスキマ副業」で完結してしまい、「でもAIだけだと厳しい→他スキル（インスタ運用）を相談したい」という**面談に行く動機づけが作れていない**（※はあちゅう構図と同型）。

## パラドックス：運用代行への橋渡しがないのに、なぜ入会できたのか
**問い**：6月AIクリエイティブは「AIだけじゃダメ→運用代行→相談会で相談できる」という**面談に行く理由（＝運用代行への橋渡し）を作れていない**。なのに、なぜ面談に来た人は入会したのか？

**答え＝入会者は"AIに興味を持った人"ではなく、"もともと在宅ワーク/運用代行をやりたかった人"がAIの入口からたまたま入ってきた人**だった。証拠：入会5名の**申込時点（事前診断）の興味スキル**：

- 46歳 会社員 → **インスタ運用代行**
- 44歳 会社員 → **インスタ運用代行**
- 47歳 パート → **インスタ運用代行**
- 45歳 パート → **インスタ運用代行**
- 38歳 産育休 → オンライン秘書

→ **4/5がインスタ運用代行、残り1名もオンライン秘書。誰も「AI」ではない**。＝AI訴求で入ってきたのに、入会者の本命スキルは最初から運用代行系だった。

| 段階 | 何が起きたか |
|---|---|
| ライン追加（友98） | **AI×"スキマ15分・月2万"のハードル下げフック**が広く効き、好奇心層に加え**"時間のないフルタイム会社員/フルパート"まで**大量登録（＝リーチ拡大の主動力はAIトピックの広さ＋スキマ時間フック） |
| **予約の壁（予約率30%）** | クリエイティブが"面談に行く理由"を作らない→**予約まで進むのは"元々在宅志向がある一部"だけ**（好奇心層はここで脱落＝「ライン追加はするけど予約まで行かない」） |
| 面談→入会（入会率42%） | 橋渡し（運用代行への教育）は**クリエイティブでなく"面談そのもの"が担った**。通り抜けた少数は①元々運用代行志向②手取り15万+の払える層→高確率で入会 |

→ **クリエイティブは「橋渡し」を面談に丸投げしている**。結果、**予約率は低いが（好奇心層を取りこぼす）、通り抜けた人の入会率は高い（元々本気＋払える層に自己選別される）**。「スキルスキップ面談を受ける理由がない」＝**"自分の中に理由がある人"しか予約しない自己選別フィルター**が働き、入会率だけ高く出た。

**伸びしろ**：クリエイティブで「AIだけでは月2万止まり→本気で月5万なら運用代行→それを相談できるのが相談会」の橋を架ければ、**今は予約前に捨てている"在宅志向はあるが背中を押されていない層"を予約に乗せられる**（＝予約率を上げ、入会の絶対数を増やせる）。

## 面談を受ける理由：「あった/なかった」ではなく"位置づけ"が変わった
※noteは読まれない前提。**全員が見るストーリーズで検証**すると、**6月も受講生実績・相談会価値・SSコラボ感は"あった"**（例：ミキさん6ヶ月で月20万・当日入会報告／「何を相談していいか分からない人こそカウンセラーに」／「1年以上推しているスキルスキップ」）。＝「6月は実績・コラボ感が無かった」は誤り。本当の差は次の4点。

| 観点（ストーリーズ） | 5月 | 6月AI |
|---|---|---|
| 打ち出す金額 | **月5万〜**（→月10-20万の階段） | **月2万**（ゆとり）＝温度・切迫度↓ |
| 運用代行の位置づけ | **本命・最短ルート**（発信者は挫折／運用代行は1ヶ月目から収益／適性診断で運用代行へ誘導、アンケ「運用代行86%」） | **"時間がかかって難しいもの"→だからThreads×AIで月2万を自分で**（＝運用代行を回避する方向） |
| 面談の必然性 | 「何をすべきか＝面談で診断」＋相談会（＝運用代行を売る場）と整合 | 教科書（予約特典）が"完成した自走ノウハウ"→相談会は「月2万をより現実的にする補助」に格下げ |
| キャンセル訴求 | 一部 | **頻発**（「無断キャンセルがいた」「誰が休んだか把握できる」）＝「みんなキャンセルしている」の社会的証明で実施率↓ |

- **本質**：6月は"面談を受ける理由の要素"が消えたのではなく、**①打ち出す金額を月2万に下げ ②運用代行を"避けるもの"に位置づけ ③教科書で自走ノウハウを渡した**ことで、**"スクール面談（＝運用代行を売る場）へ行く必然性"が構造的に弱まった**。＝**教育（自走Threads×AIで月2万）と出口（運用代行スクール）がねじれている**のが根本問題。
- → 伸ばすなら「Threads×AI＝入口（月2万）／本気の月5万は運用代行／それを相談するのが面談」と、**教育と出口を一直線に繋ぐ**（金額の階段を見せ、運用代行を"本命"に戻す）。
- **もう一つの"面談を受ける理由"＝「話して自分を整理する場」**：運用代行や金額の話だけが動機ではない。**「何がしたいか分からなくてもOK。話して気持ちと状況を整理するだけで、次の一歩が見える」**という"自分と向き合って整理する場"としての価値も、強い来訪動機になる（例：「何を相談していいか分からない人こそカウンセラーに」「自分が何が好きか・どんな生活を送りたいかを整理することから」）。これは**目標がまだ曖昧な受動層（＝AI流入の"見てるだけ層"52%）にこそ効く**汎用的な理由で、5月・6月とも使われていた。→ AI流入導線では、この**"整理して前に進める"訴求を前面に出す**と、まだやりたいことが定まらない層の予約の背中を押せる。

## クリエイティブへの示唆（＝次のCR設計）
- **AIの入口は残しつつ、"AIだけでは足りない→インスタ運用を相談したい"の橋を架ける**：スキマAI（月2万）で入口を広げ、「本気で月5万+なら運用代行、その相談ができるのが相談会」と**面談に行く理由**を明示（5月の階層提示を6月導線にも接続）。
- **6月に欠けた"受講生実績"を戻す**：同属性（40代・会社員/フルパート・手取り15万+）の成功事例を提示し、"払える層"の確信を後押し。
- **キャンセル訴求（「無断キャンセルがいます」等の希少性・煽り）の頻度を抑える**：反復すると「みんなキャンセルしている」と学習されキャンセルを誘発しうる。実績・カウンセラー紹介・意気込みなど"行きたくなる"コンテンツに置換。
