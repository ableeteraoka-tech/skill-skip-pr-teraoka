# 仮説整理：maki 9月末PR × しょうごっこ 7月PR（working）

寺岡の仮説メモを整理し、ストーリーズ文字起こし（maki 9/25〜10/3、しょうごっこ 7/1〜7/27）と事前診断で整合性を確認したもの。
判定：◎＝データと合う／○＝おおむね合う／△＝一部合わない・補足が必要

---

## 仮説の全体像（ひとことで）

makiさんの診断PRは「自分に向いている仕事の種類」を知る話になっていて、読み手は「私の能力で合うのか」を考える。だから「自分にもできそう」まで届かず、優先度が上がらない。

しょうごっこさんの7月PRは「働き方を変えたら生活がどう変わったか」を、本人とSARINAさんの2人の実話と金額で見せていた。さらに、動画を見る流れを途切れさせずにつないでいた。

---

## 仮説1：働き方を知るだけでは行動しにくい（maki）　判定：○

**合っている点**
- 診断の中心は「タイプ」と「向き不向き」。CTAも「自分に合う働き方を診断する」「自分の選択肢を知るところから」
- makiさん自身も「診断は仕事を決めるものというより、方向を知る最初のきっかけ」「相談会は何かを決める場所じゃない」と、決める必要のなさを伝えている。安心にはなるが、今やる理由は弱くなる
- 事前診断では、興味スキル「その他」が12%から28%に増え、「見ているだけ」も42%から56%に増えた。知ったあとに何をするかが見えていない

**補足**
- 予約者に限ると、本気度が低いとは言い切れない。「今すぐ始めたい」は61%で8月と同じ。自由記述でも「工場勤務を辞めたい」「派遣を辞めたい」「離婚に向けて自立したい」と、変えたい気持ちは強い
- 本気度が低いのは、予約しなかった大多数のフォロワー（LINE追加がKPI120に対して18）の話として分けて書いた方が正確
- 予約者の問題は本気度より、**気持ちはあるのに一歩目のイメージがない**こと（自分で調べている／行動している人は22%から0%に）

## 仮説2：makiさんの訴求は「働き方の種類」の話で、能力に合うかが前に出る　判定：◎

**合っている点**
- 診断の結果は5タイプ（発信者・動画編集・サポーター・デザイン・ディレクター）。BOOKもタイプ別の仕事の始め方
- 読み手の反応がそのまま能力の話になっている
  - 「向いてる仕事は分かったけど、50代の私にも本当にできるんでしょうか？」（9/26 ストーリーズ）
  - 「まきさんの診断では発信者タイプでしたが…発信能力はないと思います」（事前診断）
  - 「デザインタイプだったので、センスないのにできるのか不安でした」（10/2 感想DM）
- タイプが当たっていても外れていても、「私にできるか」という問いが生まれる。8月の「秘書さんの実話×月10万」は、能力より「この人みたいな生活」を見せていた

## 仮説3：makiさんも実績訴求はしている　判定：○

- 9/27〜28に「パート掛け持ちで手取り10万前後、サッカーシューズを買い替えられなかった」→「月収3倍以上、娘と岩盤浴、家族で外食」の話がある
- 秘書さんの「1万→3万→5万→7万」も出ている（9/28）

**補足**
- 実績が出たのは最終盤の2日間で、その日のCTAも「診断」のまま。実績から「私もこの生活に近づきたい」と思っても、次の行動は「タイプを知る」になっていた
- 実績の主語がmakiさん本人と秘書さんだけで、読み手と同じ立場の受講生の金額つき事例がない

## 仮説4：しょうごっこさんは、物理的な働き方とライフスタイルの話をしている　判定：◎

- 軸は「海の上でスマホも使えない働き方」から「家族を最優先にできる在宅パパ」への変化（7/12、7/18）
- SARINAさんの対談の目次は「受講中のスケジュール」「家事・育児・本業との両立術」「時間をつくる方法」（7/20〜22）。1日の過ごし方が具体的
- 「息子さんが在宅で働くママをかっこいいママと言ってくれた」（7/1）と、生活の場面で語っている
- 読み手の反応も生活の言葉になっている：「子どもとの時間をもっととれるようにしたいという声がたくさん届いた」（7/15）

## 仮説5：しょうごっこさんは実績を金額で見せている　判定：◎

- SARINAさん：会社員・1児ママ、6か月で累計52万円・継続案件5件（7/21〜24）
- 読み手の質問「未経験で月5万円ってどんな仕事？大丈夫なヤツですか？」に正面から答えている（7/10）
- 「月10万給料が増えることはない」と、目標額も明確（7/17、7/24）
- 本人以外の、読み手に近い立場の人の金額つき実績がある。makiさんとの一番大きな違い

## 仮説6：「楽で楽しくて稼げる」は怪しく感じる　判定：○（言い方を変えた方がいい）

- 9月末の予約者は、他社の無料相談に参加済みが22%。「スクールで借金だけ残った」「怪しい副業支援の人が多い」と不信も強い
- しょうごっこさんは「楽」とは言っていない。SARINAさんの「気合いで頑張った」がそのまま響いている（7/25の感想DMで、「気合いで頑張った」という言葉に共感した声）。怪しさには、代表への質問対談（7/17）や「大丈夫なヤツですか？」へのQ&Aで向き合っている
- 方向性としては「楽で楽しい」より、**「今の生活の中で無理なく続けられて、ちゃんと金額になる」**の方がよい。苦労も見せた方が信用される

## 仮説7：しょうごっこさんのフォロワーは動画を見る習慣がある　判定：◎

## 仮説9：makiさんは「howの教育」（インスタの仕事の中身・始め方）がほぼない　判定：◎（しょうごっこさんはあった。ただし種類が違う）

### maki 9月（9/1〜9/28 ストーリーズ）
ストーリーズで語っているhowは、ほぼ「自分の向き不向きを知る」こと。仕事そのものの中身や、仕事になるまでの道筋はほとんど出ていない。

| 出ていたもの | 日付 | 量 |
|---|---|---|
| 秘書さんが低単価案件から運用代行（資料作成・データ分析して提案）に移り、月1.5万から約10万に | 9/16 | 1〜2枚 |
| 秘書さんの仕事の例（スケジュール管理、請求書管理） | 9/20 | 1枚 |
| 動画編集は「スマホで撮った動画のいらないところを切って、文字を入れるくらいから」 | 9/18 | 1枚 |
| BOOKの目次（応募のきっかけ、Canvaで収入を得る手順、クライアントワークの6つのこと など） | 9/27〜28 | 目次だけ |

- 仕事の中身は「診断 → スクショをDM → BOOK」の先にしかなく、ストーリーズを見ているだけの人には届かない
- その結果、事前診断では興味スキル「その他」28%、「50代の私にもできる？」「発信能力はない」という声が出ている。タイプはわかっても、その仕事を自分がやっている姿が浮かばない

### しょうごっこ 7月（7/1〜7/27 ストーリーズ）
howはあった。ただしスキルの手順ではなく、**仕事になるまでの道筋と、時間の作り方**が中心。

| 内容 | 日付 |
|---|---|
| 「未経験で月5万ってどんな仕事？」に「発信してる人やお店の裏方。投稿を作ったり、コメントに返したり」と答える | 7/10 |
| VSLの予告で「月5万から10万の仕事にしていった方法、実際の仕事内容まで具体的に」 | 7/9 |
| SARINAさん：ポートフォリオ作成の案件（倍率39倍）を応募文で勝ち取った | 7/18 |
| 対談の目次：初案件獲得の秘訣、案件応募で気をつけたこと、ポートフォリオ制作の裏話 | 7/20〜22 |
| 勉強した時間：メイク中、料理中、寝かしつけ後の2〜3時間 | 7/23 |
| 体験会：自分のスマホで実際に動画編集してみる | 7/26〜27告知 |

- 細かいhowは動画（VSL・対談）の中にあり、ストーリーズではその目次と一部を見せて「動画で見たい」を作っていた
- howの主語が「読み手と同じ立場の人」（会社員ママ・保育士ママ）。「この人の手順なら私もなぞれる」と思える

### 違いのまとめ
- makiさん：howは「自分を知る」まで。その先は資料（BOOK）に預けている
- しょうごっこさん：howは「仕事を取るまで」と「時間を作るまで」。実在の人の体験として、動画で見せている
- 次回の診断PRでは、タイプ別に「その仕事の1日」「最初の1件をどう取ったか」を受講生の実例で見せるところまでを、ストーリーズ上で出す必要がある

## 仮説10：「相談会で自分に合う仕事を知ろう」は、人が教えてくれるのを待つ姿勢を作る　判定：◎

### makiさんの相談会の打ち出し方
- 「無料相談会で、自分に合った始め方を整理する」（9/26）
- 「相談会は何かを決める場所じゃなくて、自分にはどんな選択肢がある？を一緒に整理する時間」（9/27）
- 「カウンセラーさんに診断結果を伝えたら、自分の生活に合わせて何ができそうか教えてくれるよ」（10/3）
- 「肩の力を抜いてリラックスして」「人生相談の場所」（10/1）

診断も相談会も、答えを外から受け取る形になっている。診断は「ツールがタイプを教えてくれる」、相談会は「カウンセラーが合う仕事を教えてくれる」。読み手が自分で考えたり、試したりする場面がない。

### 事前診断の「相談したいこと」で確認
「教えてほしい／何から／自分に何ができるか／分からない」系の割合

| | 割合 |
|---|---:|
| maki 8月 | 40%（27/67） |
| **maki 9月末** | **87%（13/15）** |
| しょうごっこ 7月（勉強会タグの7月分） | 43%（10/23） |
| しょうごっこ 8月 | 37%（48/131） |

maki 9月末の実際の声：
- 「分からないので一から教えていただきたいです」
- 「何から始めればいいのか、何を勉強すればいいのか教えていただきたいです」
- 「聞きたい事や相談したい事もまだよく分からない」
- 「未定」

しょうごっこさんの7月は、同じ「知りたい」でも確かめたい中身がはっきりしている。
- 「未経験でどれぐらいで収益化できるのか。スキルアップはいくらかかるのか」
- 「勉強中に仕事をいただくことはできるのか」
- 「運用代行について詳しく知りたい」
- 「詐欺案件とか動画で言ってたから、引っかからないか不安」（動画を見たうえでの質問）

### 読み
- makiさん：何をしたいかを決めていないまま「教えてもらいに行く」予約になっている。目的が本人の中にないので、日が近づくと優先度が下がり、事前キャンセルや未回答につながる
- しょうごっこさん：動画で道筋（仕事内容・案件の取り方・時間の作り方）を見たあとに予約するので、「自分の場合はどうか」を確かめに行く予約になっている
- 相談会を「なんでも話してOK」と打ち出したのはしょうごっこさんも同じ（7/13）。違いは、予約する前に読み手が自分で考える材料を持っていたかどうか
- 次回は、予約前に読み手に自分で一歩動いてもらう（体験・自分で答える問い・聞きたいことを1つ決めて予約）設計にして、相談会を「確かめに行く場」にする

※しょうごっこさんのデータは勉強会タグの7月分で、7月PR経由の予約と完全には一致しない可能性あり。重複行は除いていない
