## makiさん 9月末PR｜キャンセル要因分析（しょうごっこさん7月PRとの比較）

### サマリー

- makiさん9月末PR（おうち仕事診断→無料相談会）のキャンセル率は67%。8月ローンチの41%から大きく悪化
- 穴は事前キャンセル（8件）と、事前診断未回答による自動キャンセル。当日の無断キャンセルは1件だけで、予約後に「行く理由」が消えている
- 同じ在宅ワーク訴求で数値のよかったしょうごっこさん7月PRと比べると、大きな要因は3つ
  1. **howがない**：仕事の中身・始め方・最初の1件の取り方がストーリーズに出ていない
  2. **「自分に合うか」を問う訴求**：makiさんは能力の話、しょうごっこさんは生活の制約を変えた話
  3. **待ちの姿勢**：makiさんの予約者は「教えてもらいに行く」、しょうごっこさんの予約者は「確かめに行く」
- 次回のしょうごっこさん診断PRで同じことが起きないように、診断を「タイプを知って終わり」にせず、howと見本の人まで見せる設計にする

### 数値（makiさん 9月末PR、10/6時点）

| | 9月末PR | 8月ローンチ |
| --- | --- | --- |
| 新規面談（確定分） | 18 | 61 |
| 着席（RG違反の実施を含む） | 6 | 36 |
| 事前キャンセル | 8 | 9 |
| 自動キャンセル（事前診断未回答） | 3 | 6 |
| 当日キャンセル（無断） | 1 | 10 |
| キャンセル率 | 67% | 41% |
| キャンセル者のうち事前診断未回答 | 42% | 約24% |

- 9月末は面談日が10/9まであり、未処理4件。入会は体験授業経由で1件
- 事前キャンセル8件のうち2件はLINEブロック

---

### 要因①：howがない

| | makiさん 9月 | しょうごっこさん 7月 |
| --- | --- | --- |
| ストーリーズのhow | 「自分の向き不向きを知ろう」が中心 | 仕事の中身、案件の取り方、時間の作り方 |
| 仕事の中身 | 秘書さんの運用代行、動画編集の入口がそれぞれ1〜2枚 | 「発信してる人やお店の裏方。投稿を作ったり、コメントを返したり」と質問に正面から答える |
| 最初の1件 | なし | 倍率39倍のポートフォリオ案件を応募文で取った話、初案件獲得の秘訣 |
| 時間の作り方 | なし | メイク中・料理中・寝かしつけ後の2〜3時間で勉強 |
| howの置き場所 | 診断→DM→BOOKの先（ストーリーズでは目次だけ） | 動画（VSL・対談）。ストーリーズで目次とさわりを見せる |

- makiさんの仕事の中身は、診断を受けてBOOKを受け取った人にしか届かない
- 事前診断では興味スキル「その他（選択肢にない）」が12%から28%に増え、インスタ発信は29%から6%、オンライン秘書は20%から0%に減った。タイプはわかっても、その仕事をしている自分が浮かんでいない

### 要因②：「自分に合うか（能力）」と「働き方を変えた（物理的な制約）」

| | makiさん 9月 | しょうごっこさん 7月 |
| --- | --- | --- |
| 訴求の軸 | どの仕事が自分の性格・得意に合うか | 時間と場所の制約がある働き方から、家族を優先できる働き方へ |
| 読み手が考えること | 私の能力で、その仕事ができるか | 私の生活でも、この働き方ができるか |
| 見本の人 | makiさん本人と秘書さん | しょうごっこさん本人（元海上保安官）と、会社員1児ママのSARINAさん |
| 実績の見せ方 | makiさんの月収3倍、秘書さんの1万→7万（最終盤の2日間） | SARINAさん6か月で累計52万・継続案件5件、未経験で月5万→10万 |

- 能力を問う訴求は、タイプが当たっても外れても「私にできるか」という不安を生む
  - 「向いてる仕事は分かったけど、50代の私にも本当にできるんでしょうか？」
  - 「診断では発信者タイプでしたが…発信能力はないと思います」
  - 「デザインタイプだったので、センスないのにできるのか不安でした」
- しょうごっこさんの訴求は生活の場面で語られていて、反応も「子どもとの時間をもっととりたい」という生活の言葉で返ってきている
- しょうごっこさんは「楽に稼げる」とは言っていない。SARINAさんの「気合いで頑張った」がそのまま共感を集めている。苦労も見せることで、怪しさが薄れている

### 要因③：makiさんは待ちの姿勢、しょうごっこさんは確かめに行く姿勢

**makiさんの相談会の打ち出し方**
- 「無料相談会で、自分に合った始め方を整理する」
- 「相談会は何かを決める場所じゃない」
- 「カウンセラーさんに診断結果を伝えたら、何ができそうか教えてくれるよ」

診断は「ツールがタイプを教えてくれる」、相談会は「カウンセラーが合う仕事を教えてくれる」。読み手が自分で考えたり試したりする場面がない。

**しょうごっこさんの7月**
- 予約前に動画で道筋（仕事内容・案件の取り方・時間の作り方）を見ている
- 質問を募集して、対談の中で答えている（「みんなから預かった質問を詳しく聞いてきた」）
- 8月は、自分のスマホで実際に動画編集をしてみる体験会へつないでいる

**事前診断の「相談したいこと」を、相談への姿勢で3つに分けた**

| タイプ | 中身 | 例 |
| --- | --- | --- |
| A. おまかせ型（待ち） | 何を聞くかがまだ決まっていない。教えてもらうのを待っている | 「分からないので一から教えてほしい」「何から始めればいいか教えてほしい」「未定」 |
| B. 不安確認型 | 自分にできるか、向いているかを確かめたい | 「パソコンスキルもないけど何ができるか」「マメじゃないけど出来るのか」 |
| C. 具体確認型（積極） | 確かめたい中身が決まっている。お金・期間・仕事内容・案件の取り方など | 「どれぐらいで収益化できるか」「勉強中に仕事をもらえるか」「案件をもらうにはどうするか」 |

| | A. おまかせ型 | B. 不安確認型 | C. 具体確認型 |
| --- | --- | --- | --- |
| makiさん 8月 | 31% | 25% | 43% |
| makiさん 9月末 | **47%** | 27% | **27%** |
| しょうごっこさん 7月 | **13%** | 20% | **67%** |

- 1人の回答に複数の要素がある場合は、C→B→Aの順で優先して分類
- makiさん9月末・しょうごっこさん7月はそれぞれ15人なので、1人で約7ポイント動く

**読み**
- makiさん9月末は、おまかせ型が半数近く。8月より16ポイント増え、具体確認型は16ポイント減った。何を聞くか決めないまま予約している
- しょうごっこさん7月は、具体確認型が3分の2。動画で道筋を見たあとなので、「収益化までの期間」「費用」「勉強中に仕事をもらえるか」「詐欺案件とか動画で言ってたから不安」と、確かめたいことがはっきりしている
- 不安確認型（自分にできるか）は、どちらも2割前後でほぼ同じ。差がついているのは、おまかせ型と具体確認型の比率
- しょうごっこさんの8月（勉強会）はA32%・B26%・C43%で、makiさん8月とほぼ同じ。7月の具体確認型の多さは、動画で道筋を見せた7月PRの特徴と考えられる

**makiさん9月末の実際の声（A. おまかせ型）**
- 「分からないので一から教えていただきたいです」
- 「何から始めればいいのか、何を勉強すればいいのか教えていただきたいです」
- 「漠然と興味を持って調べているだけなので、どんな仕事があるのか詳しく聞きたいです」
- 「聞きたい事や相談したい事もまだよく分からない」

**しょうごっこさん7月の実際の声（C. 具体確認型）**
- 「未経験でどれぐらいで収益化できるのか。スキルアップはいくらかかるのか」
- 「勉強中に仕事をいただくことはできるのか。費用はどれくらいかかるのか」
- 「まず何から始めればいいのか、運用代行について詳しく知りたい」
- 「本業と2本立てでやる場合の税金面」

相談会を「なんでも話してOK」と打ち出したのは、しょうごっこさんも同じ。違いは、予約する前に読み手が自分で考える材料を持っていたかどうか。目的が本人の中にない予約は、日が近づくと優先度が下がり、事前キャンセルや事前診断の未回答になる。

### 要因④：面談に行けた人は、行く理由を最初から自分で持っていた

PRで行く理由を作れなかった中で、着席した人はなぜ来られたのか。事前診断の回答を、着席した人とキャンセルした人で比べた。

**着席した7人（RG違反の実施を含む）**

| | 年齢・状況 | 悩み始め | 今の働き方 |
| --- | --- | --- | --- |
| 事例1 | 46歳・23年勤めた正社員を3月に退職。来月からカフェのパートだが、収入が全然足りない | 3ヶ月前 | 辞めた |
| 事例2（RG違反） | 45歳・子どもの不登校で7月に退職。失業保険を受給中 | 1年以上 | 辞めた |
| 事例3（入会） | 46歳・会社員。離婚を考えていて、経済的に自立しないといけない | 1年以上 | 自立が必要 |
| 事例4 | 52歳・パート、手取り8万。「空いている時間がたくさんある」 | 6ヶ月 | 続けながら上乗せ |
| 事例5 | 48歳・派遣、残業40時間で賞与なし。来年10月に辞めると決めている | 6ヶ月 | 辞めたい（期限あり） |
| 事例6 | 33歳・工場の2交代勤務。「年齢的にもこの働き方はもう辞めたい」 | 1年以上 | 辞めたい |
| 事例7 | 44歳・パート。「仕事ばかりの生活、働き方を変えたい」 | 1年以上 | 変えたい |

- 全員、PRの前から悩んでいた（3ヶ月〜1年以上）。PRをきっかけに悩み始めた人はいない
- 7人中6人が、すでに辞めた・辞めると決めている・離婚で自立が必要、のどれか。今の働き方を続けられない事情を、もともと持っていた
- 唯一の上乗せ型（事例4）は、体験授業まで進んだが費用面で失注

**キャンセルした8人（事前診断の回答あり）**

- 半分（4人）が、今の仕事を続けながら収入を上乗せしたい人
  - 「今の仕事は10年以上勤めた好きな仕事」
  - 「今のパートは好きなので続けたい」
  - 「貯金できるぐらいの収入がプラスでほしい」
  - 「月々の収入を増やしたくて」

**読み**
- 悩みの期間や「今すぐ始めたい」の割合は、着席した人とキャンセルした人でほぼ同じ。差が出たのは悩みの深さではなく、今の働き方を続けるのか、終わらせるのか
- PRが行く理由を作ったのではなく、変える理由をもともと持っていた少数が残った。変えなくていいと思っている上乗せ型は、予約しても途中で離れている
- 入会した事例3は、意欲が「時期をみて始めたい」で、熱量が特に高い人ではなかった。決め手は体験授業での「楽しい、これが仕事にできたら」というイメージ。来る理由は本人の事情、決める理由は体験、と分かれている
- 次回のPRで「今変える理由」を作れれば、上乗せ型も面談まで残せる可能性がある
- 着席7人・キャンセル8人と人数が少ないため、傾向として扱う

### その他の要因

**予約前後の流れ**
- しょうごっこさん：VSL（7/12〜14）→代表との対談動画（予約特典）→SARINAさん対談（7/22〜24）→体験会の告知（7/26）と、見るものが途切れずに続いた。予約したあとにも次のコンテンツがあり、熱が冷めにくい
- makiさん：診断4日間で一本。最終日は「残り5枠」「迷ってる間にも動いてる人がいる」「今日23:59まで」が続き、勢いの予約が入った
- 予約後のmakiさんのストーリーズは、「当日のキャンセルや無断欠席はしないで」「カウンセラーさんが準備して待っている」とお願い中心。一方、参加者の感想DM（勧誘されなかった／センスがないと思っていたけど体験に進めた／秘書さんの事例で始める順番がわかった）は、行く理由を作る投稿として効いていた

**動画を見る習慣（しょうごっこさん）**
- 長尺動画の予告とカウントダウン、「片付けやスキンケア中にラジオ感覚で」と見るハードルを下げる一言。「動画みました」の感想DMがほぼ毎日届き、対談動画は配布2日目で402件

**来た層の変化（makiさん）**
- 芯は8月と同じ（40代・既婚・子あり・貯金0円が半数・今すぐ始めたい約6割）
- 35〜39歳が20%から0%に、50代が6%から17%に増えた
- 「見ているだけ」が42%から56%に増え、自分で調べている・行動している人は22%から0%に
- 離婚・夫婦関係の悩みが1%から28%に。決裁や支払いの壁が厚い層で、RG違反1件もここから出ている

### 次回に向けて：しょうごっこさん（診断PR）

- 診断を「タイプを知って終わり」にしない。タイプごとに「その仕事の1日」「最初の1件をどう取ったか」を、読み手と同じ立場の受講生の実例で見せる
- 訴求の軸は、これまでどおり「働き方を変えたら生活がどう変わったか」。診断は「自分の生活に合う働き方を見つける入口」として置き、能力の診断に見せない
- howの深い部分は、ストーリーズで目次とさわりだけを見せて、動画で受け取ってもらう（7月の型）
- 予約前に、読み手が自分で一歩動く場面を入れる（質問を募集して動画で答える、体験してみる、聞きたいことを1つ決めて予約する）
- 予約後も次に受け取るコンテンツを用意して、熱が切れないようにする。事前診断は、来る理由を言葉にする場として案内する

### 次回に向けて：makiさん

- ストーリーズ上でhowを出す。秘書さんの運用代行の仕事内容、1日の流れ、最初の案件の取り方を、BOOKの外でも見せる
- 見本の人を増やす。makiさん本人と秘書さんに加えて、読み手と同じ立場（40代・パート・子ども2人など）の受講生の金額つき事例を出す
- 相談会の打ち出しを「教えてもらう場」から「自分の場合を確かめに行く場」に変える。予約前に、診断結果をもとに聞きたいことを1つ決めてもらう
- 締切の煽りは、相談会に行く理由を作ってから重ねる。予約後は義務感に訴えるお願いより、参加者の感想DMで行く理由を思い出してもらう
- 離婚・自立の悩みの層は決裁や支払いの壁が厚い。この切り口を続けるかは、入会の数字も見て判断する
