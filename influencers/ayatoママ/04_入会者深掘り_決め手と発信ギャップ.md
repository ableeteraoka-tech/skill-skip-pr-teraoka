# Ayatoママ 入会者深掘り ｜ 決め手 × カウンセリングの位置づけ比較（5月 vs 6月）

入会6名（5月コラボ4・6月キャンペーン訴求2）の面談記述を精読し、「なぜ決まったか」を抽出。あわせて、その決め手が**発信（ストーリーズ）で予告されていたか**を5月末 vs 6月末で検証する。

## 1. 入会者の決め手 ── 5月 vs 6月

### 5月コラボ 入会4名
| 属性 | 決め手（要約） |
|---|---|
| 28歳・会社員・19万 | 話を聞く中で**自分にもできそう**と思えた（適性の不安解消） |
| 27歳・パート・10万 | **体験でできると思った**（青森で働き口なし・イラスト好き） |
| 診断未記入 | **担当が子育て中で話しやすい**＋**目標期間を提示**され今後がイメージできた |
| 41歳・パート・15万 | 体験で**夜の時間で受講イメージ**が湧き時間の不安が消えた＋信頼＋アフタースキップ |

### 6月キャンペーン 入会2名
| 属性 | 決め手（要約） |
|---|---|
| 31歳・パート・20万 | テレアポが辛く**やりたい気持ちが高かった**＋**夫が許可**（動機＋家族承認） |
| 34歳・専業・0円 | 体験で**画像作りが楽しい＝これが仕事になるなら**（元高校教員） |

### 比較（決め手の型）
| | 5月コラボ | 6月キャンペーン |
|---|---|---|
| 決め手の型 | **体験で「自分にもできそう」**（適性・時間の不安が消えた） | **体験で「楽しい・仕事になる」**（動機＋家族承認） |
| 効いた要素 | 担当への共感・アフタースキップ・目標期間＝**"続けられる"安心** | 強い動機（現職が辛い）・夫の承認 |
| 共通 | **カウンセリング単体でなく"体験"が決め手**／**低手取り（10万・0円）でも入会** | 同左 |

→ 5月＝「**できそう（不安解消）**」で決まる／6月＝「**楽しい・やりたい（動機）**」で決まる。ただし両群とも**体験で腑に落ちた瞬間**が共通の引き金。＝発信で「体験を受けると"できそう／楽しい"が分かる」を予告できれば質の高い予約になる。

## 2. 面談前の不安（聞きたいこと） ── 5月 vs 6月

| | 5月コラボ | 6月キャンペーン |
|---|---|---|
| 聞きたいこと | 「私に**適性があるか**」「何を聞いたらいいかも分からない」「イラスト・雛形作りが**活かせるか**」 | 「**スキルがなくても**始められるか」「どんな仕事があるのか、**お金がかかるのか**」 |
| 不安の芯 | **自分にできるか**（適性・活かせるか） | **仕事の実像と費用**（何をする・いくら） |

→ 共通の不安は **適性・進め方・費用**。5月は"自分にできるか"、6月は"何の仕事でいくらか"に寄る。どちらも**相談会の"来る理由"＝「この不安が体験で解消される」**と伝えることに尽きる。

## 3. カウンセリングの「位置づけ」 ── 5月 vs 6月 徹底比較

相談会（無料カウンセリング）を**"どういう場所"として売ったか**。ここが5月と6月で最も違い、RG違反0 vs 5の分かれ目になった。

### 3-1. 全比較（相談会の売り方の9項目）

| 軸 | 5月コラボ（5/30–31・14枚） | 6月キャンペーン（6/24–30・9枚） |
|---|---|---|
| ①何をする場所か | **解像度が上がる場所**「何から始めるか分からない→SNSの仕事ってこういうことね、と見える」 | **人生相談・何でも相談OK**（"働き方相談"で曖昧） |
| ②仕事像（何の仕事か） | **SNS運用代行を明示**「ayatoママのようなアカウントを手伝う」 | **明示なし**（"どんな在宅ワークが向いているか相談できる"止まり） |
| ③実績・証拠 | **入会者の実績**「受講生が入会2ヶ月で案件獲得」「私も運用代行してもらってる」 | **相談会の体験談**「無料相談会に参加したら理想を叶えた」 |
| ④来る理由 | 無料で解像度・**他と比べる前提でOK**・無理な勧誘なし・自分も体験した | **アマギフもらえる・今だけ・締切**・「1時間が30年を変える」 |
| ⑤特典の扱い | アマギフ1,000円は**最後に軽く** | **アマギフ1,500円を前面** |
| ⑥対象 | 在宅したいママ（子供軸） | 働き方に悩む人全般（ママ以外に拡大、but仕事像なし） |
| ⑦訴求タイプ | **入会訴求**（入会したらこんな仕事ができる） | **無料訴求**（無料で相談したら変わる） |
| ⑧頻度・助走 | 5/31に11枚集中＋**note先行を5/27–30に助走**（2段構え） | 6/24・25・30の3日9枚（**6月前半ほぼ空白・助走なし**） |
| 結果 | RG違反**0**・売上270万 | RG違反**5**・目的不一致流入 |

### 3-2. 一言でいうと（位置づけの差）

- **5月＝相談会は「入会後の仕事（運用代行）が見え、"何から始めるか"の解像度が上がる場所」**。＝**入会の前段**として機能。入会者の実績で「入会したらこうなる」を見せた（入会訴求）。
- **6月＝相談会は「無料で何でも相談できる場所（＋アマギフ）」**。＝**相談会そのものがゴール化**。仕事像も入会者実績もなく、無料・特典が主役に（無料訴求）。

→ この**"位置づけ"の差**が、来る人の質（RG違反0 vs 5）をそのまま分けた。5月は「何の場所か」が明確で目的の合う人だけが来た。6月は「無料で何でも」だから目的の違う人（特典目当て・コンテンツ販売・ターゲット外）まで来た。

### 3-3. ★両月に共通する穴＝「悩み・理想を整理する場所」という位置づけ

相談会を"どういう場所"かで見ると、**5月は◎だが1つの角度が両月とも欠けている**。

| 位置づけの角度 | 5月 | 6月 |
|---|:--:|:--:|
| 働き方を知れる（解像度が上がる） | ◎ | △ |
| 悩みを言語化してくれる | ○（体験談経由） | △（1回・箇条書き） |
| **悩み・理想を整理する場所／整理しないと先に進めない** | **✗** | **✗** |

- どちらの月も「**まず悩み・理想を整理する入口**」という位置づけは語られていない。6月は「理想を叶える最短ルートが明確になる」と**ゴールを提示する方向**に寄った。
- 事前診断で「まだ何もしてない」が**5月コラボ21%・6月キャンペーン56%**、入会者も「何を聞いたらいいかも分からない」＝**整理できていない層が主**。「カウンセリング＝悩み・理想を整理して動けるようにする場所、整理しないと一歩も進めない」はこの層にドンピシャで、かつ間口が"在宅を考えている人"に絞られてRG違反も減る。＝**5月・6月に共通する最大の伸びしろ**。

## 4. 示唆（相談会の位置づけの直し方／打ち手の総括は[01 §4](01_2経路比較_コラボvs面談経由.md)）

1. **"体験で解像度が上がる"を平時から予告**：入会者全員の決め手。月末集中でなく継続的に（5月末の型を平時に薄く広げる）。
2. **カウンセリングを「悩み・理想を整理する場所」と位置づける**（§3-3の穴）：「まず現状と理想を整理しないと先に進めない、それを一緒にやる場所」。"まだ何もしてない"層に刺さり、間口が絞れてRG違反も減る。「人生相談／何でも相談OK」の広げすぎは封じる。
3. **"来る理由"を不安ベースで語る**：「適性が不安な人ほど来て」「低手取りでも決めた人がいる」。
