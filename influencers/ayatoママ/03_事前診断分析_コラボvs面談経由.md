# Ayatoママ 事前診断分析（5月コラボ vs 6月キャンペーン訴求）

元データ：[2026_事前診断_ayatoママ.tsv](2026_事前診断_ayatoママ.tsv)。群分けは**紹介者タグ**：
- **5月コラボ**（もしも//Ayatoママコラボ）＝5月末告知のスキルスキップコラボ本番
- **6月キャンペーン訴求**（もしも//面談経由//Ayatoママ）＝6月末のアマギフ企画

**分母の取り方（重要）**：属性・悩み・理想は**新規カウンセリングで事前診断を記入した実人数**が分母（**5月コラボ n=12／6月キャンペーン訴求 n=12**）。
- 延べ予約（5月コラボ28・6月キャンペーン18）には、**体験授業・契約決済など同一人物の後続レコード**や、**キャンセルで診断未記入の予約**が含まれるため、属性分析では除外する。
- ファネル数値（予約・実施・入会・売上）は**公式月次**を使う（面談予約＝5月コラボ19・6月キャンペーン13）。

## 2. 悩みの深掘り

### 選択式（複数回答）
| 悩み | 5月コラボ | 6月キャンペーン訴求 |
|---|--:|--:|
| 働き方に関する悩み | **83%** | 75% |
| 収入に関する悩み | 67% | 75% |
| キャリア形成 | 17% | **50%** |
| スキル | 33% | 17% |

→ 両群とも「収入×働き方」が二枚看板。**6月キャンペーン訴求は"キャリア形成"意識が突出**（50%）＝就業層らしく「この先のキャリアをどうするか」に踏み込んでいる。

### 自由記述の頻出テーマ（voice of customer）

**5月コラボ（専業ママの再スタート）**
1. **子どもとの時間を守りたい×家計の足し**「子どもとの時間を増やしたく仕事を辞め専業に。でも学費・老後・お小遣いが不安」
2. **専業からの再開の迷い**「子供が1歳を超えたので働きたいが、預けて働くビジョンが見えない」
3. **転勤族で働けない**「1年毎に転勤、夫の仕事も不定期で私が働くと時間が合わない」
4. **持病の子・不安定なパート**「子が持病持ちでパートに変えられ、時給が最低賃金以下」
5. **好きな仕事だが低収入**「保育士の仕事は好きだが収入が釣り合わず将来が不安」

**6月キャンペーン訴求（転機・就業層）**
1. **体力的にフルタイムが辛い**「元々体が弱くフルタイムが辛い。通勤も負担」「短時間パートだと手取り9万で生活が厳しい」
2. **転職・転勤の転機**「県外転居で転職検討」「夫の海外転勤に帯同、辞めるかも」
3. **専門職からの転換**「介護士・看護師で土日災害時も勤務、自宅でできる仕事に」
4. **出産・産育中**「出産予定で在宅で何かできないか、でもスキルがない」
5. **老後・将来不安**「安定はあるが給料が上がらず老後資金が不安」

→ 5月コラボは**"育児と両立したい専業ママの再スタート"**、6月キャンペーン訴求は**"就業しているが転機・体力・将来不安で在宅を探す層"**。悩みの手触りが違う。

## 4.5 入会者の属性（5月コラボ vs 6月キャンペーン訴求）
入会6名（5月コラボ4・6月キャンペーン訴求2）を分解。※小さいnなので傾向として読む。

| | 5月コラボ 入会4 | 6月キャンペーン訴求 入会2 |
|---|---|---|
| 年齢 | 28・27・41歳＋1 | 31・34歳 |
| 婚姻/子 | 既婚子あり2・未婚子なし1・他1 | 既婚2（子なし1・子2人1） |
| 職業 | パート2・会社員1・他1 | パート1・専業1 |
| 手取り | 10万・15万・19万・他 | 20万・**0円** |

### ★ Ayatoは「低手取りでも入会する」
- **5月コラボでパート手取り10万・6月キャンペーン訴求で専業手取り0円が入会**している。＝「払える層かどうか」より、**守りたいもの＋在宅の必要性が明確なら低手取りでも決まる**。
- ただし母数が小さく（実施12・有効面談5）、絶対入会数（4・2）はまだ少ない。伸ばすレバーは**「若年/低所得を増やす」ではなく、6月キャンペーン訴求のRG違反を減らして有効面談を増やす×体験授業の転換**。

## 5. ⚠️ 決まらない理由（入り口と出口を分ける）

### A｜RG違反 ＝ 入り口で層がズレた（6月・7月に5件）
特典目当て／目的不一致／ターゲット外の3タイプ。理由の詳細と発信要因は [02](02_事前診断×文字起こし_発信と流入の質.md)・[01 §2](01_2経路比較_コラボvs面談経由.md)。

### B｜入会率が低い ＝ 出口で即決しない（対象内だが背中を押せない）
実施したのに決まらなかった人の理由（優先度順）：
1. **体験授業への移行が標準運用**（5月コラボ）：カウンセリング→体験の2段階で、未入会の多くは「体験移行＝保留」。**入会は体験の転換率で見るべき**。
2. **夫・家族相談**（両群）：専業・手取り0円は金額が大きく夫承認待ち。「家族相談」が頻出。
3. **与信が通らない**（5月コラボ）：CBS審査否決（夫収入合算でも否決）で入会キャンセル。低所得層の壁。
4. **自己効力感・時間の不安**（両群）：「本当に継続できるか」「2時間ちゃんと取れるか」。
5. **体験の見せ方が逆効果**（5月コラボ）：「自分でできそう」と思わせ→「グループに費用もったいない」で離脱。
6. **ライフイベントと時期不一致**（両群）：転職活動中・2ヶ月後アメリカ転勤・冬に退職予定。

## 6. PR改善（事前診断ならではの示唆／総括は[01 §4](01_2経路比較_コラボvs面談経由.md)）

- **理想の天井を上げる**（5月コラボ）：「家庭の足し程度」で止まる層に、同属性の「月+10万／自立」実例を見せる。
- **興味スキルで出し分け**：5月コラボ＝インスタ運用代行／6月キャンペーン＝動画編集・デザインの仕事実例。
- **入会率の底上げ**（§5B）：夫相談・与信・費用を先回り（費用感の事前提示／夫に見せる資料／体験で「一人では無理」を実感）。
- 受動層（見てるだけ50%）向けに「まず話を聞くだけでOK」導線。
