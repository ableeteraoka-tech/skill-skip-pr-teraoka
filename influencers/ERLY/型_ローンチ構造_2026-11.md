# ERLYさんの型（11月 年内最後のコラボ）

元にしたもの：【共有用】ERLYさん11月台本（Googleドキュメント）、ストーリーズ文字起こし（erlyuesh 2026-11）
期間：教育3日（11/5〜11/7）＋訴求3日（11/8〜11/10）／参加特典：Amazonギフト1,500相当＋16大特典（予約特典なし）
予約数などの結果は、この資料を作った時点では未確認。

## サマリー

1. 教育は、本人の生い立ちを漫画3話にして24時間限定で1話ずつ配る連載。「続きは明日」で3日間つなぎ、3話目の最後に「お知らせ」を予告して開始日に入る
2. 漫画の流れは、お金がなくて夢を諦めた→不安なまま動けなかった→人に頼った転機→家で働けるようになった。最後の「詳しい人に相談した」が、そのまま相談会につながる
3. 教育の入口は質問箱。前向きでいられる理由、モチベ、我慢の話から、自然に過去の話へ入っている
4. 訴求では、相談会で聞けることを具体的に並べ、CTAの文言を毎回変えている（わたしにもできるか／自分に合う発信／仕事・子育てと両立できるか）
5. 実績は本人の収益画面（月40万前後）と、受講生の結果（卒業6ヶ月で＋20万、育休中に2ヶ月でショート動画の仕事）を並べる

## 2. 各要素の中身

### ① 漫画の連載（教育の中心）

| 話 | タイトル | 中身 | 次の日へのつなぎ |
| --- | --- | --- | --- |
| 1話 | 何も選べへんかった頃の私 | お金のことで我慢していた学生時代、貯金がないまま妊娠 | 感想DMを翌朝に出す |
| 2話 | はじめて誰かを頼った日 | 人に頼るのが苦手だった本人の転機。家で会社員以上の収入を作れるようになった始まり | 「明日3話、最後にちょっとしたお知らせ」 |
| 3話 | 家で働けるようになるまで | SNSの仕事を始めたきっかけ、夫に2年間こっそり〇〇していたこと、今の働き方になるまで | 翌日「大事なお知らせ」で開始 |

- 24時間限定で配ることで、その日のうちに読ませている
- 文字だと読めなかった人が、漫画で最後まで読めた（感想DMで本人が拾っている）
- 漫画の結論（相談したことが転機）が、相談会を受ける理由になっている

### ② 質問箱を入口にする

- 「いつも前向きだけど落ち込む時はない？」「モチベは？」「我慢することある？」から、過去の話へ入る
- 訴求中も「知識なくてもできる？」「どう始める？」「不安定じゃない？」「時間がなくてもできる？」を質問箱の形で答える
- 質問の形にすると、本人が言いたいことを押しつけずに出せる

### ③ 相談会で聞けることを具体的に

- わたしなら何を発信できそう？／仕事や子育てと両立できる？／お仕事につなげるには何から始める？
- 好きなことも得意なこともわからないけど何を発信できる？／顔出しせずにできる仕事は？／発信をどう収入につなげる？
- 「やりたいことがはっきりしていなくても、わたしに合うものってあるんかな？から話していい」
- CTAの文言を、その前の話に合わせて毎回変えている

### ④ 実績の並べ方

| 誰の実績か | 中身 |
| --- | --- |
| 本人 | 4人の子どもをほぼワンオペ、使える時間は1日2〜3時間で、10月の報酬約40万 |
| 本人の体験 | 4人目の出産時、つわり・入院・産後も収入があった |
| 前回の受講生 | 卒業6ヶ月で＋20万、本業の勤務時間を減らせた |
| 受講生 | 育休中に2ヶ月でショート動画の仕事、未経験から収益化、初めて案件を獲得 |
| 相談会を受けた人 | 思ったよりハードルが低かった、一番合う在宅ワークを提案してもらえた、無料なのになんで悩んでたんだろう |

### ⑤ 今やる理由

- 年内最後のコラボ、3日間限定
- 今年もあと2ヶ月。今年こそと思っていたのに後回しにしていない？
- 来年も同じ我慢を続けてほしくない、人生は一度きり
- 毎回終わってから「もう予約できませんか」と来るが、次はいつになるかわからない

## 3. 使いどころのメモ

- 予約特典を作る準備がないとき、教育が3日程度と短いときに使いやすい型
- 本人の生い立ちに強い話（お金で夢を諦めた、ワンオペで4人）がある前提。漫画にする素材と制作の時間が必要
- 相談会を受ける理由を、本人の転機（詳しい人に相談した）から自然につなげられる
