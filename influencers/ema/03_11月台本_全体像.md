# ema 11月台本 全体像

## 前提

- 期間：事前教育 11/20（金）〜11/27（金）、ローンチ 11/27（金）夜〜11/29（日）
- 特典：予約特典は愛犬のLINE絵文字の完全版note。お試し版noteはローンチ2日目（11/28）に配り、予約を迷っている人への再訴求に使う。それまではリンクを出さない
- 届けたい人（10月の事前診断より）：30代後半〜40代、犬と子どもがいる、SNSは見ているだけ、使える時間は1日1〜2時間、貯金は5万円以下で費用とパソコンが不安
- 訴求：ゴールは在宅ワーク（犬や家族のそばで働く）、始め方は副業（今の仕事を辞めずに1日1〜2時間から）

## 組み立て

- 1日目は maki さん11/19に入れた価値観の訴求の形：「今年も残り1ヶ月とちょっと」→ スマホの写真フォルダを見返してもらう → 写真がほとんどない時期があった → 撮ろうと思う余裕すらなかった → 人生は一度きり。3日目に同じく11/20の「もうすぐクリスマス、今年はもう戻ってこない」を入れる
- 3日目以降の土台は ema さん5月（予約29件）の流れ：昔の私の話から悩みを回収 → 回答シェアと時間の有限さ → 在宅ワークとは＋収入推移 → 質問への回答と、なぜプロか → 昔の自分への話 → 開始
- LINE絵文字は10月にも同じ特典を出しているので、10月に見た人がいる前提で組む。新しい要素は「10月に作り方を配ったら、実際に作って販売した人がいる」と「120円から売れる」「使い放題の人に使われても売上が入る」
- 話の軸は「LINE絵文字をきっかけに、自分で稼ぐ最初の一歩を」。絵文字は、自分で作ったものにお金がつく初めての体験で、在宅の仕事の入口として出す。emaさんのきっかけは離婚だったが、みんなのきっかけは絵文字でいい
- スキルスキップとのコラボと相談会は初日から出し、毎日どこかで触れる
- 特典は初日から興味づけし、毎日触れて期待値を上げる。2日目の1枚目で「作り方を配る」と予告し、絵文字の楽しさは3日目以降に出す
- 毎日の1枚目で離脱させない。前日の質問箱の回答から入らず、その日一番引きのある話から入る（回答は途中に入れる）
- 気づきは、見ている人が自分で気づける材料（数える、見返す、仕組みを知るなど）がある日にだけ置き、感情面と感情以外（知る・わかる）を1つずつ書く。1日のテーマは1〜2個に絞る
- 理想・悩み・価値観・緊急性が抜けないよう、各日の担当を決めておく

はなこさんの振り返りから持ち込むこと
- 理想の生活とワクワクを先に見せる
- 厳しい言葉は使ってもよいが、受付開始の直後には重ねない
- 後半は予約が少なくても出せる枚にする
- 最終日は午前・昼・夜に分けて一番厚く出す
- 閲覧数とリンククリックを毎日報告してもらう
