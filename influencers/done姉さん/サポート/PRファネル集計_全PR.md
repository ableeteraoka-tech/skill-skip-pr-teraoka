# done姉 PRファネル集計（全PR）

## サマリー
- **規模（ライン追加）は 1月145 → 2月コラボ80 → 5月以降14前後**と激減（ピーク比 約1/10）。
- **モデルが5月から変化**：1〜2月コラボ＝体験レッスンあり／5月コラボ以降＝直接面談（レッスンなし）。
- **入会は好調期に集中**：1月1・2月コラボ3、5〜7月は計2（すべて6月着金）。
- 母数が小さい5月以降は月別の率がブレる。意思決定は**5-6月合算（入会率40%）**で見るのが安全。

※率は合計ベース。月別だと着金ズレで率が暴れる（6月入会率200%等）ため、5月以降は3ヶ月まとめの方が実力値。

### 率の定義（各ステージ＝直前ステージ比）
- レッスン予約率＝予約÷ライン追加／レッスン実施率＝実施÷予約
- 面談予約率＝面談予約÷（レッスン実施 or ライン追加）／面談実施率＝面談実施÷面談予約／入会率＝入会÷面談実施
- 5月以降（直接面談）は面談予約率の分母＝ライン追加

### ⚠️注意
- **2月コラボの面談予約率141.67%**（17÷12）：レッスン未実施のまま直接面談を予約した人がいるため（＝直面談経由が上乗せ）。
- **6月の入会率200%**（入会2÷面談実施1）：着金（入会）は面談から遅れて発生するため。6月の入会2件は5月面談からの持ち越し着金の可能性大。**5-6月合算なら入会率40%**（入会2÷面談実施5）。

### 読み
- **5月は配布数も少なく（749 vs 1月1,210）、配布→予約CVRも0.4%と1月（7.4%）の約1/18**。**上流(reach)と転換の両方で崩れている**。
- ※5月のCVR母数はnote相談会配布物ベース。2チャネル合算ファネル（面談予約7）とは計測対象が微妙に違うため、厳密な突合は要注意。
- 配布物の実物：1月＝[特典/1月配布物_SNS在宅ワーク3ステップ.pdf](../特典/1月配布物_SNS在宅ワーク3ステップ.pdf)（保存済）。Drive/noteの元リンクは寺岡管理。

## 集計の前提
- **5月以降は2チャネル合算**（「done姉コラボ」＋「面談経由/done姉」）。通常キャンペーンリンク（5/10〜12）はコラボ外で除外。
- 集計単位：1月コラボ＝1-2月、2月コラボ＝3-4月（ローンチ翌月に面談・着金が持ち越すため）。5月以降は月別。
