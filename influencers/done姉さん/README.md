# done姉さん（PRデータ・分析）

30代ちゃん・はあちゅうと同じ構成の入れ物。データを頂いたら各フォルダに入れて、分析MDを足していきます。

## フォルダの使い分け
| フォルダ | 入れるもの |
|---|---|
| （直下） | 事前診断TSV／属性CSVバックアップ／月次の分析MD |
| `台本/` | PR台本（回ごと・清書） |
| `文字起こし/` | ストーリーズ等の発信ログ（1行＝1枚の縦持ちTSV推奨） |
| `カウンセリング/` | 申込者ごとの個別カウンセリング全文（1人1ファイル） |
| `サポート/` | 予約推移・数値・タイムラインなど実行データ |

## 進捗
- 2026-07-31：フォルダ作成
- 2026-08-01：1-7月ストーリーズ取込／PRファネル集計／訴求比較分析

- 事前診断の回答（CSV/Excelエクスポート推奨。改行が崩れず正確）
