maki版と同じ「知り合いの実績フック → “おうち仕事”（中身はインスタ運用代行）」型。
done姉さん用にデータでチューニング済み。**[ ]の中を"本当の実話"で埋めるだけ**の状態。

## 埋めるだけテンプレ

```
【保存版】[元の状況]を[時短/スキマ時間で/在宅に]、[時間ベネフィット]も月5万も増えた[関係性]の話。
─ ママのための、はじめての“おうち仕事”
```

## [ ] に入れる要素（実話が来たら確定）

| スロット | 候補・ルール | 例 |
|---|---|---|
| 関係性 | **確定：done姉さんの受講生 → サポーター（秘書）になった人**（一次情報＝「私のサポーターがね…」／受講生の成長＝スクールの証明にもなる。maki の"元看護師＝私の秘書"と同型） | 「私のサポーター（元・受講生）」 |
| 元の状況 | 本業・働き方（フルタイム/パート/専業/職種） | 「フルタイム勤務」「パートの掛け持ち」 |
| 変化 | 時短にした／スキマ時間で／在宅にした | 「スキマ時間で」 |
| 時間ベネフィット | 家族時間／子どもとの時間／自分の時間 | 「家族時間」「子どもとの時間」 |
| 数字 | **原則 月5万**（done姉さんの需要主役）。実話の数字が違えば実数字を優先し盛らない | 「月5万」 |
| 中身 | “おうち仕事”で隠す（本文でインスタ運用代行に着地） | 固定 |

- 【保存版】[元の状況]から、スキマ時間で家族時間も月5万も増やして“私のサポーター”になった受講生の話。─ ママのための、はじめての“おうち仕事”
- 【保存版】“見る専”だった受講生が、子どもとの時間も月5万も増やして私のサポーターに。─ ママのための“おうち仕事”のはじめかた
- 【保存版】[元の状況]が、おうちで月5万＋家族時間を手に入れて私のサポーターになった話。─ おうちで、時間も収入も増やすノート

## 使うときの注意（maki版で学んだ地雷）

- **職業名を主語にしない**（看護師/会社員で最大層が外れる）。主語は「状態」か「関係性」。
- **自分ごとワード（ママ・家族）は"読者側=ブリッジ"に置く**。実話の人物に無い属性（子ども等）を載せない＝嘘にしない。
- **数字は"増えた分"と読ませる**（総収入に見せない）。
- **意外性のタネ**＝「[時間/負担]を減らしたのに[時間/お金]が増えた」の逆説。
- done姉さんは**50代が母数だが買わない → 30代子持ち・在宅志向に照準**。

## 実話が来たら集める3項目（maki版と同じ）
1. 誰が（関係性・元の状況）
2. どう変わったか（時間ベネフィット＋月◯万／"減らしたのに増えた"の逆説があるか）
3. 具体エピソード1つ（読者=ママの理想と重なる"時間で得たもの"）
