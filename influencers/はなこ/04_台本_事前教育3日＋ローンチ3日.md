# はなこさん 台本（事前教育3日＋ローンチ3日）初稿

## サマリー
- 向ける相手：お給料も時間も、今の働き方のままでは足りないと思っている人。既婚・独身、子どもの有無、犬の有無がいずれも半々に近いので、属性では切らない。犬は大切な存在の一例として、本人の話の中で触れる程度にする
- はなこさんは28歳・独身・子なしなので、語るのは自分の経験だけ。家庭の場面は読者に聞く、置き換えてもらう形にする
- 事前教育：Day1 誰に向けた話か → Day2 時間とお金／今の毎日／辞めなくていい → Day3 遠回りと相談会の意味
- ローンチ：Day4 開始と特典 → Day5 不安とQ&A → Day6 締切
- ★は本人・運営の確認が必要な箇所。予約数、DM、受講生の実績は実物があるときだけ入れる

## 元にした数字

| 事前診断の悩みの記述（6名） | お金4名、働き方4名、大切な人との時間3名、犬に触れたのは1名 |
