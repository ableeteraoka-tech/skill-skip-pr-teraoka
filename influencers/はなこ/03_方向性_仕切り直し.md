## 仮説：なぜ20代に寄ったか
看護師の激務時代の話が刺さり、激務・夜勤系の人が多く来た。ただ、激務の話がはなこさん自身（28歳・独身）の目線で語られていて、子どもや家庭がある人の場面が出てこないため、20代・独身に寄った。

| 10月に出していたもの | 届きやすい層 |
|---|---|
| 「今年28になります」「同年代も多いのかな？」 | 同年代の20代 |
| 24歳で借金を肩代わり、20代で看護師からフリーランスへ | 20代のキャリアチェンジ |
| 激務のつらさが、体力・メンタル・肌・眠れない・人間関係など自分自身のこと | 自分のことだけ考えればいい段階の人 |
| 犬を母に任せていた（実家暮らし時代）、引っ越し、徹夜でnote作成 | 独身・身軽な人 |
| 「定年まで耐えるのは無理だと思った」 | 社会に出て数年の人 |

30〜40代が自分ごとにできる場面（子どもの送迎や急な発熱で休む、夫の収入だけでは足りない、今からでも間に合うのか、体力が落ちてもこの働き方を続けられるか）は出ていない。見ている人のしんどいことの1位は「給料が低い・上がらない」（44%）で、夜勤や体力ではない。

→ 既婚・未婚、子どもの有無をアンケートで確かめて、属性を見直す。激務だけで行くとまた20代に寄る可能性があるので、将来を見据えた話（給料が上がらないままの10年、体力が落ちても続けられるか、家族との時間）も入れる。はなこさん本人が28歳なので、30〜40代は「若いからできた」と感じる可能性がある。激務系から在宅に移った30〜40代の受講生の実績があれば使う。

## 3. 方向性

### 1. 主軸は激務の働き方のつらさにする
事前診断で一番多い入口は、夜勤・残業・体力・休みのなさなど今の働き方のつらさ（5名中3名）。犬が入口になっているのは1名なので、犬は主軸にせず、入口の一つとして残す。見ている人の69%が会社員で、しんどいことの1位は「給料が低い・上がらない」なので、看護師に絞らず、時間とお金の両方のつらさを入口にする。看護師の話は、はなこさん自身の経験として残す。

### 2. 35〜44歳に届く話を足す
フォロワーで一番多い35〜44歳（38%）からの予約がまだない。10月は、はなこさんと同年代の20代に届いている。今の働き方はストーリーズの投票ですでに聞いている（会社員69%）。念の為、アンケートで犬を飼っているかを確かめ、そのうえで30〜40代が自分ごとにできる場面（家族との時間、このまま給料が上がらない働き方を続けた先）を足す。激務系から在宅に移った30〜40代の受講生の実績があれば使う。

### 3. 相談会に寄せる
スクールに入ると決めていない人、他社と比べている人が多い。10月はスクールの仕組み（同じコーチ、進捗管理シート）や自己投資の話（スクール代を1年で回収）が予約前に出ていたので、これは予約前には出さず、相談会の中で話してもらう。事前診断では「見ているだけ」「まだ何もしていない」が5名中4名で、何から始めるかを決める前の段階にいる。相談会は「今の働き方のしんどさを話して、私でもお家で働けるのか、ほかにどんな働き方があるのかを相談できる場」として、肯定の形だけで出す。

### 4. 本業を辞めない前提を出す
今の仕事をすぐには辞められない・手放したくない人が3名、使える時間は1時間が3名。「今の仕事を続けながら、1日1時間で何から始めるか」を見せる。

## 4. 仕切り直し前に確認すること

- フォロワーのうち、看護師の割合（ストーリーズの投票結果）
- フォロワーの既婚・未婚の割合
- フィード投稿にコメントが来ているが、DMで対応しているか
- ローンチ期間中に来たDMと、質問箱の回答内容（emaさんも同様に確認）
- ローンチ期間中のストーリーズの閲覧数
- 開始日時と枠数（開始前に確定し、1回で告知する）
- 激務系から在宅に移った30〜40代の受講生の実績（運営にヒアリング）
