# ローンチ・プレイブック（maki × 30代ちゃん 統合）

> 出典：maki『台本FB_maki宛_8月後半_川口さん』(8/22-25 秘書コラボ) ＋ 30代ちゃん『2026-07_ストーリーズ』(7/1-5 楽天ROOM×カウンセリング)。
> 目的：コラボ相手が変わっても使える"ローンチの型"。特典→相談会予約への気持ちの動線を作る。
> 表記注意：IFごとに用語を守る（美桜さんは「一部公開版」、30代ちゃんは「お試し版」）。フレーズは流用せず各IF本人の声で書き直す。

---

## 0. 全体ゴール（気持ちの動線）
**特典が欲しい → 中身をもっと知りたい → 自分の場合はどうか相談したい**
- 経験談で終わらせず、その都度フォロワーの不安・本音を代弁 → 問いかけて"自分ごと化"。
- 相談会予約が最終ゴール。特典（note＋アマギフ）は"予約の理由づけ"。

## 1. 横断で必ず入れる4本柱（maki）
1. **特典の魅力を早い段階で**（①何が受け取れる ②予約で何がもらえる ③読むと何が分かる）
2. **予約反応を見せてお祭り感**（1人目→2人目→〇分で〇人→〇時間で〇人）
3. **不安・本音を代弁して問いかける**（怖い/何話す/中身見えない/どうせ私には無理）
4. **相談会が何をする場所かを伝え、予約ハードルを下げる**（期間の最初と最後、最低2回）

## 2. 日別の型（4日構成の例）

### Day1｜開始・特典公開・予約スタート
- コラボ発表 → 特典note完成 → 中身の3点（何から/どう稼ぐ/コツ）
- **予約特典の受け取り条件を明示**（相談会予約でnote／参加でアマギフ）
- CTAは「相談会を予約してnoteを受け取る！」（"予約"を動詞に）
- 初日から**予約反応**（1人目DM→数分で〇人）でお祭り感
- 枠数の初期提示（残り〇枠）

### Day2｜お祭り感・不安代弁・相談会=整理の場
- 予約者の声／0→1報告を複数（背景ストーリー付き＝共感）
- **未予約の不安を代弁**：何を話せばいい/自分にできるか/まだ決めきれない
- 相談会は"入会を決める場"でなく**"自分の状況を整理する場"**
- **特典を相談会とセットにした理由**（note渡して終わりにしたくない）
- （maki）問いかけページを黒背景×白文字で1枚「"どうせ私には無理"と思った人いない？」

### Day3｜一部公開版を配布・中身の価値・"表面情報"を一蹴
- **一部公開版を配布**（キーワードDMで／字数明示 例:4000字／配布は期間中のみ）
  - ※maki型では「視覚的に」＝モザイク付きスクロール動画でボリュームを見せる
- 読んだ人の声（"未経験でもイメージ湧いた"）
- （30代）**"表面的なネガティブ情報"を一蹴**：AIで仕事なくなる/SNS飽和/フォロワーないと無理
  →「で、みんなどこで稼いでるの？まで調べて動いた人が結果を出す」
- 情報の段階整理：一部公開版=入口／本編=さらに／相談会=自分に合う進め方まで

### Day4｜最終日（締切）・熱量・将来訴求・ラストCTA
- **締切訴求は午前＋夜の2回**（"今日23:59で終了"／現在の予約数・受取数）
- （30代）**"最初の熱量"論**：やりたい気持ちは今が最大、時間が経つとやらない理由が生える
- **将来への問いかけ**：物価↑給料そのまま／10年後"あの時やっとけば"／今のままでいい？
  - きつく責めず、少し鋭い言葉で人生を考えさせる
- （maki）**特典の希少性**：検索で出ない/他人に教えたくない情報/今回のために作った
- ラストCTA（受け取り・予約は今日まで）

## 3. お金・数字の見せ方（maki）
- 数字単体で終わらせず「その数字で何ができるか」まで。
  例：月〇万→家族旅行〇回／習い事／10年で〇〇万→増やせる選択肢。

## 4. 相談会の訴求（最重要・maki）
- 「入会する/しないをその場で決める場所ではない」
- 「自分にどんな選択肢があるかを一緒に考える／10年後に後悔しない人生を選ぶ時間」
- 「だから予約特典の受け取り条件にしている＝読んだ人にこそ相談会まで受けてほしい」
- （30代）「煽らない・勧誘しない→必要な人が来てる」／入会しなかった報告も載せて安心感

## 5. 希少性・後回し防止
- 枠のカウントダウンを運営コメントで（残8→追加30→14→10→7…）
- 人数制限「受け取れるのは〇人／残り〇人／あと5人で終了」
- 締切間際の"滑り込み"訴求（ストーリー消える前に）

## 6. 素材チェックリスト（★で台本に差し込む）
- [ ] 予約DM（1人目/2人目/〇分で〇人）
- [ ] 0→1・実績報告（背景ストーリー付き）
- [ ] 卒業生/受講生のBefore/After実績
- [ ] 枠数・残数（運営提供）
- [ ] 一部公開版リンク＋配布キーワード＋字数
- [ ] アマギフの受け取り方（例：面談後2週間でメール送付）＝表記はIF規定に従う
- [ ] 締切日時
