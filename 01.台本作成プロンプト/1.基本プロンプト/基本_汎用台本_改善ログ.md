# 全体FB（全IFに適用される普遍的なルール）

> 複数IF・複数キャンペーンで共通して当てはまる気付き・修正指示の累積。
> `/generate-script` 実行時に必ず内部チェックリストとして適用される。
> 違反した枚は出力前に書き換える。

## フォーマット

```
## YYYY-MM-DD: <タイトル（一行）>
- **対象**: <出典ファイルパス＋Day/枚 など（任意）>
- **指摘**: <ユーザーからのFB原文>
- **ルール化**: <今後の生成時に必ず守ること>
- **カテゴリ**: 表現／構成／トーン／素材／PR感／その他
```

## 2026-05-13: 1日のフォロワー能動アクションは1〜2個までに絞る

- **対象**: PR原則
- **指摘**: 単日内にアンケート＋質問箱を両方入れると、フォロワーが能動的に動く部分が詰め込みすぎになり、各アクションのエンゲージメント率が落ちる。
- **ルール化**: 1日（特に Day1）で読者に能動アクション（アンケート／質問箱／DM誘導／スタンプ／リアクション要求／タップ要求等）を求める箇所は **1日1つ、多くても2つまで**。3つ以上になる場合はDayをまたぐか、削る。
- **カテゴリ**: 構成
- **多重保存**: 30代ちゃん/2026-06 が起点（`_生成台本/v2.md` Day1）

## 2026-05-13: 冒頭フックを後半で回収し、不幸の箇条書きで「自分のどれかに当たる」状態を作る
- → 2026-05-13 メインプロンプト第6章【D】ルール4に昇格
- **対象**: PR原則
- **指摘**: Day冒頭で出したフックを中盤〜後半で再提示し、「その状態が続くとどうなるか」の不幸を箇条書きで複数並べると、読者の誰かに必ず1つは刺さる。
- **ルール化**: Day内で **冒頭フック → 中盤〜後半で再提示 → 「このまま続くとどうなるか」の不幸を箇条書き** という構造を入れる。箇条書きは複数の異なる悲観シナリオを並べ、マスのターゲットの誰かに当たるよう網を広く張る。
- **カテゴリ**: 構成
- **多重保存**: 30代ちゃん/2026-06 が起点（`_生成台本/v2.md` Day1 枚7）

## 2026-05-13: 訴求軸をターゲット絞り込み→広げる「メリハリ設計」で対象を最大化する
- → 2026-05-13 メインプロンプト第12章「ターゲット絞り→広げるメリハリ設計」に昇格
- **対象**: PR原則
- **指摘**: 一見特定セグメント向け（例：離婚を考えるママ）の訴求でも、「この話は◯◯すべきとは言わない／安心してね」と明言し、円満層・独身層など隣接セグメントにも自立／保険／普遍テーマとして広げると、ターゲットがマスに拡張されローンチが伸びる。
- **ルール化**: 強い訴求軸（離婚／退職／別離など心理ハードルが高い軸）を扱うDayでは、**①「〜すべきとは言わない」と明言して心理ハードルを下げる** ②「隣接セグメントにとっても保険／普遍テーマ」と意識的にターゲットを広げるテキストを併置する。狭める／広げるのメリハリを設計に組み込む。
- **カテゴリ**: 構成
- **多重保存**: 30代ちゃん/2026-06 が起点（`_生成台本/v2.md` Day1 枚6）

## 2026-05-13: アンケートでフォロワーに「自分の状態」を選ばせ自分ごと化させる
- → 2026-05-13 メインプロンプト第9章「アンケートの設計ルール」に昇格
- **対象**: PR原則
- **指摘**: アンケートでフォロワーにボタンを押させて自分ごと化させると、その後の訴求への没入度が上がる。

- **カテゴリ**: 構成
- **多重保存**: 30代ちゃん/2026-06 が起点（`_生成台本/v2.md` Day1）

## 2026-05-13: Day1冒頭4〜5枚は「因果のレイヤーを1段ずつ降りる」段階的気づき構造
- → 2026-05-13 メインプロンプト第6章【D】ルール3に昇格
- **対象**: PR原則
- **指摘**: 1枚ごとに新しい気づきを段階的に与えると、読者が能動的に読み進める動機になり、最終的に「自分が嫌い／自分依存」のような深層気づきまで一貫性をもって到達できる。
- **ルール化**: Day1 冒頭4〜5枚は **1枚＝1段の気づき深化** で設計する。表層の事実（行動／状態／数字）→ 行動原因 → 心理構造 → 自己評価／自己否定 のように、**因果のレイヤーを1段ずつ降りる**構造を取る。1枚に2段以上詰め込まない。
- **カテゴリ**: 構成
- **多重保存**: 30代ちゃん/2026-06 が起点（`_生成台本/v2.md` Day1 枚1〜4）

- **カテゴリ**: 表現／構成
